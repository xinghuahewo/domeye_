# 国家中断报告与追问

## 工作流

1. 只接受已有合法 `country_outage` 引用，不接受任意国家或任意时间。
2. 先调用 `country_outage_resolve`，确认事件、publication、revision、RRC25 和
   正式报告资格。
3. 调用 `country_outage_get_observation` 获取固定快照事实合同。不得自行计算、
   补零、插值或从模型记忆补充数字。
4. 只有在宿主明确要求读取 ASN 明细且能力为 `available` 时，才调用
   `country_outage_get_asns`。语言槽生成本身不需要 ASN 明细；不得为改写措辞
   重复读取工具。
5. 生成报告时读取 [指标与边界](references/metrics-and-boundaries.md) 和
   [报告输出合同](references/report-output-contract.md)。
6. 宿主先以固定证据生成并校验完整确定性基稿。模型只输出报告合同要求的原子
   语言槽 JSON，不输出报告结构、数字、证据引用、Markdown 围栏、工具过程或
   思考过程。
7. 快照冲突、最低数据不足、确定性基稿失败、语言槽失败或最终校验失败时停止，
   不提供半成品报告，也不静默退回未应用模型文本的基稿。

## 强制边界

- 从始至终只描述 RRC25 固定统计范围内的 BGP 控制面观测。
- 不认定全国断网、用户或业务影响、攻击、政策、配置错误、基础设施故障、
  责任主体、完全恢复或事件结束。
- 不把 Prefix×VP、前缀、ASN、IP、用户、业务和地址等价资源互相换算。
- UPDATE 与可见性变化时间相邻只能写成时间对应，不能写成因果。
- 缺失能力省略相应章节或明确降级，不能用常识、外部资料或零值补齐。
- 所有可发布文本的下降、持平、上升、回升、继续下降以及窗口结束相对起点的
  描述，都由宿主根据工具返回的确定性派生事实锁定。模型语言槽不得新增或改写
  任何方向判断，也不能套用伊朗代表事件的方向。
- 非最终快照明确数据截止时间和非最终状态，不推断窗口之后的变化。
- 基础报告不搜索互联网。外部证据只能由宿主在用户显式授权的独立模式中提供。
- 不执行 Shell、文件读取或编辑、SQL、任意 URL、会话切换和数据写入。

## 语言要求

- 使用简体中文，面向能够阅读网络观测报告的人。
- 语言槽只改写事件无关的口径和证据边界说明；标题、摘要、数字、方向、章节、
  引用和不能回答项均由宿主固定。
- 用简洁完整的一段话解释指定语义，不增加事件、国家、运营商、ASN、时间、
  数字、因果或恢复事实。
- 使用克制表述，例如“观察到”“时间上相邻”“部分回升”“不能据此确认”。
