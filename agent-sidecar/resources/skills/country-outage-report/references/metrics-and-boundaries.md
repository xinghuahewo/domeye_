# 指标与证据边界

## 一、固定身份

报告、追问和下载必须共同绑定：

- `incidentId`
- `publicationId`
- `revision`
- `dataThrough`
- `cohortId`
- `collectorId=rrc25`
- `windowStartUtc`
- `windowEndUtc`

任一接口身份不同都属于快照冲突，不能拼接。

## 二、核心指标

### Prefix×VP

`visible_prefix_vp_count` 表示“某个前缀是否能从某个固定 BGP 观测点看到”的关系
数量。同一前缀对应多个观测关系，因此它不是唯一前缀数、IP 数、用户数或业务数。

`visible_prefix_vp_ratio` 的分母是固定 cohort 中的 `prefix_vp_count`。起点、最低点
和结束点必须来自同一固定人口。

### Origin ASN 状态

- `fully_visible`：固定成员路由全部可见；
- `partially_visible`：固定成员路由部分可见；
- `fully_invisible`：固定成员路由全部不可见；
- `unknown`：该槽无法形成状态。

不同状态的峰值可能发生在不同时间，不能直接相加。持续时间不能自动解释成影响
规模，ASN 的固定路由人口可能差异很大。

### IPv4 与 IPv6

只能比较同一地址族自己的固定 Prefix×VP 人口和覆盖率。地址族覆盖率不能换算为
用户或业务影响。

### UPDATE

`announce_count`、`withdraw_count` 和 `update_total` 是相应时间槽内的 BGP UPDATE
活动。峰值与可见性变化相邻只能表述为时间对应。`withdraw_ratio` 上升不能单独
证明故障持续、原因或恢复。

### 国家级等价资源

IPv4 `/24` 和 IPv6 `/48` 等价资源是规范化、去重后的路由资源覆盖，不是实际在线
地址。大前缀会折算为大量等价块，不能解释成同等数量的独立前缀同时变化。

## 三、缺失和质量

- `available`：可以使用；
- `building`：尚未形成可发布结果；
- `unavailable`：当前快照没有该能力；
- `not_applicable`：该能力对本事件不适用；
- 缺槽：保留缺槽原因，不补零、不连线；
- 非最终事件：明确 `dataThrough`，不推断其后的状态。

正式报告最低需要固定快照、RRC25、窗口、统计人口、可见性序列、起点、最低点、
结束点和质量状态。扩展能力缺失只降级章节，最低数据缺失则拒绝正式报告。

## 四、结论等级

变化方向必须读取工具已经提供的确定性派生事实，不能套用伊朗代表事件的方向：

- 起点到最低点的差值小于零时写下降，大于零时写上升，等于零时写持平；
- 最低点到窗口结束的差值大于零时写回升，小于零时写继续下降，等于零时写持平；
- 窗口结束相对起点的差值小于零时写仍低于起点，大于零时写高于起点，等于零时
  写回到起点或与起点持平；
- 方向词必须在标题、副标题、摘要、关键数字、章节和不能回答项等全部可发布文本
  中保持一致；
- 变化覆盖多个 origin ASN、IPv4 与 IPv6 的相对变化、UPDATE 时间对应和窗口后段
  状态，只能在相应能力可用且对应事实存在时写入；
- 非最终快照必须明确 `dataThrough` 和非最终状态，不能推断窗口之后的方向。

禁止在仅有 Domeye 快照时写成：

- 全国互联网已经中断；
- 用户或业务受到同比例影响；
- UPDATE 导致中断；
- 某运营商或 ASN 应负责；
- 攻击、政策或配置错误是原因；
- 网络已经完全恢复或事件已经结束。
