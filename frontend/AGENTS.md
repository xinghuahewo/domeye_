# 前端局部协作规则

本文件只补充仓库根目录的 `AGENTS.md`，适用于 `frontend/`。根级规则继续完整生效，本文件不得放宽或覆盖上级的数据、事实、安全、任务隔离和发布约束。

## MUST

- `contracts/openapi.json` 是前端传输层的机器接口合同；`src/types/openapi.generated.d.ts` 只能通过根目录 `make api-types` 生成，禁止手工修改。
- HTTP 传输、基础地址和端点构造必须留在 `src/api/`；Vue 页面和组件不得直接使用 `fetch` 或 Axios，但可以调用 `src/api/` 导出的客户端函数。
- 固定数据范围相关界面必须消费根级唯一数据档注入的窗口和时区，不得用浏览器当前时间替代业务查询窗口、快照时钟或观测时间。
- 对版本化事件和 Agent 流程，必须传递并校验合同实际提供的事件与发布身份，拒绝混合版本、身份回退以及迟到响应覆盖当前页面；不得要求旧接口提供其合同中不存在的身份字段。
- `null`、缺槽、不可用和未知必须保持原语义，不得补零、插值，或用其他国家、事件、publication 的数据填充。
- 不得在页面中重算后端或 Sidecar 已提供且会改变事实语义的阶段、极值、Finding、Claim 或 Agent 回答；纯展示格式化、分页和排序可以在前端完成。
- 正式 Agent 用户出口必须忠实呈现公开 `answer_text`；允许不改变语义的 HTML 转义、安全 Markdown 渲染和纯展示排版，除此之外不得裁剪、润色、拼接或在 Guard 后重写。错误只展示公共合同允许的稳定消息，重试入口只服从公开 `retryable`；普通界面不得泄露内部审计对象、身份、摘要、路径、端口或未纳入公共合同的内部错误码。
- 异步页面必须如实区分加载、空数据和失败；只有合同允许安全重试时才提供重试。新增或修改交互控件时，必须保留语义、键盘操作和焦点可达性。
- 行为变化必须新增或更新就近的 Vitest，并覆盖受影响的关键否定边界。最终检查必须服从任务合同和仓库风险分类器；局部测试不能替代根级 postflight。
- 当任务验收目标明确包含布局、响应式、焦点路径或视觉层级时，必须在真实浏览器中验证受影响的视口和状态。该要求只在视觉结果属于本次验收目标时生效。

## SHOULD

- 保持现有职责方向：`src/api/` 负责传输，`src/utils/` 负责必要的校验与归一化，`src/types/` 负责类型和页面模型，页面与组件负责交互编排和呈现。
- 在最靠近数据边界的位置校验不可信响应；格式异常或身份不一致时应失败可见，不应静默回退到更旧或语义更弱的页面。
- 优先使用就近定向测试完成快速循环，并保留混版、迟到响应、缺失值和内部信息泄露等负向断言。
- 优先复用当前 Vue、Vite 和 Vitest 栈。新增状态管理、请求、组件、DOM、E2E 或视觉测试框架前，应先证明现有工具不能满足已确认目标，并取得相应任务授权。

## MAY

- 可以从仓库根目录执行 `make preview`，或使用开发模式、可用的浏览器工具完成视觉检查；`make preview` 只是可选入口，其固定 Mock 结果不能单独证明真实 Candidate、发布或部署状态。
- 可以在合同允许的范围内进行显示格式化、有界分页、排序和交互状态派生，但不得借此生成新的领域事实。
- 只有当更深目录形成独立权威、独立命令或独立风险边界时，才考虑增加更深层的 `AGENTS.md`。
