# 国家中断通用观测页最终验收文档

版本：2.0
状态：最终效果合同  
数据范围：`[2026-02-24T00:00:00Z, 2026-03-11T00:00:00Z)`，即 224-310
适用对象：上述范围内全部合法 `country_outage` 事件的事件详情页及其下钻阅读体验

## 一、文档定位

本文只设计最终效果，不规定数据库表、文件布局、接口拆分、编程语言、进程形态、
投影器实现、页面组件或具体实施顺序。

最终页面回答五个用户问题：

1. 事件窗口内有多少前缀发生路由中断，多少独立观察方向看不到它们；
2. 有多少 AS 受到影响，哪些 AS 的固定前缀全部发生路由中断；
3. 固定前缀对应的 IPv4 地址量和 IPv6 `/48` 等价量如何变化；
4. 出事的是哪些 AS，这些 AS 是什么性质；
5. 哪些网络只在事件前的实际 RRC25 AS_PATH 中与出事 AS 存在路径关联，并且其中
   哪些同时出现前缀路由中断。

“国家中断”是既有事件类型名称。页面从始至终只描述 RRC25 所见 BGP 控制面路由
观测，不据此认定全国断网、用户或业务影响、原因、攻击、政策行为、责任主体、
客户依赖或传播因果。

## 二、用户最终看到的页面

正常可用事件只有一条默认阅读路径，不提供 224-310 全窗切换：

1. **事件概览**：国家、事件状态、事件窗口和一句观测事实摘要；
2. **前缀路由中断趋势**：中断前缀与完全中断前缀随时间变化；
3. **AS 路由中断趋势**：AS 路由中断与受影响 AS 随时间变化；
4. **IP 地址变化趋势**：固定 cohort 的 IPv4 地址量、IPv6 `/48` 等价量，以及
   独立的新前缀轨道；
5. **受影响 AS 列表**：AS 身份、名称、性质、前缀中断规模、观察方向和路径关联
   下游规模；
6. **路径关联下游**：实际观测路径关系、同时发生中断的子集及其前缀和地址规模。

正常页面不展示 RRC25、Publication、Revision、数据截止、完整度、mapping 或外部
属性快照版本等审计字段，也不向用户展示 `Prefix×VP` 术语。系统仍须在幕后保证
这些身份唯一、结果一致；身份或质量不成立时进入明确的不可用或不完整状态，不能
用零值、空图或旧结果伪装正常页面。

## 三、最终效果要求

### GFA-01：全部合法事件进入同一稳定体验

- 任意合法 `country_outage` 引用进入同一页面结构和同一术语体系；
- 国家、事件、窗口和最终性由事件事实决定，不存在国家专用页面分支；
- 伊朗与其他国家使用同一指标定义、缺失语义和下钻规则；
- 非法事件、合法但数据未就绪、数据不完整和完整可用具有不同用户结果。

### GFA-02：事件窗口随生命周期确定并在最终态冻结

- 页面默认窗口从首次检测前一小时开始，即向前覆盖 12 个完整五分钟槽；
- 活动事件只延伸到最新完整槽，不展示尚未完整的数据；
- 事件进入最终态后，页面窗口和所有确定性数字冻结；
- 来源边界不足一小时时保留左边界缺口，不静默扩大 224-310 数据范围；
- 页面不提供全局 224-310 窗口与事件窗口之间的切换。

### GFA-03：固定 cohort 和独立观察方向在事件前冻结

- 固定 cohort 取首次检测到前缀路由中断之前最后一个完整五分钟状态点；
- cohort 成员至少能够唯一识别前缀、地址族、origin ASN 和当时实际观察到该前缀的
  方向集合；
- 一个独立观察方向定义为一个 RRC25 peer ASN；同一 peer ASN 的多个 BGP 会话只算一个方向；
- 同一方向内只要任一仍可观测会话看到该前缀，该方向即为可见；只有该方向没有任何
  会话看到该前缀时才判为不可见；
- cohort 冻结后，新出现的前缀或观察方向不改变事件分母。

### GFA-04：前台“中断”只表示当前路由未被观测到

- 页面不要求出现显式 WITHDRAW 才把一个方向判为不可见；
- 当一个方向的相关会话全部不可观测，且当前没有该前缀路由观测时，该方向按不可见
  计入；
- 会话掉线不会被伪写成 WITHDRAW，也不会被描述为对端主动撤回；
- 无法确定方向状态时结果为未知，不把数据缺失直接算作中断；
- 页面使用“前缀路由中断”“AS 路由中断”和“受影响 AS”，不使用“全国断网”或
  “服务中断”替代。

### GFA-05：前缀部分中断与完全中断具有唯一规则

- 固定前缀至少一个预期方向不可见、至少一个预期方向仍可见时，为部分中断；
- 固定前缀全部预期方向不可见时，为完全中断；
- 固定前缀至少一个预期方向不可见时，计入“前缀路由中断”；
- 每个前缀可回答预期方向数、不可见方向数、仍可见方向数和当前分类；
- 前缀只计一次，不因同一 peer ASN 的多个会话或重复路径而重复计数。

### GFA-06：AS 路由中断与受影响 AS 具有唯一规则

- 固定 cohort 中某 AS 至少一个固定前缀部分或完全中断时，该 AS 为受影响 AS；
- 某 AS 的全部固定前缀均为完全中断时，该 AS 为 AS 路由中断；
- 新出现前缀不抵消固定前缀中断，也不把 AS 提前写成恢复；
- 未知前缀状态保持未知，不静默并入正常、受影响或 AS 路由中断；
- 前缀人口、AS 人口和观察方向人口始终分开，不生成混合影响分数。

### GFA-07：前缀路由中断趋势能够直接阅读事件变化

- 五分钟趋势至少同时呈现前缀路由中断数量和完全中断前缀数量；
- 用户能定位首次中断、最大中断、回落和终点状态；
- 图例、摘要、悬浮值和下钻使用 GFA-05 的同一分类结果；
- 缺槽断开显示，不补零、不连线，也不解释为恢复。

### GFA-08：AS 路由中断趋势与前缀趋势分图展示

- 五分钟趋势同时呈现 AS 路由中断数量和受影响 AS 数量；
- AS 趋势与前缀趋势分图展示，使用各自整数纵轴，不混用比例或双轴制造可比性；
- 用户能从任一时刻下钻当时的受影响 AS 与 AS 路由中断集合；
- AS 趋势只由 GFA-06 的确定性状态产生，不复用旧 AS 中断表的不同口径。

### GFA-09：IP 地址变化趋势使用唯一前缀去重

- IPv4 地址量按唯一 IPv4 前缀计算，不因观察方向数、BGP 会话数或 AS_PATH 数量重复；
- IPv6 使用 `/48` 等价量，并明确它不是 IPv6 实际地址总数；
- 固定 cohort 的可见资源变化与事件后新出现前缀的资源量分轨呈现；
- 新前缀只表示事件窗口内新增观测，不抵消固定 cohort 的路由中断，也不计入当前事件
  的恢复判断；
- IPv4 与 IPv6 分别展示单位，不能直接相加为单一 IP 影响数字。

### GFA-10：受影响 AS 列表同时给出身份、性质和观测规模

- 列表至少展示 ASN、AS 名称、组织或性质、固定前缀数、部分中断前缀数、完全中断
  前缀数、不可见独立方向数和路径关联下游 AS 数；
- AS 路由中断排在受影响 AS 之前；同类先按完全中断前缀数降序，再按实际观测的
  路径关联下游 AS 数降序，最后按 ASN 稳定排序；
- 缺少 AS 名称或性质时显示未知，不通过猜测、在线搜索或名称推断补齐；
- 列表不使用无解释的单一影响分数，也不把排序解释为用户影响或重要性。

### GFA-11：受影响 AS 可以在同一事件窗口下钻 AS 详情

- 点击 ASN 进入已有 AS 特征页面，不复制第二套 AS 档案；
- AS 详情默认继承当前事件的开始和结束时间，不退回“最近 24 小时”；
- AS 详情中的事件窗口指标与国家中断页使用兼容的时间槽和缺失语义；
- 返回国家中断页后保持原事件、时间位置和列表条件。

### GFA-12：路径关联下游只来自事件前实际 AS_PATH

- 路径关联下游只从 cohort 冻结点实际观测到的 RRC25 AS_PATH 提取；
- 只有观测路径包含受影响 AS 的网络才进入路径关联集合；
- 页面区分全部路径关联下游与其中同时出现前缀路由中断的子集；
- 每个下游 AS 至少能查看关联路径、同时中断前缀数、IPv4 地址量和 IPv6 `/48`
  等价量；
- 第一版不使用 AS relationship、customer cone 或外部拓扑推断，不使用“依赖下游”
  “受传播影响”或“因该 AS 中断”等因果措辞。

### GFA-13：页面以用户任务组织，不以内部数据结构组织

- 页面顺序固定为事件概览、前缀趋势、AS 趋势、IP 资源趋势、受影响 AS、路径关联
  下游；
- 首屏优先回答发生规模和当前状态，不展示内部制品身份；
- 前台不出现 `Prefix×VP`，改为“多少前缀被多少独立观察方向判定为不可见”；
- 审计信息仍能支持后台复核，但不占用正常用户阅读路径；
- 不可用模块不显示空图、全零图或误导性占位数字。

### GFA-14：质量、缺失和身份冲突始终失败关闭

- 缺槽、会话状态未知、前缀状态未知、AS 属性缺失和 AS_PATH 缺失分别保留语义；
- 同一页面的概览、趋势、列表和下钻必须属于同一事件窗口和同一冻结结果；
- 任何身份、窗口、统计人口或最终性冲突都阻止发布混合页面；
- 已完整发布的旧结果在新结果失败时保持可用，但不能被标成新结果；
- 错误状态使用用户可理解的说明，不泄漏凭据、服务器路径或内部堆栈。

### GFA-15：一次打开不会下载完整高基数矩阵

- 页面首开只取得完成首屏和趋势所需的有界数据；
- 受影响 AS 和路径关联下游支持稳定分页或按需加载；
- 页面不会因一次加载全部 AS×时间、前缀×方向或路径矩阵而超时、冻结浏览器或生成
  数十 MB 的默认响应；
- 翻页、筛选和下钻保持同一事件窗口与冻结身份；
- 数据规模增长不改变用户阅读顺序和字段语义。

### GFA-16：最终页面保持事实边界并完成核心用户任务

- 用户能够完成“判断前缀中断规模”“判断 AS 中断规模”“查看 IP 资源变化”
  “识别出事 AS 及性质”“查看路径关联下游”五类核心任务；
- 页面只陈述可由路由状态、会话观测、前缀、origin ASN、AS_PATH 和冻结 AS 属性
  直接支持的事实；
- 对原因、攻击、政策、设施故障、用户影响、客户依赖、责任和窗口外恢复保持未知或
  正确弃答；
- 同一冻结输入重复生成时，趋势、列表、排序、路径关系和数字一致；
- 伊朗与至少一个非伊朗事件通过同一合同验证，且不出现国家专用实现效果。

## 四、明确不产生的效果

本合同不得被解释为交付以下能力：

- 修改国家中断检测算法、阈值、首次检测时间或事件合并规则；
- 多 collector 选择、合并或交叉验证；
- DNS、HTTP、流量、Probe 或服务遥测融合；
- 全国断网、数据面不可达、用户或业务影响判断；
- 原因、攻击、政策、配置、设施故障、责任或传播因果；
- customer cone、商业关系或客户依赖推断；
- 历史正常带、季节性基线或窗口外恢复判断；
- 将新前缀作为固定 cohort 恢复量；
- 在正常前台展示审计台、原始 Prefix×VP 矩阵或完整 AS_PATH 大集合；
- 扩大 224-310 数据范围或把窗口外数据静默拼入事件。

## 五、不构成最终通过的情况

以下任一情况存在时不得宣告通过：

- 只换页面布局或文案，底层仍按 Prefix×VP 行数冒充唯一前缀数；
- 同一 peer ASN 的多个会话被重复算作多个独立方向；
- peer session down 后仍无条件沿用旧可见状态，或者把 session down 伪造成 WITHDRAW；
- 固定 cohort 仍冻结在 224 起点而不是事件首次中断前最后完整状态点；
- 新前缀抵消固定 cohort 中断或被写成事件恢复；
- AS 路由中断、受影响 AS 和旧 AS 中断表混用不同定义；
- IPv4 地址量因前缀重叠、观察方向或路径重复而重复计数；
- customer cone 或外部关系被包装成已观测下游；
- AS 详情页忽略事件窗口并退回最近 24 小时；
- 页面仍默认返回完整 AS×4,320 状态矩阵或数十 MB 响应；
- 缺槽、未知或身份冲突被补零、连线或静默拼接；
- 页面暗示全国断网、用户影响、原因、依赖、责任或完全恢复；
- 只通过文档、Hook、单元测试、API 200 或静态草图，没有同一候选的数据、接口和
  浏览器效果证据。

## 六、最终判定

- **通过**：GFA-01 至 GFA-16 全部具有同一候选版本的可复核证据，伊朗与至少一个
  非伊朗事件同时完成核心用户任务；
- **有条件通过**：没有已知偏离，但合同明确列出的外部验收条件尚未到期；
- **不通过**：任一到期要求失败，或通过删除、降低、改写本文规避失败；
- **未知**：证据缺失或无法重现；未知不得解释为通过。

本文不授权修改 `backend/core/`、执行原始数据扫描、RouteState 重放、数据库装载、
外部网络读取、付费模型调用或生产切换。任何阶段、Hook 或候选通过都不自动等于
已合并、已部署或生产最终效果通过。
