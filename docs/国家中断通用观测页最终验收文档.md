# 国家中断通用观测页最终验收文档

版本：1.0  
状态：最终效果合同  
适用对象：全部 `country_outage` 事件的数据 API 与事件详情页  
效果基线：现有伊朗国家中断数据观测页

## 一、文档目的

本文只规定最终用户、前端和 API 调用方能够观察到的效果，不规定内部模块、
数据库表、进程、编程语言或实施顺序。

最终目标是把当前伊朗国家中断页面从单事件特例变成全部国家中断事件共享的产品
能力，并允许不同事件在同一合同下具有不同的数据完整度。新数据到达时，已发布
事件能够持续向后追加；历史补正发生时，调用方能够识别 revision 变化。

本文不要求第一版让全部历史事件拥有与伊朗完全相同的数据深度，但要求所有事件
使用相同的身份、接口、缺失语义和页面框架。

## 二、最终用户效果

用户从任意合法国家中断事件进入详情页后，应当经历一致的阅读路径：

1. 识别国家、事件、观测范围、数据截止时间和数据状态；
2. 查看当前事件实际可用的国家状态、资源、报文和 ASN 数据；
3. 在新数据到达后看到时间线持续向后追加；
4. 在数据暂缺时看到断点和原因，而不是零值或恢复；
5. 在历史结果被补正时看到 revision 改变；
6. 在审计区域核对数据来源、统计人口、collector、mapping 和质量边界。

伊朗事件仍应保持当前完整观测能力，但不再拥有专用路由、专用接口或专用页面
代码。

## 三、最终效果要求

### GFA-01：任意国家中断事件进入同一详情体验

- 任意合法 `country_outage` 引用均由同一解析入口进入国家中断详情页；
- 国家代码、国家名称、事件身份和时间范围由数据决定；
- 页面不得因国家不同而切换到国家专用组件或国家专用 API；
- 不存在伊朗、巴西、中国或其他国家的硬编码展示分支；
- 非法引用与“合法但尚无增强观测”的事件具有可区分的响应。

### GFA-02：伊朗页面现有能力无损保留

- 伊朗事件仍能读取固定 cohort、Prefix×VP、ASN 状态、双栈分类、报文轨道、
  关键时间、质量与审计信息；
- 伊朗现有 60 个已发布状态点及其数值不得因通用化发生无说明变化；
- 伊朗事件的缺失、正常带不可用、窗口左删失和未确认恢复语义继续诚实展示；
- 通用化不得把伊朗页面降级为旧数据库摘要页。

### GFA-03：全部事件共享稳定的数据 API 形状

- 国家中断事件共享 overview、series、ASN 分页和 audit 四类能力；
- 相同语义使用相同字段、单位、时间格式和值状态；
- API 返回 schema version、revision、data through、publication state 和
  final state；
- 同一 revision 中，各接口返回的事件身份、cohort、时间范围和数据截止点一致；
- 新国家事件接入后，既有前端不需要增加国家专用解析逻辑。

### GFA-04：不同数据完整度通过能力声明诚实表达

- 每个事件明确声明自身可用能力；
- 能力至少能区分可用、构建中、不可用和不适用；
- 缺少 ASN 状态时，页面不显示空矩阵或全零矩阵；
- 缺少资源、Prefix×VP、双栈或审计数据时，相应区域隐藏或展示明确原因；
- 伊朗是首个数据最完整的事件，不是所有事件必须伪装达到的模板值。

### GFA-05：新数据正常到达时页面持续向后更新

- 活动事件的新观测按时间顺序追加，不重写已经确认不变的旧时间点；
- `data_through` 只表示已完整发布到所有相关接口的最新连续时间；
- 页面无需重新部署或更换 URL 即可读取新增数据；
- 同一正常追加过程中 revision 保持不变；
- 事件达到最终状态后，`is_final` 明确变化，页面停止把它描述为持续更新。

### GFA-06：一次更新时间在全部页面能力上保持原子一致

- overview、series、ASN 分页和 audit 不得分别停留在不同的已发布时间；
- 页面不会出现趋势图已更新、ASN 状态未更新但仍声明相同 `data_through` 的情况；
- 未完成的一次更新不得提前推进公开数据截止点；
- 前端刷新时要么看到上一完整状态，要么看到下一完整状态。

### GFA-07：缺槽、迟到和失败不会被解释成业务变化

- 缺槽保持断线或明确缺口，不得补成零；
- 暂时没有新文件不得解释为“无更新”“恢复”或“正常”；
- 迟到数据补齐后，调用方能够识别补正范围；
- 处理失败时保留最后一个完整 `data_through`，同时暴露处理状态；
- 未知、缺失、窗口外、解析失败和不适用具有不同语义。

### GFA-08：历史补正通过 revision 可见且可追溯

- 正常追加新时间点不产生新 revision；
- 已发布时间点因迟到数据、mapping、算法或源数据变化而重算时产生新 revision；
- 当前页面默认读取最新已发布 revision；
- audit 能说明 revision 的生成时间、替代关系和数据身份；
- 旧 revision 不得无痕消失或被静默覆盖。

### GFA-09：统计对象、人口和口径在所有国家保持一致规则

- Prefix、Prefix×VP、ASN、UPDATE 报文和资源等价值不得混称；
- 比例必须能识别分子、分母、collector、地址族和观测时间；
- cohort、mapping 与算法版本对调用方可见；
- 原报告、旧数据库和增强观测的不同口径可以并列，但不得相互覆盖；
- 单 collector 控制面观测不得外推为全国数据面或实际服务影响。

### GFA-10：大集合通过服务端分页和稳定筛选使用

- ASN 数据不得要求浏览器一次下载完整国家矩阵；
- 分页结果提供总量、页码、页大小和稳定排序；
- 筛选、搜索和排序在翻页后保持同一 revision 与时间范围；
- 缺少完整矩阵时不得返回其他事件或其他国家的数据占位；
- 数据规模增长不改变 API 基本形状和页面阅读方式。

### GFA-11：实时、历史和旧库数据在同一页面中可辨认

- 页面能够识别数据来自实时追加、历史重放、旧库兼容或混合来源；
- 数据来源差异不得改变相同指标的基本字段语义；
- 历史重放结果可作为实时流的起始数据，但不得伪装成实时采集；
- 旧数据库摘要可以作为基础能力，但不得冒充固定 cohort 状态；
- 用户能够识别当前事件的数据截止时间、最终性和证据等级。

### GFA-12：新增国家事件只增加数据，不增加国家专用代码

- 至少一个非伊朗国家事件能够通过相同页面和相同 API 合同展示；
- 接入该事件不需要增加国家专用前端组件、API 路由或字段解释；
- 该事件缺少的能力能够按 GFA-04 正确降级；
- 新观测追加后能够按 GFA-05 至 GFA-08 正确更新；
- 伊朗事件与新增事件同时通过桌面、移动端、API 和语义回归。

## 四、页面最终稳定结构

不同事件可以隐藏不可用区域，但可用区域的相对叙事保持一致：

1. 事件与观测身份；
2. 数据截止时间、revision、最终性和质量状态；
3. 国家状态与资源时间线；
4. UPDATE 活动时间线；
5. 地址族与 ASN 状态；
6. 分页调查入口；
7. 数据能力、缺失原因、来源和审计。

页面不得因为某个国家数据较少而用伊朗数字、空图、零值卡片或分析性文字填充
空间。

## 五、允许的数据完整度

所有合法事件至少属于以下一种可识别状态：

| 状态 | 用户效果 |
| --- | --- |
| `legacy_summary` | 展示旧库事件摘要，明确没有增强状态数据 |
| `aggregate_available` | 展示国家资源或报文聚合，不声称固定 cohort 状态 |
| `state_partial` | 展示部分增强状态，并标出缺失能力 |
| `state_complete` | 展示固定 cohort、国家状态和 ASN 状态 |
| `evidence_complete` | 在完整状态基础上提供可追溯证据入口 |

状态名称可以在最终合同中等价调整，但不同完整度必须可机读、可解释，且不得通过
零值伪装成完整。

## 六、不构成最终通过的情况

以下任一情况存在时，不得宣告最终完成：

- 仅把伊朗接口复制成多个国家专用接口；
- 只有伊朗事件可用，其他合法事件仍进入旧的空白详情页；
- 其他事件用全零 ASN、空 cohort 或伊朗数据占位；
- 新数据到达后必须重新部署前端或人工改代码；
- 不同接口公开不同 `data_through` 却没有能力或状态说明；
- 正常追加每五分钟都创建新 revision；
- 历史补正静默覆盖旧结果；
- 缺槽被连线、补零或解释为恢复；
- ASN 矩阵仍由浏览器一次性加载全部数据；
- 新增第二个国家时仍需修改国家专用代码；
- 为实现通用化削弱伊朗页面现有观测能力；
- 只完成 API 返回，不验证页面最终可读效果。

## 七、最终判定

- **通过**：GFA-01 至 GFA-12 全部具有可复核结果，伊朗与至少一个非伊朗事件
  同时通过，且活动事件完成一次正常追加验证；
- **有条件通过**：不存在已确认偏离，但部分外部数据尚未到期；必须明确未到期
  项目，不得把它们写成已通过；
- **不通过**：至少一项已确认偏离，或通过降低、删除、改写本文要求规避失败；
- **未知**：缺少判定证据；未知不得解释为通过。

本验收只判定国家中断通用观测页及其数据 API 的最终效果，不授权重构旧检测核心、
替换生产数据链路、执行历史全量重放或扩大到其他异常类型。
