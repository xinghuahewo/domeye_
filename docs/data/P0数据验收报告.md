# P0 数据验收报告

## 1. 验收结论

固定二三月数据档已达到 P0 历史数据兼容准入；事实、指标、缺失语义和质量证据可复核。全窗口原始证据仍未完成，RouteEvent 语义能力仅由明确选定的 pilot 验证，候选制品未执行生产激活。

本结论对应 `passed / legacy_compatible`，不等同于 `raw_traceable`，也不表示实时服务、生产数据库或生产前端已经切换。本轮遵循用户指定的资源边界：不重新执行真实全量 A/B；D2 只做一次最终全窗口生成，独立 A/B 仅抽取 64 个事件，D4 与 Metric 均只做一次最终生成。

### 5.2 RouteEvent 仅为 pilot

RouteEvent pilot 读取 1,200 条原始物理记录，展开为 2,392 条 RouteEvent，其中 announce 2,248、withdraw 144，IPv4 1,405、IPv6 987。制品明确标记 `pilot_only=true`、`production_complete=false`。它证明所选样本的解析、稳定 ID 和原始引用链可以工作，不证明全窗口语义解析、稳定 VP 或全量原始可追溯已经完成。

### 6.2 指标范围与缺失语义

10 个冻结 MetricSeries 共 169,920 个五分钟点，来源精确对账差异为 0，候选指纹为 `49fe2af2a4ce6dba26a7ab4e5b6a6c38fb9fd6c7d1d29ffedf13b8435c849f0b`。

首页使用的 BGP 指标中，每项 16,992 个槽：10,232 个有值，6,720 个 `source_unavailable`、34 个 `parse_failed`、6 个 `processing_gap`。所有缺口保持 `value=null`；前端折线使用 `connectNulls=false`，不会把缺测画成正常 0。

## 7. 可复现性与本轮资源边界

本轮没有重新执行真实全量 A/B，证据按以下分层保存：

| 维度 | 状态 | 证据解释 |
| --- | --- | --- |
| 全量 D2 | 单次最终生成 | 完整 1,171,464 Incident 制品与 SHA 闭包 |
| 有界 A/B | 64 个事件通过 | 两次执行的六个签名文件字节一致，候选指纹相同，稳定 ID Jaccard=1 |
| D4 | 单次生成 | 六类合同样本与跨层输入身份闭合 |
| Metric | 单次生成 | 10 项、169,920 点与来源精确对账 |
| `cross_run` | `partial` | 只覆盖 64 个事件，不外推到全量 |
| `full_semantic` | `not_run` | 没有全量第二次语义生成与比较 |

抽样 A/B 的两个目录、文件和 inode 均独立，执行 ID 与命令哈希不同；但证据明确记录 `cryptographic_independence_proven=false`，避免把“独立目录”误写成密码学独立执行证明。

## 11. 当前数据缺口

1. 6,720 个 UPDATE 槽与 70 个 RIB 槽没有源制品；
2. 34 个 UPDATE 槽与 3 个 RIB 槽没有通过压缩容器完整性准入；
3. RouteEvent 只有 pilot，没有全窗口语义解析、稳定 VP 和逐记录引用；
4. 绝大多数历史事实没有 VP 身份，不能做严格逐 VP 传播或恢复判断；
5. Evidence v2 只有六类各 1 个合同样本，不是全量事件证据；
6. 全量跨运行语义复现没有执行；
7. ASN/国家工作台中的部分旧指标仍是历史事实适配层，不得自动提升为 P0 MetricSeries；
8. `database.env` 的旧端口映射需要在独立配置治理任务中处理。

这些缺口已经进入 API 限制、质量报告、页面状态和发布元数据，不会被隐藏为 0、空数组或“正常”。

## 12. 发布状态

最终证据包安装到服务器 release 目录，但不创建或修改 `current` 等激活指针，不启动常驻候选 API，不替换现有前端。生产激活需要新的明确授权、不可变制品评审和回滚门禁，本轮不包含该授权。
