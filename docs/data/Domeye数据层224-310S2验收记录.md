逻辑边界固定为：

```text
S1 完整 RouteEvent
  ↓
唯一 RouteState
  Key = collector + VP/peer + prefix + address_family
  Value = 可见性 + origin ASN + AS_PATH/属性引用
          + 最后 RouteEvent/坐标 + 最后更新时间 + 质量状态

RouteState Checkpoint（同一状态的可恢复快照）
```

Prefix×VP 是 RouteState 主键的高基数维度，不是平级事实库。本阶段没有实现
Prefix×VP Evidence；S5 如需物化 Evidence，只能从指定 RouteState/Publication 派生。

## 三、唯一 RouteState 与 Checkpoint 效果

1. RouteState 只有一张按 `collector + peer IP/ASN + prefix + AFI` 寻址的 map；
2. Seed RIB 直接流式写入这张 map，不生成第二份 Seed 事件事实；
3. UPDATE 分区可并行解析，但只按 artifact index 和分区内 record/element 坐标严格顺序
   更新 RouteState；
4. 每次变更先移除旧状态摘要，再写入新值；withdraw 更新同一个键并把可见性设为 false，
   不写入另一套“不可见路由表”；
5. RouteState 值保存 origin、AS_PATH 内容摘要引用、属性摘要引用、最后 RouteEvent ID、
   artifact/record/element 坐标、事件微秒时间和质量状态；
6. Checkpoint 只是同一 RouteState 的 145 字节确定性记录编码，按 RouteState key
   排序并物化为 64 个 gzip shard；
7. Checkpoint 清单绑定来源 RouteEvent dataset/内容、实现提交、投影器、mapping、
   `processed_slot`、`data_through`、人口、质量人口、状态摘要和每个 shard 的 SHA-256；
8. 两段槽账本覆盖 1..2160 和 2161..4320，每条记录绑定来源分区内容、RouteEvent
   文件摘要、转移摘要、状态人口和双水位；缺槽、乱序、损坏或身份冲突均失败关闭。

机器合同为
[`rrc25-route-state-store.schema.json`](../../contracts/data/rrc25-route-state-store.schema.json)。
