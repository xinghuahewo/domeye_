
## 四、事件生命周期

### 4.1 正式事实

正式候选共保存 243 条不可变事件事实：

| 阶段 | 条数 | 语义 |
|---|---:|---|
| `detected` | 81 | 保留旧事件身份，并对齐到首个完整五分钟状态点 |
| `ongoing` | 81 | 检测后下一连续、质量 complete 的 RRC25 状态点 |
| `recovery_candidate` | 0 | 固定窗口没有可信正常带，不伪造候选 |
| `recovered_observation` | 0 | 没有可信正常带，不伪造恢复观测 |
| `final` | 81 | 224-310 固定观测窗口关闭，不等于恢复 |

每条事实保存前序 fact、观测时刻、`data_through`、检测器版本、S3 metric dataset、
metric slot SHA-256、当槽指标、质量和 limitation。243 个 fact ID 独立复算 mismatch=0；
事实 UPDATE/DELETE 均由不可变触发器拒绝。

### 4.2 状态机能力

状态机显式支持：

```text
detected → ongoing
ongoing → recovery_candidate
recovery_candidate → ongoing                 # 撤销恢复候选
recovery_candidate → recovered_observation   # 确认控制面恢复观测
recovered_observation → ongoing               # 后续再次异常
任一合法未终结状态 → final
```

`ongoing → recovered_observation` 的跳级为 false，`final → ongoing` 为 false。恢复候选、
候选撤销和观测恢复由同一事实模型支持，但正式 81 个事件没有可靠正常带，因此没有把
这些能力冒充为本窗口已经发生的事实。

## 十一、DLAE 判定

仍可按原 ID 读取。current 只指向 verified Publication，使用 expected version 原子推进，
禁止倒退，失败不改变上一个完整版本。

### DLAE-11：通过

5,701 个 Analysis Publication 与 Observation 分开推进并精确 `derived_from`；81 个
Observation 领先 Analysis 的中间状态由不可变指针审计保留，最终两者时间一致。正式
统一输出只能选择时间一致的组合，分析不会覆盖确定性观测。

## 十二、阶段结论与限制

S4 的入口、出口和 DLAE-09 至 DLAE-11 已由同一候选身份的文件、数据库、全量身份复算、
旧制品闭包、失败演练和来源不变证据闭合。S4 通过，S5 尚未开始。

本结论不说明：

- S5 的 4,320 点读模型、Prefix×VP Evidence、API、页面、报告快照或性能已完成；
- S6 的旧库影子迁移、双读对账、权限角色、回退或生产切换已完成；
- 当前生产页面已经读取 S4 候选；
- RRC25 控制面观测证明全国断网、用户影响、原因、攻击、责任或真实服务完全恢复。
