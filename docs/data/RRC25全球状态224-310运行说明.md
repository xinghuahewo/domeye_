# RRC25 2 月 24 日至 3 月 10 日全球状态运行说明

## 一、运行边界

- collector 始终为 `rrc25`；“全球”仅表示 RRC25 单采集器所见的 BGP 控制面状态。
- 输入窗口按 RIPE RIS 文件名的 UTC 日期冻结为半开区间
  `[2026-02-24T00:00:00Z, 2026-03-11T00:00:00Z)`。
- 使用 `bview.20260224.0000.gz` 建立一次全球 Seed RIB，随后严格应用
  4,320 个五分钟 UPDATE。
- 不连接或修改生产数据库，不修改 `backend/core/`，不切换生产运行时。
- 结果不证明全球互联网真实状态、用户影响、完整中断、原因或责任。

## 二、输入质量

旧原始制品集中有两个文件未通过 gzip 完整性校验：

- `updates.20260224.0840.gz`
- `updates.20260226.0635.gz`

运行不得覆盖这两个原文件。应在隔离输入目录下载同名 RIPE RIS 制品，完成
`gzip -t`、大小和 SHA-256 校验后写入本次 selection，并将
`repair_artifact_count` 固定为 `2`。其余文件使用已验证 artifact manifest 的
身份。运行时解析器会再次按 selection 中的大小和 SHA-256 流式核验全部输入；
任何缺槽、哈希变化、MRT 解析失败或槽内时间越界都会停止运行，不推进状态游标。

## 三、一次解析与可恢复产物

长窗入口为：

```text
tools/rrc25-iran-replay-go/cmd/rrc25-global-window
```

处理分为三层：

1. 每个 UPDATE 只解析一次，按稳定 RouteKey 写入 64 shard 的不可变
   RouteDelta spool；中断后会校验并复用已完成槽。
2. 单一全球 RouteState 严格按槽、record、element 顺序应用 RouteDelta；每天
   生成一个可独立恢复的完整 checkpoint，不保存每五分钟 5,000 多万行全状态。
3. 每五分钟生成所有固定国家/未知桶的紧凑摘要；摘要只保存国家、地址族、ASN
   和 Prefix×VP 计数及活动，不重复写出完整 ASN 列表。事件窗口的 ASN 明细应从
   最近 checkpoint 加 RouteDelta 定向重建。

紧凑 RouteDelta 包含状态计算所需的 VP、prefix、动作、origin 和稳定原始坐标，
但不包含完整 AS_PATH 和全部 BGP 属性。因此它可避免国家可见性等状态算法再次
解析 MRT，不能冒充未来路径分析所需的完整 RouteEvent 权威层。

## 四、运行命令

先执行无写入 preflight：

```bash
go run ./cmd/rrc25-global-window \
  --phase preflight \
  --raw-root /path/to/frozen-input \
  --selection /path/to/selection.json \
  --compatible-mapping /path/to/compatible-mapping.json \
  --revised-mapping /path/to/revised-mapping.json
```

正式运行使用 create-only 输出目录：

```bash
go run ./cmd/rrc25-global-window \
  --phase run \
  --raw-root /path/to/frozen-input \
  --selection /path/to/selection.json \
  --compatible-mapping /path/to/compatible-mapping.json \
  --revised-mapping /path/to/revised-mapping.json \
  --output /path/to/run-output \
  --workers 12 \
  --spool-shards 64 \
  --checkpoint-shards 64 \
  --checkpoint-slots 288
```

同一运行失败后，只能对同一输入、mapping 和输出目录增加 `--resume`。恢复会
验证既有 RouteDelta 和最新日 checkpoint，不重新读取已完成阶段的原始文件。

## 五、完成条件

只有同时满足以下条件，才能把运行标记为完成：

- `COMPLETE.json` 存在且 `processed_update_count=4320`；
- `data_through=2026-03-11T00:00:00Z`；
- 15 个 UTC 日摘要和 15 个日质量分区完整；
- 最终 checkpoint 可独立恢复，RouteState 人口和状态摘要一致；
- 全部槽均有连续输入，所有国家/未知桶逐槽满足人口守恒；
- 原始坏文件、生产数据库、生产发布目录和 `backend/core/` 均未被修改。
