## 4. 数据库仍不能回答的字段

- 稳定 collector、VP、peer IP 和同快照观测人口；
- 支持结论的具体 MRT record、element、文件哈希和 raw 引用；
- 国家级异常前、中、后的完整逐 VP 路由状态；
- 精确传播范围和逐前缀恢复过程；
- 前兆是否导致后续中断；
- 物理断线、流量影响、主动行为或政府意图。

旧 AS/Prefix 事实存在 `pre/eve` AS_PATH 快照，但没有稳定 VP 和 raw 坐标，
`next` 恢复快照覆盖也不足，因此只能作为 legacy 路径旁证。
