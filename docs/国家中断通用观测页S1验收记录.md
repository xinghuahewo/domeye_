## 一、本阶段结论

S1 已对 81 个旧国家中断事件冻结首次检测前最后一个完整五分钟状态点、事件前
固定 cohort 和预期独立观察方向。同一 peer ASN 的多个会话只形成一个独立方向；
选中前缀在冻结点被 RRC25 看到的所有 peer ASN 方向均进入分母，不因该方向当时看到
不同 origin 或 origin 未知而被删除。

会话状态只作为独立的可观测性事实，不会把 peer down 写成 WITHDRAW，不会用会话事实
覆盖路由事实。RouteState 仍是唯一状态事实，cohort 只是指定 RouteState 冻结点的事件
人口和下钻证据，不是第二套状态层。

## 六、边界回检

S1 只交付会话事实、生命周期边界和事件前 cohort：

- 不改变国家中断检测结果、首次检测时间、结束事实、事件 ID 或合并规则；
- 不生成 S2 的前缀、AS、IP 五分钟分类与趋势；
- 不生成路径关联、Publication、API 或页面，不改动 PostgreSQL 和生产环境；
- peer ASN 是分母方向，peer IP/完整会话身份只用于方向内的实际可观测性；
- 新出现的前缀或方向不改变已冻结 cohort 分母，交由 S2 以独立轨道处理。
