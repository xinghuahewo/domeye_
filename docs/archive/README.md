# 文档归档索引

本目录保存已经从当前开发入口移出的旧设计、旧计划、历史验收记录和数据证据。正文原则上保持原样，归档不等于删除，也不等于当前能力仍然有效。

## 归档区

- [Agent 历史材料](agent/README.md)：W6 讨论包、旧 P0/P1/P2 计划与合同、旧 Agent 认证和运维记录。
- [Core 历史材料](core/README.md)：旧事件详情页、通用观测页、趋势分析、伊朗页面和前端叙事。
- [数据历史材料](data/README.md)：旧数据层、INFO 落库、P0 数据基础、RRC25 重放和历史数据证据。

## 使用规则

1. 归档文档只回答“过去的设计或某个历史 Candidate 当时怎样”，不能覆盖当前架构和首片合同。
2. 归档文件名中的“最终验收”“生产”或“已认证”只绑定其原始 Candidate、数据身份和时间。
3. 需要恢复某条旧规则时，先在当前架构下建立新的边界、合同和验收任务；不要直接把归档文件重新当作生产入口。
4. 当前新增文档不得放回归档目录以逃避状态说明；应在正文写清 `Designed`、`Implemented`、`Verified` 或 `Released` 的对象和证据。
