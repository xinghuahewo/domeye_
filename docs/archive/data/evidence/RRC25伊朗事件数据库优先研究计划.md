# RRC25 伊朗事件数据库优先研究计划

## 1. 决策

本事件不再以“先重放完整研究窗口”为默认路线。

执行顺序调整为：

1. 先从现有独立数据库冻结事件事实、国家五分钟曲线、ASN/前缀影响和恢复信号；
2. 逐项标记数据库可以回答、只能有限回答和不能回答的字段；
3. 仅针对证据缺口处理关键事件槽和少量代表实体；
4. 不启动 1,928 个 UPDATE 槽的全窗口重放。

旧项目 `/home/bgpdata/Domeye` 保持只读；研究代码不修改 `backend/core/`，不写数据库，
不修改前端，也不部署生产。

## 2. 时间和口径

数据库业务时间是 `timestamp without time zone`，本研究统一按北京时间
`Asia/Shanghai` 解释，并同时输出对应 UTC。不能依赖数据库会话时区自动换算。

| 名称 | 北京时间 | UTC | 语义 |
| --- | --- | --- | --- |
| 旧检测器起点 | `2026-02-27 09:12:32` | `2026-02-27 01:12:32Z` | 旧记录首次触发时间 |
| 研究窗口起点 | `2026-02-28 00:00:00` | `2026-02-27 16:00:00Z` | 用户批准的最早研究边界 |
| 候选早期扰动 | `2026-02-28 06:35` 左右 | `2026-02-27 22:35Z` 左右 | 可描述为前兆候选，不能写成因果前兆 |
| 第一显著波次 | `2026-02-28 17:00–18:45` | `2026-02-28 09:00–10:45Z` | 更新量、前缀和 AS 中断集中出现 |
| 第二显著波次 | `2026-02-28 22:25–22:34` | `2026-02-28 14:25–14:34Z` | IPv4 等效地址达到更低点 |
| 旧摘要刷新时刻 | `2026-02-28 22:34:40` | `2026-02-28 14:34:40Z` | `event_info` 中的当前描述时刻，不等于 `s_time` |
| 观察结束 | `2026-03-06 16:40:00` | `2026-03-06 08:40:00Z` | 半开研究窗口终点 |

旧记录把首次触发时间保存在 `s_time`，后续又用新时刻和新最大集合覆盖
`event_info/outage_ases`。两者相差 134,528 秒，必须拆成独立时间锚，不能继续把
整行解释为同一时刻的快照。

## 3. 已由数据库确认的研究主体

### 3.1 数据覆盖

- `feature_country(source='r', country='伊朗')` 在研究半开窗口内有
  `1,928/1,928` 个五分钟槽；
- 缺槽为 `0`，五项指标 SQL NULL 均为 `0`；
- 此处只说明国家指标层完整，不证明逐 VP、逐前缀原始观测完整；
- `feature_other_YYYYMM` 是 ASN 活动稀疏表，缺行表示该 ASN 当槽没有落活动记录，
  不能解释为路由不可见或数据缺失。

### 3.2 国家事实

旧 `country_outage_202602` 事实为：

| 字段 | 值 |
| --- | --- |
| 国家 | `IR / 伊朗` |
| 风险 | `high` |
| 最大受影响 ASN | `176` |
| 总 ASN | `556` |
| 保存比例 | `0.317` |
| 受影响集合 | 176 个 ASN |
| 结束时间、持续时间 | 未保存 |

在 `2026-02-28 22:34:40+08:00` 重新查询当时仍活跃的事实：

- 活跃 AS 中断集合为 176 个 ASN；
- 与国家事实 `outage_ases` 的 176 个 ASN 完全一致，双向差集均为 0；
- 活跃前缀中断集合为 2,842 个前缀；
- 176 个 ASN 中，97 个 AS 的旧事实最大前缀中断比例为 `1.0`，79 个为部分中断
  （`0.205–0.986`）。

这能对账旧检测器在该时刻保存的影响集合，但不能恢复集合的生成算法、阈值版本和
同快照 VP 分母。

### 3.3 指标时间线

以前六小时 IPv4 等效地址中位数 `10,146,432` 为本次数据库对账基线：

| 阶段 | 数据库观测 |
| --- | --- |
| 候选早期扰动 | `06:35` 五分钟桶新增 63 个前缀中断，涉及 3 个 ASN；`06:40` 低点的 IPv4 等效地址较基线下降约 `0.675%` |
| 第一显著波次 | `17:00–19:00` 的 ANNOUNCE/WITHDRAW 为 `4,354,758 / 210,811`；`18:45` 单桶新增 1,015 个前缀中断和 99 个 AS 中断；低点较基线下降约 `3.667%` |
| 第二显著波次 | `22:30` 单桶新增 67 个前缀中断和 2 个 AS 中断；IPv4 等效地址降至 `9,569,024`，较基线下降 `5.691%` |
| 部分恢复信号 | 按“连续 6 槽达到基线 99%”规则，首次出现在 `2026-03-01 22:00+08:00` |
| 后续观察 | `2026-03-03 08:35` 为基线 `99.542%`；半开窗口最后一个已纳入槽 `2026-03-06 16:35` 为 `99.010%` |

因此，报告中的“约 6% IPv4 下降”可由数据库指标支持。报告的 `16:14` 时间主张
不能直接沿用：数据库 `16:15` 的 IPv4 信号仍为基线的 `99.956%`，需要修订，
或明确其来自其他 Collector/时区/指标。

IPv4 值是 `/24` 等价值乘以 256，不是独立计算的原始地址并集；IPv6 值是 `/48`
等价值。二者不得相加、取最大值或直接比较损失规模。

## 4. 数据库可回答与真实缺口

| 研究问题 | 当前状态 | 使用方式或限制 |
| --- | --- | --- |
| 何时首次被旧检测器记录 | 可回答 | `country_outage.s_time` |
| 何时刷新到当前摘要 | 可回答 | 从 `event_info` 提取独立时间锚，禁止覆盖起点语义 |
| ANNOUNCE/WITHDRAW 变化 | 可回答 | `feature_country` 五分钟序列 |
| IPv4 `/24`、IPv6 `/48` 等效资源变化 | 可回答 | 分开报告单位和基线 |
| 风险等级、最大 ASN 数和保存集合 | 可回答 | `country_outage` |
| 关键时刻活跃 ASN/前缀规模 | 可派生 | 用 AS/前缀事实的半开活动区间查询 |
| 旧 AS_PATH 前/中快照 | 有限可用 | 事实表保存时间到 AS_PATH 集合，但未保留稳定 VP |
| 每个观测点具体看到了什么 | 缺失 | 无 peer IP、稳定 VP ID 和完整同快照人口 |
| 哪条原始 BGP 报文支持结论 | 缺失 | 无 artifact/file SHA、record ordinal/offset/hash |
| 国家级异常前/中/后完整路由状态 | 缺失 | 国家事实没有阶段字段，AS 的 `next_vp_paths` 全为空 |
| 精确传播范围和路由级恢复过程 | 缺失 | 需要带 VP 的 RouteEvent 和定向状态重建 |
| `199/595、73/126` | 当前不能复现 | 当前库为 `176/556`，且 22:34 活跃 AS 事实为 `97/79` 全部/部分 |
| 前兆是否导致主事件 | 不可验证 | 只能描述时间先后和指标相似性 |
| 物理断线、流量影响、政府意图 | 超出数据能力 | 需要会话、流量、主动测量和外部证据 |

目标日的旧阶段路径并非全部物理缺失：伊朗有 203 条 AS 中断、1,897 条前缀中断
事实，其 `pre/eve` 外层对象均有内容。但是 AS 的 `next` 203 条全部为空；前缀
`next` 有 257 条为空，并且与 257 条未结束记录一致。它们只能作为 legacy path
snapshot，不能冒充完整三阶段或 VP 证据。

## 5. 最小原始证据请求

数据库主线冻结后，原始数据只补以下问题：

1. 关键槽内是否存在支持数据库中断事实的 WITHDRAW/ANNOUNCE；
2. 少量代表 ASN/前缀在异常前、中、后的 RRC25 VP 可见状态；
3. 原始文件、record、element 和 RouteEvent 的稳定引用；
4. 数据库旧 AS_PATH 快照与 RRC25 原始记录是否一致。

### 5.1 事件槽

| 证据包 | 北京时间 | UTC 建议窗 | 目标 |
| --- | --- | --- | --- |
| `precursor_candidate` | `06:35` | `[2026-02-27T22:30Z, 22:45Z)` | 验证短时 63 前缀扰动，不判断因果 |
| `main_wave_1` | `18:45` | `[2026-02-28T10:35Z, 11:00Z)` | 验证 1,015 前缀、99 AS 集中中断槽 |
| `main_wave_2` | `22:30` | `[2026-02-28T14:20Z, 14:45Z)` | 验证最低点及旧摘要刷新前后的记录 |

每个进程仍限制在 10 分钟内。先只解析上述 UPDATE 槽；只有代表实体需要前后状态时，
才读取相邻 RIB 并对目标 ASN/前缀做 allowlist 过滤。不得恢复成 1,928 槽全窗口回放。

### 5.2 代表实体

首轮只取能够覆盖不同现象的少量样本：

- 完全中断：`AS48715`（旧事实 76/76 前缀）；
- 大型部分中断：`AS42337`（468/761 前缀）；
- 末波接近完全中断：`AS39501`（72/73 前缀）；
- IPv6 `/29` 等效跳变候选：`AS61008`；
- 再从 176 个集合中按确定性规则选择一个长期未结束样本。

样本只能用来验证证据链，不得外推成全部 176 个 ASN 的完整 VP 结论。

## 6. 验收

数据库阶段通过条件：

- reader 身份、`REPEATABLE READ READ ONLY`、零写权限和最终 rollback 有收据；
- 研究窗口 `1,928/1,928` 槽闭合；
- 国家事实 176 ASN 与 22:34:40 活跃 AS 集合双向对账；
- 关键波次、约 6% 下降、恢复信号均可从冻结查询复算；
- 每个输出值都带表、字段、时间窗、单位和缺失语义；
- 报告主张被标为 `confirmed/revised/unverifiable/hypothesis_only`。

原始证据阶段通过条件：

- 三个关键槽各有独立、带哈希的 evidence sidecar；
- 至少覆盖一个完全、一个部分、一个 IPv6 和一个未恢复代表实体；
- 原始引用能回查到确切 MRT 文件与 record/element；
- 不把样本结果提升为全国因果或政治结论；
- 未启动完整 1,928 UPDATE 重放。
