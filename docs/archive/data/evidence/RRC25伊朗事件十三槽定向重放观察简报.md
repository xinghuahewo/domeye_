# RRC25 伊朗事件十三槽定向重放观察简报

## 1. 结论

本次对 13 个固定 UPDATE 槽进行了定向消息解析，共保留 1,923 条 RouteEvent，
覆盖 89 个 VP 身份。观察到的核心现象是：

1. 在主异常之前的候选窗口，AS61008 的 IPv6 前缀已经出现大量宣告与撤回交织；
2. 第一主窗口仍以 AS61008 的 IPv6 路由变化为主；
3. 第二主窗口同时出现 AS61008 IPv6 和 AS39501 IPv4 的集中变化，撤回消息占比
   明显升高；
4. 第二主窗口的匹配消息集中在前 10 分钟，随后迅速稀疏，但这不能单独证明恢复；
5. AS48715 在固定窗口内没有命中消息，不能据此判断其不可见、正常或已经恢复。

本次结果是消息级定向观察，不是基于 RIB 的路由状态回放，不能直接证明国家中断、
完整传播范围、前兆因果或完全恢复。

## 4. 分阶段现象

| 阶段 | 消息数 | A / W | W 占比 | VP | 主要现象 |
| --- | ---: | ---: | ---: | ---: | --- |
| 前候选窗口 | 852 | 779 / 73 | 8.6% | 47 | AS61008 IPv6 已出现高频复宣告和撤回 |
| 第一主窗口 | 640 | 580 / 60 | 9.4% | 45 | AS61008 IPv6 震荡持续，AS42337 仅出现 1 条撤回 |
| 第二主窗口 | 431 | 319 / 112 | 26.0% | 86 | AS39501 IPv4 与 AS61008 IPv6 同时活跃，撤回占比升高 |

第二主窗口的样本组成与前两个窗口不同，因此 26.0% 不能直接解释为全国撤回率升高。
但它能够说明：在该定向样本中，22:20–22:30 的宣告与撤回交织程度明显增强。

第二主窗口内：

- 22:20–22:25 两槽记录了 430 条匹配消息；
- 22:30 槽只剩 1 条 AS39501 撤回；
- 22:35 和 22:40 两槽没有目标前缀命中。

这表现为一次短时、集中、随后快速稀疏的路由更新过程。消息停止可能来自收敛、
观测变化或没有新的 UPDATE，不能等价为前缀已经恢复可见。

## 6. 能够与不能得出的结论

可以确认：

- 主异常前已经存在目标 IPv6 前缀的高频消息变化；
- 两个主窗口都存在宣告与撤回交织；
- 第二主窗口出现了更高的定向样本撤回占比；
- AS39501 的变化具有多 VP、短时间集中爆发特征；
- 每条保留消息均可回查到 artifact、文件哈希、record ordinal 和 element ordinal。

当前不能确认：

- 前候选窗口是否导致了后续国家中断；
- 无 UPDATE 是否表示路由不可见或已经恢复；
- 这些代表前缀能否外推到伊朗全部 ASN 和前缀；
- `199/595`、`73/126` 或数据库 `176/556` 哪一组代表同快照真实状态；
- 全国传播范围、业务流量影响、物理原因或政府意图。
