# RRC25 伊朗同期全局状态重放最终验收文档

版本：1.0  
状态：最终效果合同  
适用对象：RRC25 伊朗事件同期的全球路由状态、国家投影和通用国家中断数据底座  
效果基线：已验收的伊朗 18:05–23:00 固定 cohort 状态页

## 一、文档目的

本文只规定最终调用方、数据验收者和国家中断页面能够观察到的效果，不规定内部
模块、编程语言、线程模型、数据库表或具体实现顺序。

目标是在与伊朗事件完全相同的 RRC25 输入和时间范围内，将原先“完整读取全球
RIB、只保留伊朗状态”的重放升级为一次全球状态重放。RIB 只初始化一次，
84 个 UPDATE 只形成一条有序更新流，各国家状态由同一份全球路由状态投影得到，
不再为每个国家单独读取 RIB 或重放原始 UPDATE。

本合同中的“全球”只表示 **RRC25 在固定时间窗口内可见的完整 BGP 控制面状态**，
不表示全球互联网真实可达性、数据面连通性、用户体验或国家级服务影响。

## 二、冻结输入与时间

最终验收只允许以下输入：

| 输入 | UTC 范围 | 北京时间 | 数量 |
| --- | --- | --- | ---: |
| Seed RIB | `2026-02-28 08:00` | `2026-02-28 16:00` | 1 |
| Catch-up UPDATE | `[08:00, 10:05)` | `[16:00, 18:05)` | 25 |
| 正式 UPDATE | `[10:05, 15:00)` | `[18:05, 23:00)` | 59 |
| UPDATE 合计 | `[08:00, 15:00)` | `[16:00, 23:00)` | 84 |

冻结 RIB 为：

```text
/home/bgpdata/data/ripe/rrc25/2026.02/bview.20260228.0800.gz
```

正式状态输出为北京时间 18:05 的窗口起点状态，加 59 个正式 UPDATE 槽末状态，
共 60 个状态点；最后状态时间为北京时间 23:00，即 UTC 15:00。

输入文件的路径、大小、SHA-256、槽时间和角色必须进入可复核清单。任何输入替换
都属于另一数据集或新 revision，不得静默沿用本合同结论。

## 三、最终使用效果

验收完成后，数据调用方应当能够：

1. 查看一次全球 RIB 初始化后形成的 RRC25 路由状态人口；
2. 查看全部可归属国家及显式未知桶的固定 cohort；
3. 对任意具有非零 cohort 的国家读取 60 个同时间轴状态点；
4. 查看国家 Prefix×VP、origin ASN、IPv4/IPv6 和 UPDATE 活动；
5. 查看国家内 ASN 的全可见、部分可见、全不可见和未知状态；
6. 使用同一数据包无损复现已验收的伊朗页面；
7. 将终点 checkpoint 作为后续增量 UPDATE 的起始状态，而不重新读取 RIB；
8. 点击任意合法 `country_outage` 事件后进入同一通用页面，并读取该事件对应
   国家、collector、时间窗口和 revision 的数据；
9. 在审计区域核对输入、mapping、人口守恒、处理游标、缺失和质量状态。

## 四、最终效果要求

### GSR-01：输入身份和范围唯一

- 只消费冻结的 1 个 RIB、25 个 catch-up UPDATE 和 59 个正式 UPDATE；
- 84 个 UPDATE 连续、无重复、无错位，角色和槽时间与冻结清单一致；
- 所有消费输入具有可核对的路径、压缩字节、SHA-256 和处理结果；
- 不读取 UTC 08:00 之前或 15:00 之后的 MRT 数据；
- 输出能够唯一指向本次输入集合和运行身份。

### GSR-02：RIB 形成完整的 RRC25 全球初始状态

- RIB 中获准的 IPv4/IPv6 unicast physical record、peer、prefix 和路径均被完整
  处理；
- 状态不再以 IR 或任何国家作为预筛条件；
- 所有可物化路由使用 `collector + VP + AFI/SAFI + canonical prefix` 唯一标识；
- 多条记录指向相同状态键时使用确定性顺序得到唯一结果；
- 未知 origin、AS_SET、confederation、mapping 缺失和不支持记录分别计数，不得
  静默丢弃或归入某个国家。

### GSR-03：84 个 UPDATE 只形成一条确定性状态流

- 每个 UPDATE physical record 和 RouteEvent 只被解析、识别和应用一次；
- 状态应用严格保持槽时间、原始 record 和 element 的确定性顺序；
- 同一输入重复运行得到相同的末状态、槽状态和内容哈希；
- 并行解析不得改变共享状态键的应用顺序；
- 任意国家结果都来自该共享状态流，不存在国家专用 UPDATE 重放分支。

### GSR-04：国家落位语义显式且版本化

- 国家归属只表示路由 origin ASN 的映射结果，不表示 AS_PATH 经过国家；
- seed RIB 中可唯一解析的 origin ASN 使用同一冻结 mapping 归属国家；
- mapping 版本、来源、生成时间和未知数量对调用方可见；
- 无法唯一确定 origin 或国家的路由进入明确的未知或歧义桶；
- UPDATE 改变 origin 时，旧状态归属的移除和新状态归属的加入均可对账。

### GSR-05：每个国家具有固定且可审计的 cohort

- 每个国家的固定 cohort 由同一 seed RIB 和同一 mapping 冻结；
- cohort 明确区分 Prefix、Prefix×VP、origin ASN 和地址族人口；
- 正式窗口内分母保持不变，新出现的动态路由不得悄悄改变固定人口；
- cohort ID、人口哈希、seed 时间和 mapping 版本可读取；
- cohort 为零或不存在时返回明确不可用状态，不伪造零值完整页面。

### GSR-06：所有国家共享完整的 60 点时间轴

- 正式窗口起点和 59 个槽末形成严格递增的 60 个状态时间；
- 全部国家状态使用同一 UTC、北京时间和五分钟槽边界；
- 每个状态点能够区分 observed、缺槽、处理失败和不适用；
- 末状态时间严格为 `2026-02-28T15:00:00Z`；
- 不以窗口外数据补写开始、恢复或结束状态。

### GSR-07：全球、国家和未知桶满足人口守恒

- 全球固定 cohort 等于全部国家 cohort 与显式未知桶之和；
- 每个国家每槽满足可见与不可见 Prefix×VP 人口闭合；
- 每个国家每槽的 ASN 分类与固定 ASN 人口闭合；
- IPv4、IPv6、双栈和未知地址族口径能够分别核对；
- 任一守恒式不成立时不得发布完整结果。

### GSR-08：跨国家状态迁移和撤回不产生重复或残留

- ANNOUNCE 新建、替换和 WITHDRAW 删除使用路由键中保存的上一状态；
- origin 国家发生变化时，旧国家和新国家的增量同时正确更新；
- WITHDRAW 不依赖报文中重新推断一个可能不同的国家；
- 重复报文、无现存状态的撤回和不支持事件分别计数；
- 单槽增量与槽末全量对账结果一致。

### GSR-09：伊朗结果与现有验收基线无损一致

- 伊朗固定 cohort 仍为 563 个 origin ASN、384,767 个 Prefix×VP；
- IPv4 Prefix×VP 为 383,804，IPv6 Prefix×VP 为 963；
- 60 个状态点、各槽国家状态、ASN 分类和 UPDATE 活动与现有验收包逐项一致；
- 差异必须具有可定位的输入、mapping 或算法原因；无说明差异视为失败；
- 全球化不得降低伊朗页面的质量、缺失和审计语义。

### GSR-10：非伊朗国家无需专用重放即可读取

- 所有具有非零固定 cohort 的国家都产生同合同的数据切片；
- 至少选择一个大 cohort、一个中等 cohort 和一个小 cohort 非伊朗国家进行
  数值与页面消费验收；
- 选择样本只影响验收覆盖，不影响其他国家数据是否生成；
- 不为样本国家增加国家代码分支、专用输入清单或专用字段；
- 同期没有真实国家中断事实时，只展示状态验收视图，不伪造业务事件。

### GSR-11：checkpoint 恢复与重复运行结果确定

- RIB 完成、catch-up 完成和正式窗口处理进度均具有可识别 checkpoint；
- 从中间 checkpoint 继续到 23:00，与从 RIB 连续运行到 23:00 的结果一致；
- 已完成槽不会被重复应用，恢复后处理游标单调前进；
- checkpoint 绑定输入、mapping、状态人口和内容哈希；
- 损坏、错配或来自其他运行的 checkpoint 必须被拒绝。

### GSR-12：缺失、损坏和失败保持失败关闭

- RIB 或 84 个 UPDATE 任一缺失、重复、错位、损坏或哈希不符时不发布 COMPLETE；
- 解析失败、unsupported、mapping unknown 和 source unavailable 具有不同状态；
- 最后完整 `data_through` 不因失败或尚未完成的槽提前推进；
- 已完成 checkpoint 和失败原因保留，可用于同一运行恢复；
- 不把未知、缺失、失败或窗口外解释为零、正常、恢复或未发生。

### GSR-13：交付包具有完整审计和可复现身份

- 交付包公开 schema、run ID、dataset ID、revision、mapping、算法和引擎版本；
- 输入清单、RouteEvent 计数、状态人口、国家人口、未知桶和质量门可查询；
- 关键输出具有 SHA-256，COMPLETE 只能引用已经核验的不可变文件；
- 抽样状态能够追溯到 route key、状态时间和输入记录身份；
- 原始 MRT 只读，不写旧数据库，不静默覆盖既有伊朗交付包。

### GSR-14：数据可直接接入通用国家观测与后续增量流

- 国家切片能够被现有 overview、series、ASN 分页和 audit 合同消费；
- 任意合法 `country_outage` 事件都通过同一事件解析和页面路由进入通用国家
  观测页，不因国家不同增加专用路由、组件或字段；
- 页面实际读取的 country、collector、窗口、cohort、revision 和 data_through
  均来自事件身份与数据合同，不得沿用伊朗默认值；
- 某项能力尚不可用时显示明确缺失或隐藏对应区域，不得用零值、伊朗数据或其他
  国家数据填充；
- 数据来源明确标记为历史全球重放，不伪装成实时采集；
- 伊朗和非伊朗验收样本使用同一页面与字段语义；
- 23:00 终点 checkpoint 包含后续有序 UPDATE 接续所需的状态和游标；
- 从该 checkpoint 至少追加一批时间连续的新 UPDATE，接续过程不得重新读取
  RIB；
- 新批次完整处理后，受影响国家的 data_through 单调推进，页面能够读取新增
  时间点；未受影响国家仍共享相同处理截止点；
- 生产实时切换仍需独立授权和验收，不得将一次接续验证写成生产实时已上线。

## 五、最终交付效果

最终结果至少包含可独立核验的：

- 冻结输入 manifest；
- 全球 RouteState checkpoint 身份；
- 国家 cohort 目录及未知桶；
- 60 点全球摘要；
- 60 点国家状态和国家内 ASN 状态；
- UPDATE 活动与状态迁移质量报告；
- 伊朗逐槽对账报告；
- 非伊朗大、中、小 cohort 样本报告；
- checkpoint 恢复与确定性报告；
- API 消费包、哈希清单和 COMPLETE 标记。

具体文件名和存储格式可以在实施中选择，但上述效果和身份不得缺失。

## 六、不构成最终通过的情况

以下任一情况存在时不得宣告完成：

- RIB 仍只保留伊朗或少数国家状态；
- 每个国家分别解析 RIB 或重放 UPDATE；
- 84 个 UPDATE 被多个国家任务重复应用；
- 无法说明 country mapping、未知 origin 或 AS_SET 的处理；
- 国家人口之和与全球人口不闭合；
- 动态 UPDATE 悄悄改变固定 cohort 分母；
- WITHDRAW 在错误国家留下残余状态；
- 伊朗 60 点或 cohort 出现无说明差异；
- 只有三个验收国家有数据，其他国家未生成；
- 缺槽或失败被写成零值、恢复或正常；
- checkpoint 恢复与连续运行结果不同；
- 只有聚合 CSV，没有可接续的末状态和处理游标；
- 只能直接打开国家状态地址，无法从合法 `country_outage` 事件进入同一页面；
- 新 UPDATE 已处理，但 data_through 或页面时间序列没有随之更新；
- 用同期状态验收样本伪造真实国家中断事件；
- 仅有脚本退出码，没有 API、页面、数值和审计效果验收。

## 七、最终判定

- **通过**：GSR-01 至 GSR-14 全部具有当前运行的可复核证据；
- **有条件通过**：没有确认偏离，但明确列出的外部验收条件尚未到期；
- **不通过**：任一到期要求失败，或通过删除、降低、改写本文规避失败；
- **未知**：证据缺失或无法重现；未知不得解释为通过。

本合同不授权扩大时间范围、增加 collector、覆盖生产数据、修改旧 Detection、
执行生产实时切换或把控制面结果解释为国家数据面和服务影响。
