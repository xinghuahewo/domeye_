# 国家中断趋势分析 S6 最终验收报告

## 一、结论

S6 隔离候选达到《国家中断趋势分析最终验收文档》定义的最终效果：TAE-01..TAE-15 均有同一候选上的可复算证据，数据、API、页面、报告、QA、Markdown、PDF、JSON 下载与 Value Gate 共同绑定以下身份：

- `product_id`：`trend_product_v1_4a62c0d73936f3b6174bc0493b1803fd`
- `graph_id`：`evidence_graph_v1_405fd628b95d954da40568c196a3976a`
- Python 规范 JSON SHA-256：`721da778b9aabac9c275012b858e42db637b65efd9a8ad09195b9dc4c152da22`
- Sidecar 规范 JSON SHA-256：`69c98516a5bf1d49576234da2d97fb5389fe92005cbcdd6de96259fbe83ed48b`
- 快照：`incident_trend_s1_synthetic / publication_trend_s1_synthetic / revision 1 / data_through 2000-01-01T00:55:00Z / rrc25`

两个 SHA-256 使用不同语言的既有规范 JSON 实现，因此摘要不同；反序列化后的 JSON 对象、`product_id`、`graph_id`、Claim、Evidence、Limitation、Unknown 和数值逐字段相同。验收以内容对象与各自冻结的规范化算法为准，不把跨语言摘要格式差异解释为事实差异。

S6 是验收阶段号，不是新的业务 Schema 名称。当前制品和 QA 规则仍标记为 `s5_v1`，原因是该候选尚未发布，S6 的排序、中文显示词和语义键修正属于首次候选封版前的失败关闭；若 `s5_v1` 已经对外发布，则这些变化必须升级版本，不能原地覆盖。

本结论只证明隔离候选满足 RRC25 BGP 控制面趋势分析效果合同，**不是生产部署**，不代表生产流量、配置或运行版本已经切换。

## 二、验收范围与不可越过边界

本次只验收：

- 单一 collector：`rrc25`；
- 固定窗口、固定发布、固定 revision 和固定数据截止；
- 确定性 TrendProfile、阶段、账本与组合算子；
- Evidence Graph v1；
- 页面、报告、QA 与下载对同一制品的消费；
- 正确弃答与增量价值。

本次不验收，也不允许输出：

- 多 collector 融合；
- DNS、Traffic、Probe、HTTP 或其他外部证据；
- 历史正常带；
- Hypothesis、原因、攻击、责任、因果或用户影响判断；
- 窗口结束后的完全恢复判断；
- Network RCA；
- 数据库重建、冻结核心修改或生产切换。

每条 Claim 均同时绑定：

## 七、正确弃答与 Value Gate

### 7.2 增量价值

冻结的 8 个陌生组合问题只评价既有事实与白名单算子的组合覆盖，不评价自由推理：

- B0 = 0%；纯确定性静态报告不覆盖组合追问；
- B1 = 25%；固定 QA 覆盖最快变化和地址族对照；
- B2 = 100%；当前受限语言/算子层覆盖 8 个组合问题；
- 数值准确率 = 100%；
- 阶段边界一致率 = 100%；
- Claim-Evidence 一致率 = 100%；
- 正确弃答率 = 100%；
- 核心任务完成率 = 100%；
- 证据覆盖率 = 100%。

本次不使用耗时指标作为通过条件。Value Gate 证明的是“受限交互和证据导航具有增量”，不是“当前系统已经成为自主调查 Agent”。

## 九、数据基础支持说明

S5 已对既有历史制品执行只读重算探针：同一 RRC25 历史发布包含 241 个国家/未知桶、每桶 60 个时间槽，其中 240 个国家可比较，未知桶按规则排除；伊朗下降幅度和持续性经验百分位均为 100%，ASN 终点迁移比例经验百分位为 99.583333%。

该探针只证明现有历史数据能够生成同期参照，不是本 S6 合成候选、生产发布或国家级中断结论。S6 的最终同候选验收使用冻结合成集，以确保每个数字和边界都可重复复算。

## 十、修正记录与最终判定

S6 同候选闭环发现并修正三类问题：

1. 同期国家投影的输入排列会影响制品内容地址；现已稳定排序。
2. 趋势 Claim 直接泄露 `complete/count/stable` 等内部枚举，无法通过正式中文报告校验；现由确定性中文显示词生成，底层枚举仍保留在结构字段中。
3. ASN 持续性 Claim 的数字指标键没有显式携带 ASN 语义，报告数值校验不能证明“2 个/1 个 ASN”；现已补全 ASN 指标语义键。

修正没有放宽报告校验、证据边界或正确弃答规则，也没有增加 Hypothesis、因果或外部证据能力。

最终判定：**S6 已修正后与最终验收要求一致**。只有当前分支候选通过；不是合并证明、发布证明或生产部署证明。

国家中断趋势分析最终验收回检：S6 已修正。
