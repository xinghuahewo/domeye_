# 国家中断趋势分析 S1 验收记录

版本：`country-outage-trend-analysis-s1-v1`  
阶段：S1  
范围：TrendProfile 身份、质量、基线、统计人口、分母与直接可比性  
状态：S1 已封口；不代表关键点、页面、报告、生产或最终验收

## 一、阶段结论边界

S1 只闭合 TrendProfile 的身份、质量、基线和可比性。实现从始至终只使用 RRC25，
只处理固定只读的 BGP 控制面趋势输入，不读取数据库、外部网络、模型或窗口外数据。

本阶段不是关键点、阶段、页面、报告或生产证据。输出中的分析状态固定为
`not_computed_in_s1`；关键点、原子状态、阶段、窗口账本和证据引用保持空数组，
由 S2 及以后在相同 `profile_id` 上确定性补齐。

## 二、确定性身份效果

输入必须唯一绑定：

- 合法 `country_outage` 事件引用、incident 和国家；
- `collector_id=rrc25`、`collector_count=1`；
- publication、revision、`data_through` 和最终性；
- 窗口起终点、时区、槽宽和槽数；
- 指标、单位、统计人口、分母；
- 每个槽的时刻、状态、值和来源引用；
- 基线类型及其可比口径。

编译器对归一化后的上述输入计算 SHA-256，并形成
`trend_profile_v1_<digest前32位>`。同一冻结输入重复编译逐字段相同；revision、
publication、槽值或基线变化会得到不同身份。不同快照不会被静默拼接。

直接计算前使用兼容性规则核对 incident、publication、revision、
`data_through`、RRC25、时间网格、单位、统计人口和分母；任一不一致都返回明确
冲突字段，不直接计算。

## 三、质量先于解释

每个预期时间槽必须显式存在。槽状态为：

- `observed`；
- `missing`；
- `unknown`；
- `source_unavailable`；
- `processing_gap`；
- `parse_failed`；
- `not_observed`。

只有 `observed` 槽允许携带数值，且数值必须位于 0 与分母之间。其他状态的值
必须为 `null`，缺失不补零、不连线。质量输出包含每种状态的独立计数、非观测槽
索引与原因、起点和终点是否已观测：

- 全部已观测：`complete`；
- 部分已观测：`degraded`；
- 没有已观测槽：`unavailable`。

CURVE-08 的 missing、processing gap 和 not observed 分别保留；CURVE-09 的
12 个 unknown 不被记为 observed、零或稳定。

## 四、基线、单位和分母

四种基线效果均有独立场景：

| 类型 | 数值来源 | 解释边界 |
|---|---|---|
| `fixed_cohort` | 指标分母 | 固定 cohort 100% 不是事件前正常状态 |
| `window_start` | 第一个已观测槽 | 窗口起点不是正常基线；起点未观测时降级为 unavailable |
| `contemporaneous_reference` | 同时间网格的显式参照 | 单位、人口和时间网格必须兼容 |
| `unavailable` | 无 | 不伪造可比较基线 |

所有类型都输出
`interpretation=observation_reference_not_normal_baseline`。指标单位、分母单位和
统计人口独立存在；S1 不把 count、ratio、百分点或槽积分相互换算。

## 五、冻结验收覆盖

S1 继续使用 S0 九类曲线，不按国家或事件名称分类：

- 单波、多波、震荡、平台、混合、未匹配和小分母曲线应得到 `complete` 质量；
- 缺槽曲线应得到 `degraded`；
- 全 unknown 曲线应得到 `unavailable`；
- 全 unknown 曲线请求 `window_start` 时，有效基线必须降级为 `unavailable`；
- 九条曲线的 `analysis.status` 均保持 `not_computed_in_s1`。

失败关闭集覆盖：错误 collector、多 collector、事件国家冲突、窗口与网格冲突、
槽时刻冲突、非观测槽补零、分母人口冲突和同期参照网格冲突。

已经获得页面、报告、追问、下载或生产端到端证据。最终判定仍以 S6 同一候选为准。
