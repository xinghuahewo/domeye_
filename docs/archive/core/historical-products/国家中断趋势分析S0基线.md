## 三、统一趋势处理的冻结语义

面对千变万化的曲线，目标不是为每种图形编写事件专用规则，而是让同一确定性
编译链按下列顺序处理：

```text
快照与统计人口
→ 槽质量和可比性
→ 基线类型与分母
→ 可重算关键点
→ 原子状态
→ 阶段序列
→ 可选模式摘要或降级状态
→ 窗口账本与证据引用
```

模式不是事实源。曲线可以是 `matched`、`mixed`、`unmatched` 或
`insufficient_data`；即使没有模式标签，质量、关键点、原子状态、阶段和
可重算数字仍须存在或明确降级。

冻结原则如下：

- 基线类型仅为 `fixed_cohort`、`window_start`、
  `contemporaneous_reference` 或 `unavailable`；
- 窗口起点不是正常基线，固定 cohort 的 100% 也不是事件前正常状态；
- 数量、比率、百分点、观测槽和 Prefix×VP 槽积分不得混用；
- `missing`、`unknown`、`source_unavailable`、`processing_gap`、
  `not_observed` 独立计数；缺失不补零、不连线；
- ASN 使用全可见、部分可见、全不可见、unknown 四状态，unknown 不并入可见状态；
- 时间同槽、相邻槽和滞后槽只表示对应关系，不表示原因或传播。

## 四、冻结验收曲线

机器基线冻结九条无国家、事件或真实编号捷径的合成曲线，每条 12 个五分钟槽。
后续算法只能依据数值、槽质量、分母和显式基线处理。

| ID | 类型 | 预期效果 | 关键安全点 |
|---|---|---|---|
| CURVE-01 | 单波 | 突降、低位平台、窗口内部分回升 | 回升不写成网络恢复 |
| CURVE-02 | 多波 | 两次主要恶化及间歇回升 | 不压成一次单波 |
| CURVE-03 | 震荡 | 连续升降和高波动 | 保留首个并列关键点规则 |
| CURVE-04 | 平台 | 小幅变化、整体稳定 | 小变化不放大成中断 |
| CURVE-05 | 混合 | `pattern_status=mixed` | 不强贴命名标签 |
| CURVE-06 | 未匹配 | `pattern_status=unmatched` | 无标签仍保留关键点 |
| CURVE-07 | 小分母 | 分母 3，显式警告 | 比率不掩盖绝对规模 |
| CURVE-08 | 缺槽 | missing、processing gap、not observed 分开 | 不跨缺槽生成关键点 |
| CURVE-09 | 未知 | 12 槽均为 unknown | 不解释为零、稳定或未发生 |

完整曲线冻结起点、终点、首个谷值、最大单槽下降终点和最大单槽回升终点；
并列值采用最早槽。S0 仅冻结输入和预期输出，不规定 S1/S2 的算法实现方式。

## 五、核心用户任务与正确弃答

最终候选必须完成五类任务：

1. UT-01：定位窗口内最快恶化，并显示操作数、单位和证据；
2. UT-02：判断终点是否回到起点观测水平，但不外推窗口外恢复；
3. UT-03：比较 IPv4 与 IPv6，同时显示两族分母、质量和未知；
4. UT-04：找出持续未回到起点状态的 ASN，保留 unknown、观测规模和持续性；
5. UT-05：从 Claim 下钻到 Evidence、Limitation、Unknown 和快照身份。

以下六类问题必须正确弃答：全国断网、用户影响、攻击、原因、责任、窗口外
完全恢复。弃答需说明现有 RRC25 证据和具体缺失数据，不生成“可能原因”代替未知。

| 系统 | 定义 | 当前测量状态 |

相对 B0/B1 最佳值，在陌生组合问题覆盖率或五项任务中位用时至少一项产生
可复核改善。否则不因语言更流畅而证明 Agent 增量价值。
