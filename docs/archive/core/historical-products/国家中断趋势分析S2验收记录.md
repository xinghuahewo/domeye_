阶段：S2  
范围：关键点、原子状态、阶段、模式降级、窗口账本、槽积分与阈值槽

## 一、阶段结论边界

S2 在 S1 的同一 `profile_id` 上增加确定性分析，不改写快照、质量、基线、
时间网格、统计人口或原始槽。处理顺序固定为：先原子、再阶段、最后可选模式。

算法不使用曲线 ID、国家或事件名称，不读取窗口外数据，不调用模型。模式标签只是
阶段序列之上的摘要；`mixed` 和 `unmatched` 仍保留关键点、原子状态、阶段与
窗口账本，`insufficient_data` 则禁止跨缺口计算。

本阶段不是页面、报告、生产或最终验收证据，也不覆盖地址族、ASN、活动时间对应、
同期参照或 Evidence Graph。

## 二、版本化分析规则

规则身份：`country_outage_trend_rule_s2_v1`。

| 规则 | 冻结值 | 作用 |
|---|---:|---|
| 方向变化 | 2 个百分点/槽 | 区分稳定与升降 |
| 突变 | 8 个百分点/槽 | 区分突降与突升 |
| 低位平台缺口 | 20 个百分点 | 标记低位稳定段 |
| 小分母 | 分母小于 10 | 显式警告，并按数量方向标记，不放大突变语义 |
| 震荡最少方向转换 | 8 | 防止把少量波动标为震荡 |
| 震荡最小交替率 | 0.8 | 要求升降高度交替 |
| 震荡最小总变差 | 50 个百分点 | 排除低幅交替 |
| 阈值槽 | 可见比例低于 0.95、0.90、0.80 | 只计已观测槽，不声称连续时长 |
| 舍入 | 6 位、half-even | 保证重复可重算 |

这些阈值是可识别的项目规则，不命名为业界通用中断等级。

## 三、关键点与并列规则

质量为 `complete` 时，固定生成五个关键点：

- 起点；
- 终点；
- 最小可见性点；
- 最大单槽下降的终点；
- 最大单槽回升的终点。

每个点包含稳定 ID、槽索引、UTC 时刻、数值、单位、统计人口和源引用。
并列谷值、下降或回升采用最早槽，避免同一输入多次生成不同边界。

质量为 `degraded` 或 `unavailable` 时，不跨缺口选择上述关键点；缺失不补零、不连线。

## 四、原子状态与阶段

完整曲线逐槽形成：稳定、上升、下降、突升、突降和低位平台；震荡曲线的方向状态
另带 `high_volatility` 标签。小分母曲线保持上升、下降和稳定，并携带
`small_denominator` 警告，避免一个 Prefix×VP 的变化被比例阈值放大。

阶段只合并相邻且状态和标签相同的原子状态。每个阶段列出起终槽、起终值、
原子状态 ID 和来源，完整曲线的阶段按顺序、不重不漏地覆盖全部槽。

缺槽曲线只保留 missing、processing gap、not observed 等非观测原子状态；
全 unknown 曲线只保留 unknown。两者不形成跨缺口阶段。

## 五、窗口账本

完整曲线输出以下可重算事实：

| 指标 | 公式 | 边界 |
|---|---|---|
| 起点至谷值变化 | `extreme - start` | 带方向和原单位 |
| 损失幅度 | `start - extreme` | 相对窗口起点观测值 |
| 谷值至终点回升 | `end - extreme` | 回升只表示窗口内观测值变化 |
| 终点相对起点残留 | `start - end` | 不外推窗口以后 |
| 窗口回升比例 | `(end - extreme) / (start - extreme)` | 不能解释为网络、用户或服务层面的恢复率 |
| 固定 cohort 缺口积分 | `sum(max(fixed - slot, 0))` | 单位为 Prefix×VP 槽 |
| 窗口起点缺口积分 | `sum(max(start - slot, 0))` | 单位为 Prefix×VP 槽 |

每个事实公开公式、操作数、单位、方向、基线类型、统计人口、舍入和来源引用。
Prefix×VP 槽不是用户时、服务时或真实中断时长。

阈值结果只给出观测槽数量和槽索引，保留五分钟槽宽；不连续槽不冒充连续时长。
不完整曲线的账本状态为 `unavailable`，不跳过缺失后继续积分。

## 七、通用性反证

除九条冻结曲线外，S2 用五类变形测试防止按图写死：

1. 同一输入重复分析，逐字段相同且再次分析幂等；
2. 数量与分母同比放大 10 倍，模式、关键点和阶段不变；
3. 整体平移观测窗口一天，槽索引与阶段类型不变；
4. 改写事件与国家身份但保留曲线，模式、关键点和阶段不变；
5. 任意中间槽改为显式 missing，结果降级且不再输出跨缺口关键点、阶段或账本。
