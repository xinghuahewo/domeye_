# 国家中断趋势分析 S4 验收记录

版本：1.0  
阶段：S4（Evidence Graph、阅读旅程与组合追问效果闭合）

## 本阶段效果

确定性 TrendProfile 与 S3 上下文被编译为同一个 `trend_product_v1`。
每条可发布 Claim 均有稳定 ID，并同时连接 Evidence、Limitation 与 Unknown；
节点类型只允许 Claim、Evidence、Limitation、Unknown，关系只允许
`supported_by`、`limited_by`、`unknown_about`。Evidence Graph v1 不包含 Hypothesis，
也不包含因果关系。

制品固定页面阅读旅程：身份与质量、一句话窗口状态、关键点与阶段、窗口账本、
IPv4/IPv6、ASN 迁移与持续性、活动时间对应、证据边界、事件内追问和下载。
页面、报告、QA、Markdown、PDF 与 JSON 下载只能消费同一 `product_id`；模型不得
改写阶段、数字、Claim、Limitation 或 Unknown。

白名单算子覆盖最快变化、谷值、回升与残留、阶段序列、地址族分化、ASN 迁移与
持续性、活动时间对应和证据导航。原因、攻击、政策、用户影响、责任以及窗口外
完全恢复必须正确弃答，并返回同一制品中的限制和未知节点。

## TAE 映射

- TAE-12：Claim/Evidence/Limitation/Unknown 同制品绑定，禁止 Hypothesis；
- TAE-13：六类输出面声明共用同一确定性 `product_id`；
- TAE-14：组合式追问只调用白名单算子，越界问题正确弃答。

## 阶段边界

本记录只证明 S4 确定性编译器、机器 Schema、冻结问题集和阶段 Hook 的候选证据。
它不是生产部署、真实浏览器页面、正式模型、外部证据、RCA 或 TAE-01 至
TAE-15 最终通过证明。S5 与 S6 仍须分别完成同期参照和同候选整体效果验收。
