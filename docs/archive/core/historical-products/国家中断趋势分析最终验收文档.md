# 国家中断趋势分析最终验收文档

版本：1.0  
状态：最终效果合同  
适用对象：Domeye 已有合法 `country_outage` 事件的 RRC25 趋势分析、
证据导航、报告和有界追问

## 一、文档定位

本文只设计最终效果，不规定变点算法、阈值实现、编程语言、数据库表、
进程形态、模型供应商或具体实施顺序。

最终效果不是“多生成几张图”，而是把任意合法趋势编译为一份统一的事件
状态画像：

```text
质量状态
→ 基线与统计人口
→ 关键点
→ 原子状态
→ 阶段序列
→ 损失、回升与残留
→ 地址族与 ASN 迁移
→ 时间对应
→ 同期参照
→ Claim / Evidence / Limitation / Unknown
```

这一效果是 **Evidence-grounded Incident Analysis**，不是 Network RCA。
“国家中断”是现有事件类型名称；系统从始至终只描述 RRC25 BGP
控制面观测，不据此认定全国断网、用户或业务影响、原因、攻击、政策行为、
责任主体或完全恢复。

## 二、用户最终获得的效果

用户打开事件后，不再只看到一条需要自行解读的折线，而是直接获得：

1. 这份趋势是否完整、统计人口是什么、使用什么基线；
2. 什么时候开始明显变化、最快变化和谷值在哪里；
3. 曲线经历了哪些阶段，是单波、多波、震荡还是混合型；
4. 起点到谷值损失多少，窗口内回升多少，终点还残留多少；
5. IPv4 与 IPv6 的变化是否一致，各自分母是多少；
6. 哪些 ASN 恶化、回升或持续未回到起点状态；
7. UPDATE、ANNOUNCE、WITHDRAW 与状态变化在时间上如何对应；
8. 在同一 RRC25、同一时间网格下，该国家投影与同期其他国家投影相比如何；
9. 每个结论为什么成立、有什么限制、仍然有什么未知。

## 三、最终效果要求

### TAE-01：事件、快照与趋势身份始终唯一

- 一份趋势画像唯一绑定合法 `country_outage` 事件、国家、RRC25、观测窗口、
  `publication_id`、`revision`、`data_through`、统计人口和数据最终性；
- 图表、阶段、派生数字、Evidence Graph、报告、追问和下载使用同一身份；
- 身份冲突、窗口不一致或统计人口不一致时失败关闭，不拼接不同快照；
- 新 revision 不重写旧趋势画像，而是生成可区分的新制品。

### TAE-02：任意合法趋势都有统一、可降级的 TrendProfile

- 每个可用趋势都生成统一 TrendProfile，包含指标、单位、统计人口、分母、
  时间网格、基线、质量、关键点、阶段、派生事实和证据引用；
- 复杂曲线不强制归入某一命名模式；允许 `mixed`、`unmatched` 和
  `insufficient_data`；
- 模式标签只是阶段序列之上的可选摘要，移除标签不影响关键点、阶段和数字；
- 不使用事件名称、国家代码或某次事件的固定数字作为趋势分类捷径。

### TAE-03：质量、缺失和未知先于趋势解释

- 趋势先显示已观测槽数、缺失槽数、首尾是否对齐和数据质量状态；
- `missing`、`unknown`、`source_unavailable`、`processing_gap` 和
  `not_observed` 保持不同语义；
- 缺失不补零、不连线，不解释成稳定、下降、恢复或未发生；
- 质量不足时输出可降级或不可用状态，不为了得到模式而忽略缺失。

### TAE-04：基线类型、分母和比较方向始终可见

- 每个趋势明确使用 `fixed_cohort`、`window_start`、
  `contemporaneous_reference` 或 `unavailable` 中的基线语义；
- 窗口起点不自动解释为正常基线，固定 cohort 的 100% 也不自动解释为事件前状态；
- 数量、比率、百分点和槽积分保持不同单位，不相互替代；
- 只有同快照、同时间网格、同统计人口和兼容单位的数字才能直接计算。

### TAE-05：关键点、原子状态和阶段序列能够还原曲线结构

- 趋势至少能呈现起点、终点、谷值或峰值、最大单槽下降和最大单槽回升；
- 原子状态能区分稳定、上升、下降、突降、突升、低位平台、高波动、缺失和未知；
- 用户可以按阶段阅读单波、多波、反复、平台或混合变化；
- 关键点和阶段在图表、文本、证据和下载中使用相同时刻、数值和标识。

### TAE-06：损失、回升与残留形成可重算的窗口账本

- 明确展示起点至谷值变化、谷值至终点回升、终点相对起点残留和窗口内回升比例；
- 每个数字公开操作数、公式、单位、方向和舍入；
- “回升”只表示回到窗口内某个参照水平的程度，不自动写成网络、用户或服务恢复；
- 观测窗口之后的状态保持未知，不用终点外数据静默补写。

### TAE-07：累积可见性缺口与阈值槽分布衡量广度和持续性

- 用户能同时查看相对固定 cohort 与相对窗口起点的槽积分；
- 槽积分明确单位和积分规则，不写成用户时、服务时或真实中断时长；
- 阈值结果以观测槽数和五分钟槽分布呈现，不用不连续槽冒充连续时长；
- 阈值是可识别版本的分析规则，不暗示业界通用的“中断级别”。

### TAE-08：IPv4 与 IPv6 差异同时显示比率、分母和未知

- IPv4 与 IPv6 分别生成质量、关键点、阶段、起终变化和残留；
- 地址族比较始终同时展示各自分母，小分母不用视觉或语言放大成等量影响；
- 可以回答两个地址族何时分化、谷值是否同步、终点残留是否一致；
- 不将观测差异解释为配置、业务、运营商策略或用户影响原因。

### TAE-09：ASN 从排行榜升级为状态迁移、持续性和观测规模视图

- 用户能查看 ASN 在起点、关键阶段和终点之间的全可见、部分可见、全不可见与
  未知迁移；
- `unknown` 作为独立状态参与人口闭合，不被并入全可见或部分可见；
- 每个 ASN 可下钻地址族、基线 Prefix×VP 观测规模、各状态槽数、最长持续段和终点状态；
- 优先审查视图保留观测规模与持续时间两个维度，不使用无解释的单一影响分数；
- ASN 排序不表示用户影响、原因、责任或传播方向。

### TAE-10：活动与状态只建立可审计的时间对应

- UPDATE、ANNOUNCE、WITHDRAW、资源、Prefix×VP 和 ASN 变化可在同一时间轴对齐；
- 每条轨道明确指标定义、统计人口和时间槽语义；
- 统计人口不同的轨道只能并列观察，不直接相减、合计或生成共同影响分数；
- “同槽”、“相邻槽”和“滞后槽”只表示时间关系，不自动写成导致、传播或根因。

### TAE-11：同期全球投影提供参照，不伪造正常基线或真实事件

- 同期参照只使用同一 RRC25、同一时间网格、同一 mapping 和兼容指标的国家及未知桶；
- 用户可查看目标国家投影的下降幅度、持续性、ASN 迁移和曲线形状在同期分布中的位置；
- 用户可看到同槽共同波动的国家投影比例，用于识别 RRC25 共同观测现象；
- 同期非伊朗投影不自动成为国家中断事件，同期分布不命名为历史正常带；
- 无可比人口、小分母或质量不足的投影明确排除或降级。

### TAE-12：Evidence Graph v1 把结论、证据、限制和未知绑定为同一制品

- 每个可发布 Claim 具有稳定 ID，并只通过白名单关系连接 Evidence、Limitation 和 Unknown；
- Evidence 能回到原始事实或派生事实的快照、指标、统计人口、时间、数值、公式和操作数；
- Limitation 显示 RRC25 单 collector、BGP 控制面、时间窗口、统计人口和缺失能力；
- Unknown 保留原因、用户影响、窗口外恢复、责任和不足以回答的问题；
- Evidence Graph 不包含 Hypothesis 节点，不用图连线暗示因果。

### TAE-13：图表、事件摘要、报告、追问和下载共享同一确定性制品

- 页面的阶段标注、关键数字、报告正文、追问答案、Markdown 和 PDF 来自同一通过校验的
  TrendProfile 与 Evidence Graph；
- 用户可从一句结论下钻到阶段、关键点、ASN、事实和快照身份；
- 同一冻结输入重复生成时，阶段边界、关键数字、Claim、Limitation 和 Unknown 一致；
- 模型只能对已绑定的结构组织受控中文，不能改写阶段、数字、结论等级或未知。

### TAE-14：组合式追问能够使用分析算子，但不越过事实合同

- 用户可追问最快变化、谷值、回升、残留、阈值槽、地址族分化、ASN 迁移、持续性和时间对应；
- 答案使用原报告同一快照和同一分析制品，不为新问题重新猜测曲线；
- 陌生组合问题只能调用白名单分析算子，新数字仍须形成公式、操作数和证据引用；
- 询问原因、攻击、政策、用户影响或完全恢复时，系统给出正确弃答、现有证据和缺失数据；
- 连续追问不把上一轮推测累积为下一轮事实。

### TAE-15：趋势分析必须通过用户价值与可信度双重验收

- 冻结验收集覆盖单波、多波、震荡、平台、混合、未匹配、小分母、缺槽和未知等曲线；
- 关键数字、阶段边界、Claim 与 Evidence 一致率为 100%；
- 对全国断网、用户影响、攻击、原因、责任和窗口外恢复的正确弃答率为 100%；
- 用户能完成“定位最快恶化”、“判断终点是否回到起点”、“比较地址族”、
  “找出持续未回到起点的 ASN”和“查看结论证据”五类核心任务；
- 候选系统必须相对现有纯观测页或确定性报告基线，在陌生组合问题覆盖率或任务用时中至少一项产生可复核改善，
  且不降低事实准确性、正确弃答率和证据覆盖。

## 四、最终阅读效果

用户从页面顶部到证据底部的阅读顺序为：

1. 事件、RRC25、窗口、快照和质量；
2. 一句话窗口状态结论；
3. 带阶段背景、关键点和缺槽的趋势图；
4. 损失、回升、残留和累积可见性缺口账本；
5. IPv4 / IPv6 分母及阶段对照；
6. ASN 迁移、持续性和观测规模；
7. 活动与状态时间对齐；
8. 同期国家投影参照；
9. Claim、Evidence、Limitation 和 Unknown；
10. 事件内组合式追问和下载。

页面不使用一个不可解释的“影响分数”替代上述结构，不用模式标签隐藏
原始趋势，也不强迫用户通过聊天才能看到核心分析。

## 五、明确不产生的效果

本合同不得被解释为交付以下能力：

- 多 collector 选择、聚合或相互印证；
- DNS、HTTP、Traffic、Probe 或服务遥测融合；
- 历史正常带、季节性基线或事件前正常水平；
- 全国断网、用户或业务影响判断；
- 原因、攻击、政策、配置、设施故障、责任主体或传播因果；
- 自由 Hypothesis 生成、Investigation Graph 或 Network RCA；
- 未经事实合同暴露的 Prefix、VP、AS_PATH 或 peer 级结论；
- 窗口结束之后的完全恢复判断；
- 永久会话历史或自动执行处置。

## 六、不构成最终通过的情况

以下任一情况存在时不得宣告通过：

- 只有曲线标签，没有关键点、阶段和可重算数字；
- 为了匹配模式而补零、平滑或删除缺失和未知；
- 把窗口起点或固定 cohort 100% 写成正常基线；
- 直接混算不同统计人口的指标；
- 地址族比较不展示分母；
- ASN `unknown` 在列表和聚合中消失或被静默分类；
- 把 UPDATE 与可见性的时间相邻写成因果；
- 把同期国家投影写成真实事件或正常带；
- Claim 没有 Evidence，或证据不能回到同一快照与操作数；
- 报告、页面和追问对同一数字或阶段给出不同结果；
- 模型能改写确定性阶段、数字、证据、限制或未知；
- 只通过 Hook、文档、单元测试或静态截图，没有数据、API、页面、报告、追问和下载效果证据；
- 候选系统没有证明相对现有基线的分析增量价值。

## 七、最终判定

- **通过**：TAE-01 至 TAE-15 全部具有同一候选版本的可复核证据；
- **有条件通过**：没有已知偏离，但文档明确列出的外部验收条件尚未到期；
- **不通过**：任一到期要求失败，或通过删除、降低、改写本文规避失败；
- **未知**：证据缺失或无法重现；未知不得解释为通过。

本合同不授权修改 `backend/core/`、重建数据库、扩大数据时间范围、增加 collector、
启用外部网络读取、执行付费模型调用或切换生产运行时。
