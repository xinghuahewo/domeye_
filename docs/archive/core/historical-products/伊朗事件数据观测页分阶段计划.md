# 伊朗事件数据观测页分阶段计划

> 本文是《[伊朗事件数据观测页最终验收文档](./伊朗事件数据观测页最终验收文档.md)》
> 的阶段推进边界。
>
> 本文只规定整体从什么状态开始、以什么状态结束，以及每个阶段的入口、出口和不得
> 跨越的边界；不规定实现任务、组件结构、接口字段、开发命令、人员分工或排期。

## 一、总起点

- 伊朗事件已经具有完整的 RRC25 五分钟状态重放数据；
- 当前页面以研究结论叙事为主，图表主要用于支持既有结论；
- 首屏仍显示事件状态、分析摘要和恢复判断；
- 时间语义仍以独立卡片呈现；
- episode、wave、候选前兆、结论、未知项和行动建议仍占据页面主体；
- 当前时序已经能够展示 Prefix×VP、ASN 分类、IPv4/IPv6 和 UPDATE 报文；
- 当前页面尚未形成以资源状态、单槽变化、报文活动和持续时间为主体的统一观测界面；
- 当前产品合同和任务结束 Hook 仍沿用“前端直接给出完整研究叙事”的旧验收方向。

## 二、总终点

- 最终验收文档的 FA-01 至 FA-12 全部通过；
- 页面成为以图表为主体的 BGP 数据观测页；
- 用户能够读取资源状态、单槽变化、报文活动、地址族差异、ASN 状态和持续时间；
- 关键时间全部绑定到对应指标、数值和图表；
- 页面不再直接给出生命周期、恢复、因果、前兆、服务影响和行动建议；
- 单 collector、BGP 控制面、固定人口、正常带不可用和窗口边界始终清晰；
- 任一统计值均具有稳定的对象、单位、分母、窗口和缺失语义；
- 桌面端和移动端均能完整读取主要指标；
- 每个阶段结束均完成最终验收防偏离 Hook 回检；
- 既有检测核心、研究交付身份和其他事件页面不因本次前端改造发生未授权变化。

总终点不是“旧叙事已经删除”，而是“新的数据观测效果已经完整成立，同时没有替后续
Agent 生产分析结论”。

## 三、全局边界

- 原始 RIB、UPDATE、独立 Go 重放交付包及其哈希身份保持权威，不为适配页面修改数据；
- `backend/core/` 业务逻辑不得因本次页面改造发生变化；
- 不重建数据库，不重新执行 MRT 重放，不改变生产 Nginx、端口、Screen 或运行环境；
- 不把单一 RRC25 collector 的结果扩张为全国、全球或多 collector 一致事实；
- 不把 BGP 控制面状态写成用户流量、服务可用性或实际中断规模；
- 不把 Prefix×VP 冒充为唯一前缀数量；
- 不把窗口内峰值、谷值和最大变化写成相对长期正常水平的异常程度；
- 不把窗口起点写成精确事件起点，不把窗口末回升写成恢复状态；
- 不引入 episode、wave、因果、前兆、根因、责任主体或行动建议；
- 不直接比较不同人口、不同快照或不同定义的历史数字；
- 缺失和未知不得转换为 0、正常、未发生或已经恢复；
- 伊朗验收事件以外的事件类型继续保持既有行为，不借本次任务提前推广；
- 后续阶段不得通过降低、删除或改写最终验收要求覆盖前序偏离；
- 未达到本阶段出口时不得进入下一阶段；
- 阶段完成只代表本阶段出口成立，不代表最终验收通过；
- 每个阶段结束必须调用最终验收防偏离 Hook；回检为“存在待处理偏离”时不得出场。

## 四、阶段总览

| 阶段 | 名称 | 入口概括 | 出口概括 |
|---|---|---|---|
| S0 | 最终效果与语义冻结 | 新方向已明确，旧合同仍冲突 | 最终效果、指标语义和阶段边界成为唯一验收基准 |
| S1 | 观测数据边界闭合 | S0 通过，现有数据能力已知 | 页面所需数据可用或被明确标记为不可用 |
| S2 | 主时间轴效果闭合 | S1 通过，核心时序口径稳定 | 资源状态、单槽变化和报文活动形成主视觉 |
| S3 | 维度与持续效果闭合 | S2 通过，主时间轴可读取 | IPv4/IPv6、ASN 状态和持续时间可比较 |
| S4 | 页面语义与边界收口 | S3 通过，图表主体已经成立 | 旧分析叙事退出，边界和审计信息归位 |
| S5 | 最终视觉验收 | S4 通过，页面语义已经收口 | FA-01 至 FA-12 在桌面和移动端全部通过 |

## 五、阶段入口、出口与边界

### S0：最终效果与语义冻结

#### 入口

- 用户已经明确要求前端只展示数据，不替后续 Agent 形成分析结论；
- 当前上下文、产品合同、阶段计划和 Hook 仍包含旧研究叙事方向；
- 当前数据指标与分析结论之间的边界尚未成为统一验收依据。

#### 出口

- 最终页面效果具有唯一、可引用的验收文档；
- 页面允许展示的描述性统计与禁止生产的分析结论已经明确分开；
- Prefix、Prefix×VP、ASN 状态、报文、峰谷、变化和持续时间的用词边界已经冻结；
- 分阶段入口、出口和全局边界已经冻结；
- 阶段结束 Hook 已按新的最终验收文档完成一次回检。

#### 边界

- 不以文档完成代替页面效果完成；
- 不在最终验收文档中写入实现方案、代码结构或开发排期；
- 不保留与新方向冲突的 Hook 检查口径；
- 不通过模糊措辞同时保留“只展示数据”和“前端直接给结论”两套目标。

### S1：观测数据边界闭合

#### 入口

- S0 阶段结束 Hook 回检为“一致”或“已修正”；
- 最终验收文档和阶段计划未发生未审查变化；
- 现有研究交付包、固定人口和五分钟状态点身份保持不变。

#### 出口

- FA-03 至 FA-10 所需的每类观测值均被确认可用、缺失或当前不可提供；
- 页面消费的数量、比例、单槽差值、窗口极值和持续时间具有唯一计算语义；
- 报文统计范围能够被明确表达；
- 唯一前缀时序与 Prefix×VP 时序不会被混称；
- 不可提供的数据不会由前端猜测、补零或用相近指标冒充；
- 阶段结束 Hook 已确认当前数据边界没有削弱最终效果要求。

#### 边界

- 不重新解释或改写原始研究事实；
- 不为补齐页面字段重新执行生产数据重放；
- 不在请求路径实时扫描大体量明细状态文件；
- 不把分析状态字段继续包装为中性观测数据；
- 数据当前不可用时保持“不可用”，不得降低最终验收定义。

### S2：主时间轴效果闭合

#### 入口

- S1 阶段结束 Hook 回检为“一致”或“已修正”；
- 主时间轴所需的数据、单位、分母和缺失语义已经稳定；
- 关键时间能够绑定到明确指标和状态点。

#### 出口

- FA-01 至 FA-05、FA-08 和 FA-09 在主阅读路径上成立；
- 首屏能够直接读取观测身份与范围，不显示分析状态；
- IP/前缀资源状态成为页面主视觉；
- 相邻时间槽变化能够以正负方向直接读取；
- ANNOUNCE、WITHDRAW、UPDATE 总量和比例与资源状态时间对齐；
- 窗口内关键时间均绑定指标和值，不再依赖独立时间语义卡片；
- 阶段结束 Hook 已确认主图没有重新形成事件结论叙事。

#### 边界

- 不把多个不同单位和方向的指标强行压入不可辨识的单轴；
- 不把描述性峰谷命名为最严重时刻、恢复起点或事件阶段；
- 不让长篇文字重新成为主图的解释前提；
- 不因主图完成而提前宣称地址族、ASN 和移动端效果已经通过。

### S3：维度与持续效果闭合

#### 入口

- S2 阶段结束 Hook 回检为“一致”或“已修正”；
- 主时间轴、关键标注和报文范围保持稳定；
- 地址族和 ASN 状态具有与主图一致的时间与人口语义。

#### 出口

- FA-06 和 FA-07 通过；
- IPv4 与 IPv6 能够在共享时间语义和明确分母下比较；
- ASN 状态数量、时间热力图和持续时间均可读取；
- 状态筛选和排序不暗示用户规模、商业重要性或责任归属；
- 维度视图与主时间轴之间不存在口径漂移；
- 阶段结束 Hook 已确认维度展示仍然停留在描述性数据层。

#### 边界

- 不用标题或摘要替用户判断哪个地址族“更严重”；
- 不把 ASN 状态持续时间命名为事件持续时间；
- 不把排序解释为影响、重要性、责任或因果；
- 不因维度数据量较大而静默截断且不说明范围；
- 不因桌面维度图完成而宣称移动端最终通过。

### S4：页面语义与边界收口

#### 入口

- S3 阶段结束 Hook 回检为“一致”或“已修正”；
- 主时间轴和维度图已经能够独立传达数据；
- 删除旧分析叙事不会造成核心观测数据缺失。

#### 出口

- FA-01、FA-02、FA-08、FA-10 和 FA-11 全部通过；
- episode、wave、恢复、候选前兆、结论等级和行动建议退出页面主内容；
- 旧事实记录仅保留历史身份或独立上下文语义；
- 单 collector、控制面、固定人口、正常带不可用和窗口边界无需展开即可看到；
- 指标定义、数据限制、质量和哈希进入辅助或折叠审计区域；
- 页面不再需要研究结论文字才能被理解；
- 阶段结束 Hook 已确认旧叙事没有以新标题、新卡片或 Tooltip 形式回流。

#### 边界

- 不通过删除所有边界文字实现“少叙事”；
- 不隐藏正常带不可用、单 collector 或控制面限制；
- 不把分析结论从正文搬到 Tooltip、状态标签或图表标注中继续展示；
- 不删除追溯和质量身份；
- 不改变其他事件类型的既有详情页行为。

### S5：最终视觉验收

#### 入口

- S4 阶段结束 Hook 回检为“一致”或“已修正”；
- 页面主要语义、指标口径和审计边界已经收口；
- 桌面和移动视口均具备完整验收条件。

#### 出口

- FA-01 至 FA-12 全部通过；
- 桌面端和移动端均能完整读取主要指标、时间、数值和边界；
- 页面无横向溢出，关键标注不遮挡，颜色不是唯一状态编码；
- 缺失值、时区、单位、分母、峰谷和单槽差值全部核对一致；
- 旧分析叙事相关可见模块数量为 0；
- 最终截图、数据核对和自动检查属于同一页面版本；
- 阶段结束 Hook 给出最终“一致”或“已修正”结论。

#### 边界

- 不用局部截图、单一视口或无数据空壳代替最终页面验收；
- 不用测试通过代替人工可读效果；
- 不用文案搜索为零代替图表完整；
- 不带未解释阻塞宣称最终通过；
- 不在最终验收尚未通过时切换生产版本；
- 不把本次伊朗样本的专属结论硬编码为其他事件的通用语义。

## 六、阶段封口规则

- 每个阶段结束时，Hook 必须同时回读最终验收文档和本计划；
- Hook 必须检查本阶段入口是否真实成立、出口是否全部到期、边界是否被跨越；
- 已到期的出口存在缺失、失败或无法判断时，阶段不得标记完成；
- 尚未到期的最终要求可以保持未完成，但当前实现不得使其不可达；
- Hook 回检结论只允许为“一致”“已修正”或“存在待处理偏离”；
- “已修正”必须指偏离已在本阶段授权范围内完成修正；
- “存在待处理偏离”必须列出对应 FA 编号、偏离位置和阻塞原因；
- S5 只有在 FA-01 至 FA-12 全部通过时才能宣告最终完成；
- Hook 是防偏离回检，不替代数据正确性测试、视觉验收或发布授权。
