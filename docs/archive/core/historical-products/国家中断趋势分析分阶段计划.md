# 国家中断趋势分析分阶段计划

版本：1.0  
约束：只定义阶段入口、阶段出口和实施边界  
最终效果基准：
[国家中断趋势分析最终验收文档](./国家中断趋势分析最终验收文档.md)

## 一、总入口

- 现有合法 `country_outage` 事件已能提供 RRC25 固定快照、可见性序列、地址族、
  ASN 分页、资源轨道和审计身份；
- 已有报告与追问能力只允许确定性事实和受控语言表达；
- 已验收的 RRC25 同期全球重放能够提供同时间网格的国家及未知桶投影；
- 现状尚未按统一 TrendProfile、阶段序列和 Evidence Graph v1 对上述数据产品化；
- 本计划以 TAE-01 至 TAE-15 作为唯一最终效果准绳。

## 二、总出口

- 任意合法趋势都能输出可降级、可重算、可审计的 TrendProfile；
- 页面能呈现质量、基线、关键点、阶段、损失/回升/残留、地址族、ASN 迁移和时间对应；
- 同期全球投影以参照层出现，不冒充正常基线或真实事件；
- Claim、Evidence、Limitation 和 Unknown 形成同一 Evidence Graph v1 制品；
- 图表、摘要、报告、追问、Markdown 与 PDF 使用同一分析身份和确定性结果；
- 冻结验收集和用户任务证明分析增量价值，TAE-01 至 TAE-15 全部通过。

## 三、全局边界

- 从始至终只使用 RRC25，不设计 collector 选择、多 collector 聚合或交叉验证；
- 只读现有合法事件、固定快照和已授权数据制品，不写数据库；
- 不修改 `backend/core/` 业务逻辑，不重建、裁剪、回填或迁移数据库；
- 不增加 DNS、HTTP、Traffic、Probe、外部网页或公共网络读取；
- 不产生历史正常带，不生成 Hypothesis，不建设 Investigation Graph 或 Network RCA；
- 不认定全国断网、用户影响、原因、攻击、政策、责任或窗口外完全恢复；
- 不让模型决定关键点、阶段、数字、Claim、Limitation 或 Unknown；
- 未达到当前阶段出口时不得进入下一阶段；
- 每个阶段结束必须调用国家中断趋势分析最终验收防偏离 Hook；
- Hook 结构检查通过不等于数据、算法、API、页面、报告、追问、下载或生产效果通过；
- 后续阶段不得通过删除、降低或改写最终验收要求消除前序偏离。

## 四、阶段入口、出口与边界

### S0：最终效果、数据语义与价值基线冻结

#### 入口

- 最终验收文档已形成候选版本；
- 现有 RRC25 事件数据、页面、报告、事实合同与全球重放身份可以只读核对；
- 尚未宣告趋势分析功能、候选或生产验收通过。

#### 出口

- TAE-01 至 TAE-15 的最终效果、术语、统计人口、单位、基线类型和禁止语义无冲突；
- 冻结验收曲线类型、核心用户任务、事实正确性、正确弃答和证据覆盖基线；
- 现有能力、数据存在、目标效果、候选实现和生产运行时身份分别标注；
- S0 Hook 结论为“一致”或“已修正”。

#### 边界

- 不实现趋势分析功能；
- 不调整生产、模型、数据库、数据制品或冻结核心；
- 不把设计数字和历史验收记录写成当前运行时结论。

### S1：TrendProfile 身份、质量与基线效果闭合

#### 入口

- S0 出口全部成立；
- 合法事件快照、时间网格、统计人口、指标定义和质量状态可核对。

#### 出口

- 同一事件快照能形成唯一、可重复的 TrendProfile 身份；
- 完整、降级、缺失和不可用趋势保持不同结果；
- 固定 cohort、窗口起点、同期参照和无可用基线语义可区分；
- TAE-01 至 TAE-04 的到期效果具有可复核证据；
- S1 Hook 结论为“一致”或“已修正”。

#### 边界

- 不产生页面故事、模型文字或因果推断；
- 不用平滑、补零或删除 `unknown` 换取完整曲线；
- 不把窗口起点或固定 cohort 100% 写成正常基线。

### S2：关键点、阶段与窗口账本效果闭合

#### 入口

- S1 出口全部成立；
- TrendProfile 身份、质量、基线、时间网格和统计人口已冻结。

#### 出口

- 单波、多波、震荡、平台、混合、未匹配和数据不足曲线均形成正确的关键点与阶段序列；
- 损失、回升、残留、回升比例、累积可见性缺口和阈值槽分布可重算；
- 复杂曲线可降级为 `mixed`、`unmatched` 或 `insufficient_data`，不强制贴标签；
- TAE-05 至 TAE-07 的到期效果具有可复核证据；
- S2 Hook 结论为“一致”或“已修正”。

#### 边界

- 不用国家、事件名称或某次事件固定数字决定阶段；
- 不把槽积分写成用户时、服务时或真实中断时长；
- 不读取窗口外数据补写恢复结论。

### S3：地址族、ASN 迁移与时间对应效果闭合

#### 入口

- S2 出口全部成立；
- IPv4、IPv6、ASN 和活动轨道的统计人口、分母、时间槽和可用状态可核对。

#### 出口

- IPv4 与 IPv6 趋势在同时展示各自阶段、关键数字和分母的条件下可比较；
- ASN 全可见、部分可见、全不可见与未知在列表、迁移和聚合中人口闭合；
- ASN 状态迁移、持续性和基线观测规模可下钻、可排序、可回到证据；
- 不同人口的活动与状态轨道只以同槽、相邻槽或滞后槽关系呈现；
- TAE-08 至 TAE-10 的到期效果具有可复核证据；
- S3 Hook 结论为“一致”或“已修正”。

#### 边界

- 不为小分母地址族或小 ASN 人口放大结论；
- 不将 `unknown` 静默并入其他 ASN 状态；
- 不把 ASN 排序写成影响、原因、责任或传播方向；
- 不把 UPDATE、ANNOUNCE 或 WITHDRAW 的时间对应写成因果。

### S4：Evidence Graph、阅读旅程与组合追问效果闭合

#### 入口

- S3 出口全部成立；
- TrendProfile、地址族、ASN 和时间对应结果均有稳定事实身份。

#### 出口

- 每个可发布 Claim 都具有 Evidence、Limitation 和 Unknown，并与同一分析制品绑定；
- 页面能从一句结论下钻到阶段、关键数字、ASN、公式、操作数和快照；
- 图表、摘要、报告、追问、Markdown 与 PDF 对同一阶段和数字一致；
- 白名单组合问题可回答，原因、影响、攻击、责任和窗口外恢复问题正确弃答；
- TAE-12 至 TAE-14 的到期效果具有可复核证据；
- S4 Hook 结论为“一致”或“已修正”。

#### 边界

- Evidence Graph v1 不加入 Hypothesis 或自由关系；
- 不让模型直接观察原始曲线后决定阶段、数字或结论等级；
- 不建设脱离事件的全局聊天机器人或永久会话历史。

### S5：RRC25 同期国家投影参照效果闭合

#### 入口

- S4 出口全部成立；
- 已验收的 RRC25 同期全球投影身份、国家与未知桶、时间网格、mapping 和质量状态可核对。

#### 出口

- 目标国家与可比同期国家投影使用同一趋势语义和明确归一化口径；
- 下降幅度、持续性、ASN 迁移、曲线形状和同槽共同波动的同期分布位置可复核；
- 不可比、小分母、未知桶和质量不足投影保持明确降级；
- 同期参照页面和报告不使用“正常带”、“真实中断事件”或因果措辞；
- TAE-11 的到期效果具有可复核证据；
- S5 Hook 结论为“一致”或“已修正”。

#### 边界

- 不增加 collector、时间范围或外部证据；
- 不为无合法事件的国家投影伪造事件身份；
- 不把同期分布写成历史正常基线，不把共同波动写成 collector 故障结论。

### S6：整体效果、可信度与增量价值验收

#### 入口

- S0 至 S5 出口全部成立；
- 同一候选版本的数据、API、页面、报告、追问、下载、安全与用户任务证据可共同复核。

#### 出口

- TAE-01 至 TAE-15 全部通过；
- 冻结曲线验收集在重复、顺序和并发验证中保持相同关键数字、阶段、Claim 和证据；
- 事实准确性、正确弃答率和证据覆盖满足最终合同；
- 五类核心用户任务完成，并证明相对现有基线的组合问题覆盖或任务用时改善；
- 快照冲突、缺槽、未知、不兼容人口、模型改写和越界问题保持失败关闭；
- S6 Hook 给出最终“一致”或“已修正”结论。

#### 边界

- 不以 Hook、文档、测试计数、架构图、单个 API 200 或静态截图代替最终效果；
- 不把候选验收、本地验证或历史记录写成生产部署身份；
- 不授权数据库重建、核心修改、扩窗、多 collector、外部网络读取、RCA 或生产切换。

## 五、阶段封口

- Hook 必须同时回读最终验收文档和本计划；
- Hook 必须核对阶段入口、出口、边界和到期 TAE；
- 回检结论只允许为“一致”、“已修正”、“无影响”或“存在待处理偏离”；
- “存在待处理偏离”必须列出 TAE 编号、偏离位置和原因；
- Hook 通过只代表合同结构和当前任务边界没有机检偏离，不代表业务效果通过；
- S6 只有在 TAE-01 至 TAE-15 全部具有当前候选版本证据时才能宣告最终完成。

阶段结束调用：

```bash
python3 .codex/hooks/country_outage_trend_analysis_review.py --stage S0
```

后续阶段将 `S0` 替换为对应阶段编号。
