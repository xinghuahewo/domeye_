revision：`p0-v1.3-20260809-ir-r1`

唯一正式观测源：RRC25

## 一、结论

当前系统已经是一个较强的 RRC25 国家路由可见性观测页面，但不是当前 general page
可直接使用的聊天 Agent，也不是 RCA 系统。

本次普查得到 26 项能力或边界：

| 成熟度 | 数量 | 含义 |
|---|---:|---|
| 页面可见 | 13 | 当前 IR 页面实际请求并呈现 |
| 正式 API 可用但页面未消费 | 1 | audit 身份可读，当前页未展示 |
| 可确定性推导、尚未产品化 | 3 | 极值、地址族比较、事实时间线 |
| 当前不可用 | 3 | 趋势、外部证据、Update/Withdraw 时序 |
| 仍未知 | 2 | 报告生成、现有追问对当前 general page 的运行可用性 |
| 明确越界 | 4 | 原因责任、真实用户影响、DNS/HTTP/流量、跨事件组合调查 |

P1 候选处置为 `17 adopt / 5 defer / 4 reject`。这里的 adopt 仍只是 P0
候选，不是 Tool Registry，也不表示 P1 已实现。

## 二、系统表面结论

### 2.1 当前页面实际具备

浏览器实测当前页面请求：

- `/api/v2/events/resolve`
- `overview`
- `series`
- `asns`
- `path-downstreams`

页面可见内容包括：事件身份和窗口、路由不可见集中变化、前缀与 AS 时序、IPv4/IPv6
可见规模、受影响 AS 查询、路径关联和有限真实路径样本。

当前页面没有显示：

- audit 身份；
- trend 制品；
- 报告与追问工作台；
- 外部证据；
- 原因、责任或真实用户影响结论。

### 2.2 正式 API 比页面多一项可用能力

`audit` 对同一 publication 返回 HTTP 200，可追溯到：

- dataset：`general_read_model_dataset_v1_63be5d12ef847d74824efe5be9892f8a`
- data implementation：`git:d1f4d11fa7467dad2612e3776bbb5573c633064b`
- event read model：`country_event_read_model_v1_989f698fb6f6c32579eebe7bb2bc833f`
- 525 行受影响 AS 制品；
- 1,956 行路径关联制品。

注意：该 implementation ID 绑定的是数据制品实现，不能推出当前 Web 服务完整发布
提交。health 当前没有公开应用版本。

### 2.3 路由存在不代表当前事件可用

`trend` 路由和源码都存在，但用当前 general-read-model publication 请求时返回：

```text
404 / publication_not_found
```

因此趋势只能标为“当前不可用”，不能写成“已有趋势能力”。

### 2.4 源码存在不代表当前页面能力

仓库有 `CountryOutageReportWorkbench`、报告/追问代理路由和测试。但
`EventDetailPage.vue` 命中 `generalPage` 后直接渲染并返回，只有旧 observation 路径
才显示报告与追问 tab。P0 又禁止执行会改变状态的 POST，也没有当前用户授权上下文。

因此报告和追问均记录为 unknown：它们有源码和合同证据，但没有当前 general page
同候选用户旅程证据。

### 2.5 运行态 OpenAPI 不能自动发现

仓库 `contracts/openapi.json` 登记了正式路由；但运行态 `/openapi.json` 与
`/api/openapi.json` 返回 SPA HTML，`/api/v1/openapi.json` 返回 404。P1 如需自动工具
发现，必须使用版本化本地 Typed Tool Contract，或由运行态另行公开可验签合同。

## 四、Capability Discovery Ledger 的关键发现

### 4.1 可以直接进入 P1 候选目录

- 事件与 publication 绑定；
- 身份、窗口、质量、生命周期和最终性读取；
- 概览与前缀/AS 峰值；
- IPv4、IPv6 和新前缀时序；
- 指标定义和单位；
- 受影响 AS 分页、筛选和指定 ASN 查询；
- 路径关联与有限路径样本；
- audit 身份；
- 纯函数式极值、分单位地址族比较和事实时间线。

后三项确定性推导只完成了 feasibility/Oracle seed。P1 必须重新冻结输入输出、合法
指标、null 策略、并列极值策略、权限和状态提交后，才能注册为工具。

### 4.2 当前必须降级或拒绝

- 趋势：当前 publication 返回 `publication_not_found`；
- Update/Withdraw：当前 15 条 series track 不包含该能力，缺轨道不能解释为 0；
- 外部证据：运行态 `state=not_configured`、`provider=disabled`；
- 报告与现有追问：当前页面旅程未知；
- 原因、责任、用户影响、全国中断、DNS、HTTP、流量：当前 RRC25 单源证据不支持；
- 跨事件组合调查：属于 P2。

## 五、最小 feasibility / Oracle seed

10 个 seed 已验证：

1. 合法事件和 publication 身份闭合；
2. 中断前缀时序极值；
3. IPv4 与 IPv6 分单位比较；
4. AS48715 精确查询；
5. AS49666 的同期路径关联和真实路径样本；
6. 错误 publication 失败关闭；
7. 当前 trend 预期不可用；
8. 外部证据预期未配置；
9. 按时间排序的事实节点、逐节点 evidence ref、未知结束状态和禁止因果边；
10. 两条 AS 时序的峰值、峰值时点、末值，以及逐槽峰值与窗口累计 AS 人口的区别。

以 IPv4 为例，固定前缀可见地址并集最大值为 10,156,800，最小值为 9,577,728，
确定性差值为 579,072。这个数描述控制面可见的唯一 IPv4 地址并集，不能推出用户数
或流量下降。

## 九、独立产品语义审核

独立专家角色子 Agent 只审核“语义真值是否符合产品理解”，不审核代码风格。首轮发现
三项阻断：事实时间线没有独立 Oracle、部分可回答问题被整体判为越界、AS 峰值只有
能力 ID 而没有可验收真值。修正后复审结论为 `PASS`，剩余阻断项为 0，并确认：

- 时间线包含有序事实节点、逐节点证据、未知结束状态，且禁止生成因果边；
- 全国/用户联网问题先回答数据截止时 1,024 个路由不可见前缀，再拒绝越界推断；
- AS 峰值 350/94、各自时点和末值，与窗口累计 AS 人口 525/151 明确区分；
- 当前 IR 的能力不会静默外推到其他事件；
- 未发现把 RRC25 控制面证据越级写成原因、责任、真实用户影响、全国中断或恢复。

该审核只签署 P0 v1.3 产品语义真值和 P1 入口合同，不签署 P1 实现、生产部署或 RCA。
