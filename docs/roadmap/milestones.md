# Milestone Planning

## Milestone Template

Each milestone must define:

## Goal

What capability becomes available?

## User Effect

Before:

- What users cannot do.

After:

- What users can do.

## Included Requirements

- Requirement IDs

## Architecture Impact

Affected layers:

- Agent Runtime
- Host
- Plan
- Execution
- Artifact
- Evidence
- Answer

## Acceptance Evidence

Required:

- Code
- Tests
- Runtime trace
- Product journey

## Non Goals

Explicitly excluded scope.

## Exit Criteria

A milestone is complete only when capability is demonstrated, not when code is merged.
