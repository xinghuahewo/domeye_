# Domeye Capability Roadmap

## Goal

Track product capability evolution, not only engineering tasks.

## Capability Status

| Capability | Status | Milestone | Evidence |
|---|---|---|---|
| | | | |

## Milestone Definition

Each milestone must define:

- user-visible improvement
- architecture changes
- requirements included
- acceptance evidence
- limitations

## Delivery Principle

A milestone is complete only when:

```
Implementation
+
Integration
+
Verification
+
User journey evidence
```
are available.
