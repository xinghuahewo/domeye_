# 国家中断通用观测页 S0 现状基线

版本：2.1

冻结时间：2026-08-07 18:30（Asia/Shanghai）

对应阶段：S0「最终效果与现状差距冻结」

数据边界：`[2026-02-24T00:00:00Z, 2026-03-11T00:00:00Z)`，RRC25-only

## 一、判定口径

本基线只回答三件事：当前生产已经有什么、离 GFA-01 至 GFA-16 还差什么、后续数据
应复用还是定向补提。它不实现 S1 至 S6，不把代码存在、旧验收记录、API 200、Hook
或浏览器能打开写成新版业务效果已经交付。

状态词只有三种：

- **已有**：当前生产已经以最终合同口径向用户提供；
- **部分具备**：存在可复用的数据、代码或页面能力，但口径或用户效果尚未闭合；
- **待建设**：当前生产不能完成该项用户任务。

核对对象包括当前生产页面与 API、当前不可变生产运行时、正式 224-310 S1 至 S5 数据
记录、正式 RouteEvent/RouteState 合同，以及服务器研究目录中可能复用的会话制品。
所有服务器和生产核对均为只读；S0 没有扫描 MRT、执行重放、生成数据、修改数据库或
切换生产。

### 2.3 AS 页面

当前 `/ases/<asn>` 页面默认查询“最近 24 小时”。前端以 `recentRange(24)` 初始化，后端
明确拒绝超过 24 小时的 ASN 工作台查询。国家中断页没有受影响 AS 列表和带事件窗口的
ASN 链接；直接打开 AS 页面不会继承国家中断事件窗口。因此 GFA-11 当前未交付。

## 三、正式数据现状

### 3.1 可直接复用的权威输入

| 层 | 已有事实 | 本设计中的位置 |
| --- | --- | --- |
| 原始 MRT | 224-310 选定 RRC25 RIB/UPDATE 具有清单、大小、SHA-256 和槽位完整性 | 仅在会话事实确实缺失时定向读取 |
| RouteEvent | `route_event_dataset_v1_a408005061499629321017426e99a629`，2,448,056,457 条 | 不可变路由事件源，禁止重新生成 |
| RouteState | `route_state_dataset_v1_c2f7f7c7c63c824f4e92ed4c90787bcb`，终态 60,499,595 个 key | 唯一路由状态事实；key 为 collector、peer、prefix、AF |
| Checkpoint | 槽 0、2,160、4,320 的可恢复状态快照 | 为事件投影选择最近合法起点 |
| AS_PATH | RouteEvent 引用完整路径字典，RouteState 保留路径摘要 | 事件前实际路径关联下游的唯一来源 |
| 旧事件事实 | 首次检测、部分事件结束时间与时长 | 只决定事件身份和生命周期，不改检测算法 |
| 当前 Publication/读模型 | 81 个事件、43 个国家、全局 4,320 点 | 可保留旧发布；不能冒充新版事件投影 |

正式 RouteEvent 动作只允许 `announce`、`withdraw`、`rib_snapshot`。它保存 peer IP、
peer ASN、prefix、地址族、origin、完整 AS_PATH 引用、原始坐标和质量信息；解析器明确
拒绝把 BGP4MP `STATE_CHANGE` 伪造成 RouteEvent。这一边界是正确的，但意味着会话事实
必须作为与 RouteEvent 区分的不可变旁路事实补齐。

### 3.2 不能直接复用为新版指标的现有数据

- 当前 S3 国家/ASN 五分钟指标是对全局 RouteState key 的旧聚合，不是事件前固定
  cohort 下的唯一前缀、peer ASN 独立方向、部分/完全中断、AS 路由中断或新前缀轨道；
- 当前 country series 是国家共享的 224-310 全窗序列，不是每个事件自己的窗口；
- 当前生产 ASN 能力对数据层事件返回空页，不能据此把“没有受影响 AS”写成事实；
- 当前终端 `Prefix×VP` evidence 只能作为 RouteState 下钻物化视图，不能成为另一套
  事实层，也不能直接成为最终前台指标；
- 当前 country resources 能力不可用，不能支撑 GFA-09 的 IPv4、IPv6 `/48` 和新前缀
  三条事件轨道；
- 现有 S4 的“final”表示固定 224-310 观测窗关闭，不代表每个旧事件真实恢复或生命周期
  结束。

### 3.3 会话事实缺口核对

代码中的研究解析器能够识别 BGP4MP `STATE_CHANGE`，历史 13 槽定向研究的
`parser-stats.json` 也记录过 `state_change_record_count` 和 transition 计数。这只证明
解析能力存在，不是可消费的 224-310 会话事实：

- 该研究制品只覆盖 13 个 UPDATE 槽和 4 个定向前缀；
- 它保留的是每槽聚合统计，不是含 peer IP、peer ASN、旧状态、新状态、时间和原始坐标
  的逐条会话事实；
- 旧全局状态研究只到 `2026-02-28T15:00:00Z`，没有覆盖 224-310；
- 在相关研究目录中没有找到同时满足 4,320 槽、逐条 peer 身份、完整性清单和可复现
  身份的会话制品。

结论：会话事实确实需要定向补提，但无需重做 RIB、RouteEvent 或 RouteState。

| GFA-13 | 待建设 | 当前普通页仍展示 Prefix×VP、内部 ID、审计标签和系统自证文字 | 按六个用户任务模块重做页面；审计只留后台 |
| GFA-14 | 部分具备 | 当前不可变读模型有身份和完整性校验，但旧空能力、全局窗口与生命周期仍可能造成误读 | 新投影、Publication、API、分页和错误态绑定同一冻结身份并失败关闭 |
| GFA-15 | 部分具备 | 4,320 点 series 约 220–246 KB，未首开下载完整矩阵；但大集合能力尚未交付 | AS 与路径集合稳定分页，禁止用空页冒充完成 |

否定现有不可变数据层、统一路由和有界 series 的复用价值。

## 五、影响式数据计划

### 5.1 不重跑的内容

- 不重新下载或重建 224-310 原始 MRT 清单；
- 不重新生成 2,448,056,457 条 RouteEvent；
- 不建立第二套 RouteState，不修改既有 RouteState 数据集；
- 不重算与新版人口无关的旧 S3 国家/ASN 指标；
- 不修改国家中断检测器、阈值、首次检测时间、事件 ID 或合并规则；
- 不重建 PostgreSQL，也不把高基数状态回灌旧表。

### 5.2 必须执行的定向工作

| 数据动作 | 输入范围 | 输出边界 | 为什么不可省略 |
| --- | --- | --- | --- |
| 会话事实补提 | 已冻结清单中的 4,320 个 RRC25 UPDATE MRT；不读 RIB 路由元素，不生成 RouteEvent | 逐条 BGP4MP STATE_CHANGE 事实及 peer/时间/原始坐标/完整性清单 | 正式 RouteEvent 不保存会话事实，历史制品不完整 |
| 事件状态投影 | 既有 Seed、RouteEvent、RouteState checkpoint、会话事实和 81 个事件时间 | 每事件 cohort、事件窗五分钟状态及未知语义 | 旧 4,320 点国家共享聚合不能回答新指标 |
| 前缀/AS/IP 投影 | 上述事件状态与固定 cohort | 唯一前缀、独立方向、AS、IPv4、IPv6 `/48`、新前缀轨道 | GFA-05 至 GFA-09 使用新统计人口 |
| 路径关联投影 | cohort 冻结点 RouteState 与既有 AS_PATH 字典 | 实际路径关联下游及同时中断子集 | 不允许 relationship/customer cone 推断 |
| 新 Publication/读模型 | 完整事件派生结果与冻结 AS 属性 | 有界概览/趋势、稳定分页列表、后台审计身份 | 旧 Publication 必须保留，不能静默覆盖 |

“事件状态投影”可能覆盖大部分或全部 4,320 槽，因为 81 个事件分布在整个 224-310，
且部分事件没有结束事实；这属于对既有 RouteEvent/Checkpoint 的一次受影响范围重放，
不是重解析原始 MRT，也不是重建 RouteEvent。实施前应先按事件窗口并集计算实际槽位，
选择槽 0 或槽 2,160 的最近合法 checkpoint；不得为每个事件重复做 81 次全窗重放。

### 5.3 AS 属性与生命周期的缺失处理

- AS 名称、组织和性质只复用已冻结且能绑定版本的现有属性；缺失值保持“未知”，不在线
  搜索、不凭名称猜测，不因此触发路由原始数据重跑；
- 有结束时间的事件按既有事件事实冻结；没有结束时间的事件保持“未确认结束”，不能从
  曲线、最后一个数据槽或固定制品的 `final` 字段反推恢复；
- 224 左边界不足一小时或 310 右边界之后的数据保持范围外未知，不扩大数据范围。

## 六、阶段边界与 S0 判定

S0 已冻结以下结论：

1. 当前生产是统一 224-310 读模型，不再是旧的伊朗 60 点专页，但仍不是 v2.1 最终
   事件窗口体验；
2. RouteEvent、RouteState、AS_PATH 和原始清单可复用，不能因页面改版无判断全量重跑；
3. BGP4MP STATE_CHANGE 需要对已选 4,320 个 UPDATE 文件做一次定向补提，这是唯一已
   证实必须重新读取原始 MRT 的数据动作；
4. 新版前缀、AS、IP、路径与 Publication 都是 RouteState 的确定性事件投影，不是
   新事实层；
5. 伊朗结束未知、马拉维有结束事实，证明事件窗口和最终性必须逐事件处理；
6. 当前普通页面的内部 ID、审计术语、Prefix×VP、空 ASN 能力和 AS 最近 24 小时行为
   均属于待修正现状，不能作为最终验收结果保留。

本阶段没有实施数据、API、页面或生产变更；GFA-01 至 GFA-16 仍按上表进入 S1 至 S6
逐阶段闭合。
