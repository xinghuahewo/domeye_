## 二、生产现状

### 2.1 已确认具备

- 伊朗验收事件能够进入专用的中性数据观测页；
- 生产接口 schema 为 `event_observation_v1`；
- 页面具有固定 cohort、Prefix×VP、ASN 状态、IPv4/IPv6 分类、UPDATE 报文、
  国家资源、关键时间、质量边界和审计信息；
- 观测来源为 RRC25 单 collector，时间粒度为五分钟；
- 正常带明确为不可用，左、右边界明确为窗口外未知；
- 页面未把控制面观测外推为全国数据面或服务影响。

### 2.2 尚未具备

- 生产接口仍由伊朗引用硬编码触发；
- 生产没有 `/api/v2/` 路由，当前 Nginx 也没有代理 `/api/v2/`；
- 生产 v1 合同没有顶层 `revision`、`data_through`、`publication_state`、
  `is_final` 和 capability 声明；
- 生产 v1 ASN 矩阵一次返回全部 563 个 ASN，不具备服务端分页；
- 其他合法国家中断事件尚未共享伊朗增强观测接口；
- 当前生产包为历史重放完成后的固定结果，不证明持续追加、缺槽、迟到补正或
  revision 流程已经成立。

本地工作区存在 v2 通用化代码，但尚处于在建和测试状态，不属于上述生产能力。
