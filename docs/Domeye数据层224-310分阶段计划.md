# Domeye 数据层 224-310 分阶段计划

版本：1.0  
约束：只定义阶段入口、阶段出口和实施边界  
最终效果基准：
[Domeye 数据层 224-310 最终验收文档](./Domeye数据层224-310最终验收文档.md)

## 一、总入口

- RRC25 224-310 源窗口已经明确为
  `[2026-02-24T00:00:00Z, 2026-03-11T00:00:00Z)`；
- 现有全球状态运行材料能够说明 4,320 个五分钟槽、241 个国家及显式未知桶、
  1,041,120 条国家摘要和两项修复制品身份；
- 现有数据分散在旧 PostgreSQL 月表、研究运行目录、国家事件包和发布注册表中；
- 现有紧凑 RouteDelta 能支持状态重放，但不冒充包含完整 AS_PATH 和属性的权威 RouteEvent；
- 本计划以 DLAE-01 至 DLAE-16 作为唯一最终效果准绳；尚未宣告新数据层、迁移候选或
  生产运行时完成。

## 二、总出口

- 224-310 的原始证据、RouteEvent、RouteState、指标、事件、Publication、读模型和报告
  形成统一身份、时间窗、质量、水位、版本和血缘；
- 原始证据与高基数状态位于不可变文件层，国家/ASN 五分钟指标位于统一在线时序层，
  事件与发布位于 PostgreSQL 事务层；
- 数据到达、缺失、补齐、事件演进、分析滞后和历史订正都产生明确、可回看的版本；
- API 和报告读取预计算快照，不在请求时扫描或解压全量证据；
- 旧 Domeye 表完成影子迁移、双读对账和可回退切换，在线产品不再依赖国家/月度物理表；
- DLAE-01 至 DLAE-16 具有同一候选身份的端到端证据。

## 三、全局边界

- 从始至终只使用 RRC25（`rrc25`），数据范围固定为 224-310，不增加 collector、
  不扩展时间窗；
- 本计划只定义阶段入口、阶段出口和实施边界，不列任务清单、建表语句、代码步骤、
  人员排期或部署命令；
- 原始 RIB/UPDATE、完整 RouteEvent、高基数 Prefix×VP 状态和 RouteState 检查点不作为
  PostgreSQL 热表；国家/ASN 五分钟指标不能只保存在文件中；
- 不把现有紧凑 RouteDelta 写成完整 RouteEvent，不把缺失写成零，不让
  `data_through` 越过未闭合缺口；
- 不原地修改或删除旧 PostgreSQL 表；候选层未完成对账与回退验证前不切换读取；
- 不覆盖已发布对象、Publication 或报告；订正必须形成新版本；
- 不修改 `backend/core/` 业务逻辑，不以本计划授权读写生产数据库、重跑数据或切换生产；
- 不产生全国断网、用户影响、原因、攻击、政策、责任、传播因果或完全恢复结论；
- 未达到当前阶段出口时不得进入下一阶段；
- 每个阶段结束必须调用 Domeye 数据层 224-310 最终验收防偏离 Hook；
- Hook 结构检查通过不等于数据、迁移、API、性能、恢复或生产效果通过；
- 后续阶段不得通过删除、降低或改写最终验收要求消除前序偏离。

## 四、阶段入口、出口与边界

### S0：最终效果、窗口合同与现状基线冻结

#### 入口

- 最终验收文档已形成候选版本；
- 224-310 原始窗口、状态点语义、槽位、国家人口、mapping 和修复制品身份可以只读核对；
- 旧 PostgreSQL、研究制品、发布注册表和在线读取路径仍按现状保留；
- 尚未宣告任何数据层实现或迁移效果通过。

#### 出口

- RRC25、224-310 半开窗口、4,320 槽、241 桶和 1,041,120 条国家摘要形成无歧义基线；
- 原始数据、RouteDelta、完整 RouteEvent、RouteState、指标、事件、Publication、读模型和
  报告快照的术语及职责不冲突；
- 现有能力、现有缺口、目标效果、候选实现和生产身份分别标注；
- DLAE-01 与 DLAE-16 的身份和最终验收口径被冻结，其他 DLAE 仍保持可达；
- S0 Hook 结论为“一致”或“已修正”。

#### 边界

- 不实现数据摄取、重放、建表、迁移、API 或报告功能；
- 不读取或修改生产数据库、生产制品和运行时；
- 不把既有 224-310 历史验收材料写成新数据层已经完成。

### S1：不可变原始证据与完整 RouteEvent 效果闭合

#### 入口

- S0 出口全部成立；
- 原始 RIB、UPDATE、两项修复制品、selection、mapping 和输入质量身份可核对；
- 完整 RouteEvent 所需字段、原始坐标和质量语义已经冻结。

#### 出口

- 224-310 原始证据以内容身份不可变保存，修复制品不覆盖旧坏文件；
- 相同输入重复摄取不会生成重复 RouteEvent；
- RouteEvent 保留完整 AS_PATH、必要属性、原始引用和解析质量，可被新投影器复用；
- 现有紧凑 RouteDelta 的能力限制保持显式，不被升级为权威完整事件层；
- DLAE-02 与 DLAE-03 具有同一候选身份的可复核证据；
- S1 Hook 结论为“一致”或“已修正”。

#### 边界

- 不为了形成 RouteEvent 改写原始制品或覆盖修复前对象；
- 不在此阶段宣告 RouteState、指标、事件、Publication、API 或迁移已经完成；
- 不扩展到 AS_PATH 与既定 BGP 属性之外的外部数据源或因果语义。

### S2：RouteState、检查点与确定性重放效果闭合

#### 入口

- S1 出口全部成立；
- Seed RIB、RouteEvent 顺序、RouteKey、mapping 和投影器版本身份可核对；
- 检查点兼容性与损坏处理语义已经冻结。

#### 出口

- 从 Seed RIB 全量重放和从合法检查点接续到同一 `data_through` 得到相同状态摘要；
- 4,320 个槽严格有序推进，缺槽、损坏和版本冲突失败关闭；
- 检查点可以独立恢复，并能定位其消费的 RouteEvent 与原始对象；
- 删除可重建状态后，能够从登记事实恢复相同语义结果；
- DLAE-04 与 DLAE-08 具有同一候选身份的可复核证据；
- S2 Hook 结论为“一致”或“已修正”。

#### 边界

- 不保存每五分钟全量 Prefix×VP 状态为 PostgreSQL 热表；
- 不跨过不连续事件序列推进状态水位；
- 不在此阶段宣告在线指标、事件生命周期、Publication 或页面性能通过。

### S3：统一指标、存储职责、质量与水位效果闭合

#### 入口

- S2 出口全部成立；
- 国家、ASN、collector 指标的时间、单位、分母、地址族、未知和零值语义可核对；
- 文件证据层、PostgreSQL/TimescaleDB 在线层和事务元数据层的责任边界已经冻结。

#### 出口

- 原始证据和高基数状态由不可变文件层承载，数据库保存其身份、索引、质量和血缘；
- 国家、ASN 与 collector 五分钟指标可从统一在线时序层查询，不再增加国家/月度物理表；
- `attempted_through` 与 `data_through` 分离，缺口、未知和真实零值不混淆；
- 224-310 达到 4,320/4,320、missing=0、`data_through=2026-03-11T00:00:00Z`
  和 final；窗口末端保持为 `2026-03-11T00:00:00Z`；
- DLAE-05、DLAE-06 与 DLAE-07 具有同一候选身份的可复核证据；
- S3 Hook 结论为“一致”或“已修正”。

#### 边界

- 不把所有数据只保存为文件，也不把所有原始证据塞入 PostgreSQL；
- 不用补零、插值、扩大窗口或忽略人口不守恒换取完整状态；
- 不让应用运行入口动态创建新的国家表、月份表或事件月份表。

### S4：事件生命周期、Publication 与订正效果闭合

#### 入口

- S3 出口全部成立；
- 事件身份、检测事实、阶段、Observation Publication、Analysis Publication、revision、
  current 指针和订正语义可以核对；
- 发布只消费已经通过质量门和连续水位的指标。

#### 出口

- 国家中断事件以追加事实从 detected 推进到 final，历史阶段不被后续数据覆盖；
- 每次观测推进生成新 Observation Publication，当前指针只在完整校验后原子切换；
- 历史订正形成新 revision 和被替代关系，旧 Publication 与旧链接仍可读取；
- Analysis Publication 明确来源 Observation Publication，分析滞后公开可见；
- DLAE-09、DLAE-10 与 DLAE-11 具有同一候选身份的可复核证据；
- S4 Hook 结论为“一致”或“已修正”。

#### 边界

- 不修改既有 Publication 的窗口、事实、文件、摘要或最终性；
- 不把 current 指针当作历史事实，不用指针切换掩盖发布缺失；
- 不把 recovered_observation 或 final 写成用户、业务或国家网络完全恢复。

#### 出口

- 事件首页和报告数据入口只读取发布时编译的读模型，不扫描原始 MRT、RouteEvent 或
  全量 ASN 状态；
- 事件快照、紧凑序列和报告快照达到 DLAE-12 的响应时间与载荷预算；
- 页面、API 和报告绑定相同 incident、publication、revision、window、fact set 和证据；
- 当前指针推进不改变已经开始或已经完成的报告；
- DLAE-12 与 DLAE-13 具有同一候选身份的可复核证据；
- S5 Hook 结论为“一致”或“已修正”。

#### 边界

- 不以扩大 Sidecar 超时、增加进程或反复预热代替读模型；
- 不把高基数 ASN、Prefix×VP 或原始证据塞进事件首页和报告快照；
- 不让模型重新计算指标、决定发布版本、补写未知或修改确定性事实。

### S6：旧库影子迁移、安全边界与整体最终验收

#### 入口

- S0 至 S5 出口全部成立；
- 旧表冻结快照、新候选层、双读对账、权限、回收、回退和切换证据可以共同复核；
- 同一候选版本能够完成数据、查询、恢复、订正、API 和报告验证。

#### 出口

- 旧 Domeye 数据以可追溯导入身份进入统一语义，差异闭合，旧表保持只读和可回退；
- 运行时读取身份、发布者写入身份、不可变对象和回收保护边界实际生效；
- 在线产品不再依赖旧国家/月度物理表，且没有部分切换或孤儿引用；
- DLAE-14 与 DLAE-15 的迁移和安全效果通过；
- DLAE-01 至 DLAE-16 全部具有同一候选身份的端到端证据；
- S6 Hook 给出最终“一致”或“已修正”结论。

#### 边界

- 不以原地改表、删除旧表或不可回退切换缩短迁移；
- 不以 Hook、文档、测试计数、单个 API 200、静态截图或历史生产记录代替最终效果；
- 不把候选验收、本地验证或影子读取写成已合并、已部署或生产 verified；
- 不授权扩大到其他 collector、其他时间窗、外部证据、Network RCA 或自动处置。

## 五、阶段封口

- Hook 必须同时回读最终验收文档和本计划；
- Hook 必须核对冻结窗口、阶段入口、阶段出口、边界和到期 DLAE；
- 回检结论只允许为“一致”、“已修正”、“无影响”或“存在待处理偏离”；
- “存在待处理偏离”必须列出 DLAE 编号、偏离位置和原因；
- Hook 通过只代表合同结构、数据范围和当前任务边界没有机检偏离，不代表阶段业务效果通过；
- S6 只有在 DLAE-01 至 DLAE-16 全部具有当前候选身份的证据时才能宣告最终完成。

阶段结束显式调用：

```bash
python3 .codex/hooks/data_layer_224_310_review.py --stage S0
```

后续阶段将 `S0` 替换为对应阶段编号。若使用 Codex Stop Hook，则为当前任务会话设置：

```bash
export DOMEYE_DATA_LAYER_224_310_STAGE=S0
```

该环境变量只声明需要回检的阶段，不构成阶段通过证据。
