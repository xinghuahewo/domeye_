# Domeye Target Architecture

## Principle

Pi Agent Runtime is responsible for cognitive interaction.

Domeye Trust Kernel is responsible for execution governance.

Workflow runtime is responsible for durable execution.

Domain services are responsible for deterministic computation.

## Layers

1. Agent Runtime
2. Trusted Control Plane
3. Plan / Workflow
4. Capability Execution
5. Deterministic Compute
6. Artifact / Evidence
7. Answer Publication

Detailed design will be added after source code migration planning.
