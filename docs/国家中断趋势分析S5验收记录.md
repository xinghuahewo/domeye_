# 国家中断趋势分析 S5 验收记录

日期：2026-08-05  
阶段：S5「RRC25 同期国家投影参照效果闭合」  
候选分支：`codex/country-outage-trend-analysis-s5`  
结论：候选实现与冻结 S5 合同一致；不是生产部署，也不是 S6 最终验收。

## 一、阶段入口

S5 继承 S4 的同一确定性 TrendProduct 与 Evidence Graph v1，并只消费已经验收的
RRC25 同期全球国家投影。历史制品身份仍绑定：

- run：`global_run_v1_6427ae1ad52037c83d7ec3bb9b5e7757`；
- dataset：`global_dataset_v1_d015e120c2d02d39596af86ea8f8fb7c`；
- revision：`global_replay_r2`；
- collector：`rrc25`；
- mapping：`41fa4721c1c8f5eb4fe120987eb9672d32382d694889990b93028f4c881f63c4`；
- 已验收总体规模为 241 个国家及显式未知桶、60 个五分钟状态点。

本阶段没有重放 MRT、重建国家包、修改数据库或改变既有事件身份。机器验收使用
缩小但覆盖全部分支的冻结投影集验证算法，历史制品身份用于约束真实数据入口；
缩小投影集不冒充 241 桶真实数值的重新验收。

## 二、用户可见效果

目标国家与可比国家使用同一 RRC25、同一时间网格、同一 mapping 和同一固定
Prefix×VP 归一化语义。页面、报告、追问、Markdown、PDF 与 JSON 下载继续共享
同一 `product_id` 和同一个 `contemporaneous_reference` Claim。

用户现在可以看到五类可复算结果：

1. 目标下降幅度在可比国家投影中的经验百分位；
2. 可见比例低于固定分母 95% 的槽数及其经验百分位；
3. ASN 迁移比例及其经验百分位，ASN 人口不足时保持不可用；
4. 目标曲线形状及相同形状在可比人口中的占比；
5. 目标最大单槽下降处的同槽共同波动国家比例。

经验百分位固定为 `小于或等于目标值的可比国家数 / 可比国家总数`。曲线只按
固定比例差阈值形成 `DEGRADING`、`RECOVERING` 和 `STABLE` 的折叠序列，不能由
国家代码、事件名称或样本 ID 决定。

## 三、排除与降级

以下人口不进入可比分布，但会保留代码、分母、质量和排除原因：

- 显式未知桶；
- 固定 Prefix×VP 分母小于 10 的小人口；
- 槽质量不完整、网格不闭合或含非观测值的投影；
- 分母缺失、为零或数值越界的投影。

若目标投影本身被排除，或最终不足两个可比国家，状态为 `insufficient_data`，页面
与报告只显示不可用原因，不生成伪百分位。mapping、collector、`data_through`、
时间网格、目标国家或目标逐槽人口不一致时直接失败关闭，不把不同比较口径混合。

## 四、边界

不是历史正常基线。

不自动构成真实中断事件。

共同观测比例不用于判定采集故障、共同原因、责任主体、用户影响或传播方向。
同期非目标国家仍只是同时间窗的 RRC25 控制面投影，没有获得事件身份。

本阶段没有增加 collector、DNS、HTTP、流量、Probe、外部搜索或窗口外数据；没有
Hypothesis、因果边、RCA 或模型计算。模型仍不得改写确定性数值和 Claim。

## 五、TAE-11 到期证据

冻结验收集包含 8 个投影桶：5 个可比国家、1 个小分母、1 个质量不足和 1 个未知
桶。目标的下降幅度、持续性和 ASN 迁移经验百分位均为 80%，目标曲线形状占比为
60%，目标最大下降槽的共同观测比例为 80%。这些值均由逐槽投影重新计算，而不是
写死在报告或页面。

负向用例覆盖 collector、`data_through`、时间网格、目标逐槽人口和桶数量错配；
全部按稳定错误码失败关闭。Evidence Graph 仍只包含 Claim、Evidence、Limitation、
Unknown 以及 `supported_by`、`limited_by`、`unknown_about` 三类关系。

因此，TAE-11 在 S5 候选范围内具有可复核证据。Hook 通过只证明合同结构、允许路径
和机器验收一致，不代表生产、可配置完整参照制品或 S6 全量效果已经通过。

## 六、既有 241 桶数据只读探针

为区分“算法样例可跑”和“现有数据确实可用”，本阶段在数据主机上直接只读重算
既有 `global_replay_r2` 国家包，没有生成或覆盖远端文件。`catalog.json` 与
`COMPLETE.json` 的 SHA-256 分别为
`ee10674fb08fc7323df74cf5031849edb3dbdaf8c8d7d7529ac6999e33fd9f06` 和
`eb3046bc623bf3b208a195f09d3d9616ec45d18672e838fff2d08d4c1590d20d`，与历史
验收记录一致。

241 个桶均有 60 点；排除显式未知桶后得到 240 个可比国家。按 S5 规则重算，IR 的
下降幅度为 13.120148 个百分点、经验百分位为 100%；低于 95% 分母的槽数为 56、
经验百分位为 100%；曲线形状为“平稳→下行→平稳→上行→平稳”，该形状占比为
0.8333%；目标最大下降槽为索引 5，同槽满足下降阈值的国家占比为 0.4167%。

单独读取 IR 的 33,780 条 ASN 状态后，563 个固定 ASN 中有 174 个终点状态未回到
起点，迁移比例为 30.9059%。进一步读取 240 个可比国家的 ASN 状态后，IR 的迁移
比例经验百分位为 99.583333%。这一探针证明现有历史数据能提供目标所需操作数；
它没有形成受配置加载的完整参照制品，所以仍不替代 S6 的同候选数据、API、页面、
报告、追问与下载闭合验收。
