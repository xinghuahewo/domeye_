## 一、阶段入口

本阶段只消费已经闭合的三份正式输入：

- S1 事件 cohort 与生命周期快照；
- S2 五分钟事件指标；
- S3 冻结 AS 属性、路径关联及完整审计证据。

三份输入的 dataset、content SHA、manifest SHA 和实现提交均逐项绑定。S4 没有改变
事件检测、生命周期、窗口、固定 cohort、独立方向、RouteEvent、RouteState 或 S1 至
S3 的任何事实。

## 三、读模型与 API 效果

新版读路径通过显式候选选择加载。在没有选择时，现有生产行为保持不变；一旦明确
选择新版目录，目录不存在、manifest 冲突、文件摘要冲突、人口冲突或 Publication
不匹配都会失败关闭，不回落成同事件的旧结果、空数组或全零图。

API 出口包括：

- 旧 `country_outage` 引用解析为同一事件读模型；
- 事件概览；
- 共享五分钟时间轴及前缀、AS、观察方向和 IP 资源轨道；
- 受影响 AS 的服务端筛选、稳定排序和分页；
- 实际 RRC25 AS_PATH 路径关联下游的服务端筛选和分页；
- 只供后台运维或审计入口使用的冻结身份与摘要。

受影响 AS 和路径关联每页最多 60 条。每条路径关联最多 3 个真实路径样本；完整
5,093,251 条 S3 路径证据没有复制进正常读模型，也不会成为普通 API 响应。路径关联
仍只表示事件前实际有序 RRC25 AS_PATH 中的观测关系，不表示客户依赖、传播、用户
影响或原因。

后台 API 保留 Publication、revision、截止点和摘要，供同一冻结结果校验。S5 普通
页面不得展示这些内部身份，也不得出现 PRODUCT、PUBLICATION、REVISION、DATA
THROUGH、`Prefix×VP` 或“同一冻结制品”等工程自证文字。

## 六、重跑影响判断

本阶段新增的是 S1 至 S3 已验收事实的预编译读模型和只读 API。所需字段已经全部由
S1、S2、S3 正式制品支撑，因此只执行事件级确定性投影：不重扫 MRT，
不重放 RouteEvent 或 RouteState；不重建 cohort，不重算 S2 指标，也不改 PostgreSQL。

生成过程曾有两次在正式输出前失败：一次是传包使用了错误的完整 Git SHA；一次是把
Go 制品各自的结构化内容摘要误套为 S4 JSON 摘要。两次都在身份预检阶段停止，没有
产生正式读模型。修正后以精确提交 `d1f4d11f…` 重新生成并完成上述深审。
