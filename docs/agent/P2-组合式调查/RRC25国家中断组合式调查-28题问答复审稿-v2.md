## 三、统一回答与导出规则

### 1. 海量结果

系统先确定性计算总数和稳定排序，再返回预览：

| 类型 | 默认预览数量 |
|---|---:|
| AS 排名 | 10 |
| 前缀 | 20 |
| 路径 | 5 |
| downstream origin | 10 |
| 集合交集成员 | 10 |

预览结尾必须说明：

```text
当前显示 N/TOTAL，排序为……，结果是否完整：否。
是否导出完整结果？可选 Markdown、CSV 或 JSON。
```

用户确认后调用通用 `EXPORT-01 export_result_set`。导出必须复用同一冻结 result set，绑定 publication/revision、查询参数、排序、总数、完整性和 SHA-256，不能由模型重新生成成员。

### 2. AS 严重性排序

P2 默认 AS 严重性排序冻结为：

```text
peak_invisible_direction_count DESC,
peak_complete_prefix_count DESC,
asn ASC
```

第一排序项“不可见程度”按照当前字段映射为不可见观察方向峰值 `peak_invisible_direction_count`；只有第一项一致时，才比较完全不可见前缀峰值数量。该排序不表示 AS 的拓扑关键性或业务重要性。

### 3. 路径展示

- P2 v1：5 条真实样本、路径位置、左右直接邻接、总体数量、完整导出；
- 后续能力：指定 AS 的有界路径邻域图；
- 独立大能力：类似 BGPView 的交互拓扑图。
