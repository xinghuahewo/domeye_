## 一、入口状态

P2 入口未开放。

P1 当前只完成事件绑定的 RRC25 页面能力问答：开放理解用户目标，封闭 Grounding，使用
登记的只读 Tool/算子返回可回溯事实，并在验证后提交状态。P1 的多个子目标仍是分别执行、
分别裁决、分别引用证据的受控问答，不是开放调查计划、Evidence Graph 或因果分析。

P1 候选通过不表示 P2 已设计、已实现或已验收，不得直接复用 P1 的通过结论宣称 RCA。

## 二、P2 可以继承的已验收基础

- 固定 `country_outage` 事件、publication、revision、collector、窗口和 data-through 的绑定；
- RRC25-only 的 Capability Catalog、Typed Tool/Operator Contract、Oracle 和权限白名单；
- 开放 `UserGoalPlan` 与封闭 `GroundingPlan` 的职责分离；
- 逐目标 `supported / partial / clarify / unsupported / invalid_data` 裁决；
- EvidenceState 与 DialogState 分离、验证后原子提交、失败回滚、取消、TTL、幂等与重绑；
- 当前事件窗口内的地址族变化、时序极值、新前缀补充、ASN、路径样本、指标语义和审计身份；
- 问题探针与独立产品语义 Reviewer 的角色分离及揭盲前真值流程。

这些基础只能作为 P2 的输入合同，不自动成为 P2 能力。

## 三、P2 必须新建而不能从 P1 推断的能力

P2 若启动，至少需要新的 Task Spec、Plan、Hook、Capability/Tool/Oracle revision 和独立真值：

1. 调查目标、调查计划、步骤依赖、预算、并发与中止合同；
2. 多个分析算子之间的合法组合规则，而不是模型自由串联 Tool；
3. Evidence Graph 的节点、边、身份、支持/反对关系和冲突语义；
4. 组合问题的完整性与局部失败传播；
5. 新数据源接入前的来源、权限、时间对齐、可比性和缺失合同；
6. 调查状态与 P1 DialogState 的隔离、恢复和审计；
7. 新的真实失败池、组合式黄金问题和独立专家审核。

## 四、继续禁止的越级项

- 不因 P1 能回答时间线、ASN 和地址族，就声称已经具备 Evidence Graph；
- 不因多个 P1 子目标可在一轮回答，就声称已经具备组合调查；
- 不把路径相邻、时间先后、共同变化或模型置信度当作因果；
- 不判断政府行为、攻击、配置错误、责任主体、全国断网、真实用户影响、业务损失或恢复；
- 不在没有新合同和 Oracle 前接入新闻、DNS、HTTP、流量、IODA、OONI 或其他 collector；
- 不把本地候选、Hook、测试、HTTP 200 或截图写成已合并、已部署或生产验证。

## 五、P2 建议入口门

只有以下条件同时成立，才能把本回执改为“入口开放”：

- 用户确认 P2 的第一批调查任务和明确非目标；
- 每种新增能力完成 Capability Discovery，而不是先写 Tool；
- 组合算子、Evidence Graph、权限、预算、失败和状态合同冻结；
- 有覆盖组合、冲突、缺失、超时、取消和越界的先验真值；
- 至少一个独立产品语义 Reviewer 在同候选上给出 PASS；
- 前端、Agent API、计划、Tool、Evidence Graph 和状态回执同候选闭合。

在此之前，当前产品应保持为自然语言灵活、事实与执行确定可控的 P1 RRC25 事件问答 Agent。
