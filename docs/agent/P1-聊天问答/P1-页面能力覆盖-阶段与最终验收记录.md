## 一、最终结论

P1 页面能力语义覆盖加固候选通过。

该结论只表示：在冻结的伊朗 `country_outage` 事件、publication、revision 和 RRC25
控制面数据上，自然语言问题可以被转换为开放的 `UserGoalPlan`，再经封闭的
`GroundingPlan`、已登记只读 Tool/算子、证据校验和状态事务形成可核对回答。它
不表示已合并、已部署或生产验证，也不具备 P2 组合调查、P3 假设、P4 多源证据或 P5 RCA。

用户可以用口语、同义、多目标和上下文表达提问。回答按子目标分别显示

桌面采用“回答区 + 证据执行链”双栏；窄屏把核对面板移到回答之后，事件身份、回答、

## 三、两个高风险问题的实际效果

### 1. “IP地址变化情况”

系统保留两个独立目标，而不是把所有地址资源混成一个数字：

1. 固定 cohort 的 IPv4、IPv6 变化主答案；
2. 窗口内新出现前缀的独立补充。

固定 cohort 回答为：IPv4 从 `10,156,800` 个唯一 IPv4 地址变为 `10,069,760`，
净变化 `-87,040`，窗口最小值 `9,577,728`；IPv6 从 `267,292` 个 IPv6 `/48`
等价块变为 `267,288`，净变化 `-4`。两条轨道各有 `3,455` 个观测槽，null 均为
`0`，但合同仍明确 null 不能按数值 0 处理。

新前缀补充为：IPv4 窗口累计出现 `700` 条，data-through 当前可见 `111` 条，
对应 `19,523` 个唯一 IPv4 地址；IPv6 窗口累计出现 `1` 条，当前可见 `1` 条，
对应 `524,288` 个 IPv6 `/48` 等价块。

IPv4 地址数与 IPv6 `/48` 等价块单位不同，只做分轨变化，不生成跨单位合计或
绝对严重度排序。最低点后的增加只描述观测变化，不等于恢复。

### 2. “IP地址变化趋势”

系统没有因为出现“趋势”二字就误判为不可回答，也没有伪造正式趋势产品。它沿用相同
双地址族、固定 cohort 主答和新前缀补充分层，以 `event_window_trend` 描述当前
publication 窗口内的确定性时序概括，并明确写出“不是正式历史趋势制品”。跨事件比较、
长期趋势、反事实和恢复判断仍不执行。

两轮均产生 2 个 `UserGoalPlan` 子目标、6 个合法 Grounding 节点、6 个真实执行节点；
共 12 个节点、112 个 Evidence 对象。两轮均在身份、权限、执行、证据和到期复核通过后
提交 `DialogState`，模型生成事实数量为 0。

## 六、技术闭环

```text
事件页固定 ref / publication / revision
  → 聊天页只提交自然语言与幂等键
  → Flask 窄代理注入可信只读 principal
  → Sidecar 重新 resolve 并校验 RRC25 事件身份与权限
  → Codex CLI gpt-5.6-sol 只生成 UserGoalPlan
  → 宿主 Validator 生成封闭 GroundingPlan
  → 已登记只读 Tool / 确定性 Operator
  → Evidence、身份、单位、状态事务后置校验
  → 发布逐目标回答并原子提交 DialogState
```

当前模型仅用于本地候选语义验收，不是生产认证模型入口。模型不能选择任意 URL、创造
Capability、绕过权限、提供事实、发布答案或提交状态。系统可控的是结构化计划、执行节点、
证据和状态事务；隐藏思维过程既不读取也不展示。

## 七、边界与未关闭但不阻断的事项

- 只使用当前 publication 已发布的 RRC25 控制面事实；不接入新闻、DNS、HTTP、流量、
  IODA、OONI 或其他 collector；
- 不判断政府行为、攻击、配置错误、责任主体、全国断网、真实用户影响、业务损失或恢复；
- “趋势”仅表示当前事件窗口内的时序概括；正式历史或跨事件趋势仍不可用；
- 本地候选尚未合并、部署或经过生产流量验证；
- 生产接入仍需另行完成固定模型、Prompt、成本、运行环境、认证与发布治理；
- 多目标回答仍是多个独立 P1 子目标，不是 P2 开放组合调查。
