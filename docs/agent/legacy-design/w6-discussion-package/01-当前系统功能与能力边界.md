# 当前系统功能与能力边界

> 文档口径：基于2026-08-14本地W6 v3工作树。“当前实现”只表示该工作树存在代码或本地证据，不表示已经合并、部署或成为生产能力。

## 1. 当前产品要解决的问题

国家中断Agent不是通用网络RCA系统。当前范围是：在一个已经绑定的 `country_outage` 事件、一个不可变publication及其revision、单一采集器RRC25和冻结时间窗内，读取、计算和发布可核验的BGP控制面观测事实。

核心边界是：

```text
可以发布：RRC25实际观测事实和登记的确定性派生事实
不能发布：由控制面观测直接推导的全国断网、真实用户影响、原因、责任、恢复或商业关系
```

## 2. P0、P1、P1.1、P2分别代表什么

| 阶段 | 产品含义 | 不代表什么 |
|---|---|---|
| P0 | 发现页面、API、数据人口、语义和能力边界 | 不是聊天运行时 |
| P1 | 对单一事件和publication进行受控问答 | 不是只能回答一句话，也不是自由Agent |
| P1.1 | 开放理解用户语义，Host再做闭合Grounding | 不是扩大Tool权限 |
| P2 | 多节点、有状态、可恢复、可追问和可导出的调查 | 不是另一套Tool系统 |

W0到W6是P2-S1的实现波次，不是产品阶段P0到P2。

## 3. 当前P1功能

### 3.1 请求链

当前P1 TypeScript链路是：

```text
用户问题
  ↓
绑定incident/publication/revision/RRC25/window
  ↓
开放P1SemanticPlan（用户目标）
  ↓
Host闭合GroundingPlan
  ↓
P2 Registry Admission（登记的是P1单元）
  ↓
PageCapabilityExecutor执行TOOL-01～06、OP-01～04
  ↓
Evidence Bundle和回答硬门
  ↓
原子提交DialogState
```

主要实现入口：

- [P1语义与Grounding运行时](../country-outage-agent-p2-s1-w6-offline-certification-v3-work/agent-sidecar/src/chat/runtime-v2-semantic.ts)
- [P1执行器](../country-outage-agent-p2-s1-w6-offline-certification-v3-work/agent-sidecar/src/chat/page-capability-executor.ts)
- [P1 Registry准入](../country-outage-agent-p2-s1-w6-offline-certification-v3-work/agent-sidecar/src/chat/p2-registry-runtime.ts)

### 3.2 P1可以回答的事实类型

当前登记能力包括：

- 解析并验证事件与publication身份；
- 读取检测时间、观测窗口、数据截止、质量、完整度和事件结束状态；
- 读取15轨正式RRC25时序及指标定义、单位和人口；
- 查询受影响ASN概览和指定ASN详情；
- 查询有限路径相邻关系和真实AS_PATH样本；
- 读取publication、dataset、实现、文件摘要和审计身份；
- 计算时序首末值、极值、极值时点和差值；
- 保留不同单位比较IPv4和IPv6；
- 排序事实时间线；
- 生成登记的事件窗口趋势事实。

### 3.3 P1状态特点

P1支持多个子目标，但这些子目标主要是分别Grounding、分别执行和分别回答。它没有把所有中间结果统一冻结为可复用ResultSet，也没有持久的共享调查DAG。

因此P1的“多目标”不等于P2的“组合调查”。

## 5. 当前模型能力状态

设计合同规定：

1. Sol生成开放SemanticPlan；
2. Host完成Grounding和执行；
3. Sol在已验证Evidence上生成TeacherReference；
4. DS生成StudentAnswer；
5. Host进行证据、边界和一致性验证。

但当前实际模式是 `trusted_fixture_replay_only`：

- 外部Sol调用数为0；
- 外部DS调用数为0；
- latency和token记录只属于fixture；
- cost为合成fixture记录；
- 没有真实provider模型对齐、性能和费用认证。

## 8. 当前不可越过的事实边界

系统不得把以下表述作为RRC25事件事实发布：

- 全国断网或全国网络中断；
- 真实用户数量、终端体验或业务损失；
- 事故原因、责任方或攻击归因；
- 事件已经恢复，除非存在合法事件结束证据；
- AS_PATH顺序证明customer/provider商业关系；
- 观测到的下游origin集合等于customer cone；
- 单一RRC25采集器没有观测到路由等于全球不可达。

可以表达的方式是：明确说明观测对象、采集器、publication、时间窗、人口完整性和限制。

## 9. 当前总体架构图

```text
P1 TypeScript链
UserGoalPlan → GroundingPlan → P1 Registry Admission
             → PageCapabilityExecutor
             → Evidence Bundle → DialogState

P2 Python链
SemanticPlan fixture → Host Grounding projection
                     → InvestigationPlan
                     → Registry Dispatcher
                     → ResultSet → Operator
                     → EvidenceGraph → Answer/Turn → Investigation CAS

共同点：边界、Registry思想、身份和确定性执行原则
断层：Plan IR、Dispatcher、Typed Artifact、Evidence与状态模型尚未统一
```
