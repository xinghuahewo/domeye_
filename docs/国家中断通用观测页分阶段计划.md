# 国家中断通用观测页分阶段计划

版本：1.0  
约束：只定义阶段入口、阶段出口和实施边界  
最终效果基准：[国家中断通用观测页最终验收文档](./国家中断通用观测页最终验收文档.md)

## 一、总入口

- 伊朗国家中断页面已经具备固定 cohort、国家状态、ASN 状态、报文、质量和审计
  等增强观测能力；
- 当前增强数据入口仍以伊朗事件为主要样本；
- 其他国家事件的数据完整度不一致；
- 现有旧检测核心、旧数据库事实和生产页面必须保持可用；
- 最终验收文档已成为通用化工作的唯一效果基准。

## 二、总出口

- 全部合法国家中断事件共享同一详情入口和 API 合同；
- 伊朗现有能力无损保留；
- 至少一个非伊朗事件无需国家专用代码即可展示；
- 活动事件能够正常追加新观测；
- 缺槽、迟到、revision、data through 和能力降级语义成立；
- GFA-01 至 GFA-12 全部通过；
- 每个阶段均留下最终验收防偏离回检结论。

## 三、全局边界

- 本计划不要求重构 `backend/core/` 或替换旧 Detection；
- 本计划不要求全部历史事件达到伊朗同等数据完整度；
- 本计划不要求全量历史重放；
- 本计划不把完整 RouteState 常规写入在线查询数据库；
- 本计划不扩大到劫持、泄漏、前缀中断或 AS 中断页面；
- 未达到本阶段出口时不得进入下一阶段；
- 每个阶段结束必须调用通用观测页最终验收防偏离 Hook；
- 后续阶段不得通过降低最终验收要求消除前序偏离。

## 四、阶段入口、出口与边界

### S0：最终效果与现状基线冻结

#### 入口

- 当前伊朗页面、API、数据能力和缺失边界可读取；
- 最终验收文档已经存在；
- 尚未以通用化目标重新冻结现状基线。

#### 出口

- GFA-01 至 GFA-12 的适用范围无冲突；
- 伊朗必须保留的能力与数值基线可复核；
- 通用化影响范围与非目标范围被明确区分；
- S0 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不实现业务功能；
- 不改变生产数据；
- 不把未来设计写成当前已具备能力。

### S1：通用事件身份与能力合同闭合

#### 入口

- S0 出口全部成立；
- 伊朗基线与最终效果要求均已冻结。

#### 出口

- 任意合法国家中断事件具有统一身份、版本、截止时间和能力语义；
- 合法无增强数据与非法事件能够区分；
- 不同数据完整度不会被解释成零值或完整状态；
- GFA-01、GFA-03、GFA-04、GFA-09、GFA-11 到期部分通过；
- S1 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不要求新数据实时追加；
- 不要求第二个国家具备伊朗全部数据；
- 不增加国家专用合同。

### S2：多国家通用读取效果闭合

#### 入口

- S1 出口全部成立；
- 通用身份和能力合同可被页面消费。

#### 出口

- 伊朗事件继续保持原有效果；
- 至少一个非伊朗合法事件进入同一页面和 API；
- 新事件只使用通用字段和能力降级；
- ASN 等大集合具有稳定分页边界；
- GFA-02、GFA-10、GFA-12 的静态读取部分通过；
- S2 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不以伊朗数据填充第二事件；
- 不要求历史事件全部补齐；
- 不为第二事件增加国家专用前端或后端分支。

### S3：持续追加与一致截止点闭合

#### 入口

- S2 出口全部成立；
- 通用页面已能读取多个国家事件。

#### 出口

- 活动事件完成至少一次新观测正常追加；
- 已发布旧时间点保持稳定；
- overview、series、ASN 和 audit 对外公开相同完整截止点；
- 页面无需重新部署即可看到新增数据；
- GFA-05、GFA-06 到期部分通过；
- S3 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不要求 WebSocket；
- 不把正常追加定义为历史 revision；
- 不以未完成槽推进公开截止点。

### S4：缺口、补正与最终性语义闭合

#### 入口

- S3 出口全部成立；
- 正常追加路径已经稳定。

#### 出口

- 缺槽、处理失败和数据暂缺不再表现为零值或恢复；
- 迟到或历史修正能够以新 revision 被识别；
- 旧 revision 保留可追溯身份；
- 活动与最终状态可区分；
- GFA-07、GFA-08、GFA-11 到期部分通过；
- S4 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不静默覆盖已发布历史；
- 不为通过验收伪造迟到、恢复或缺槽业务结论；
- 不扩大为全量灾备或全历史重算项目。

### S5：最终通用效果验收

#### 入口

- S0 至 S4 出口全部成立；
- 伊朗、非伊朗和活动追加样本均可复核。

#### 出口

- GFA-01 至 GFA-12 全部通过；
- 伊朗能力没有回退；
- 非伊朗事件无需国家专用代码；
- 正常追加、能力降级、缺口和 revision 效果均可见；
- 桌面、移动端、API 和语义结果一致；
- S5 阶段结束 Hook 给出最终“一致”或“已修正”结论。

#### 边界

- 不以局部接口测试替代最终页面效果；
- 不把未到期证据写成已通过；
- 不授权生产切换、旧核心替换或其他事件类型扩展。

## 五、阶段封口

- Hook 必须同时回读最终验收文档和本计划；
- Hook 必须核对当前阶段入口、出口、边界和已到期 GFA；
- 回检结论只允许为“一致”“已修正”“无影响”或“存在待处理偏离”；
- “已修正”只用于本阶段已经完成修正的偏离；
- “存在待处理偏离”必须列出 GFA 编号、位置和原因；
- Hook 结构检查通过不等于阶段效果已经通过；
- S5 只有在 GFA-01 至 GFA-12 全部通过后才能宣告最终完成。

阶段结束调用：

```bash
python3 .codex/hooks/country_outage_generalization_review.py --stage S0
```

后续阶段将 `S0` 替换为对应阶段编号。
