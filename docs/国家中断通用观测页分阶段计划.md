# 国家中断通用观测页分阶段计划

版本：2.1
约束：只定义阶段入口、阶段出口和实施边界  
数据范围：`[2026-02-24T00:00:00Z, 2026-03-11T00:00:00Z)`，即 224-310
最终效果基准：
[国家中断通用观测页最终验收文档](./国家中断通用观测页最终验收文档.md)

## 一、总入口

- 224-310 RRC25 原始 MRT、正式 RouteEvent、唯一 RouteState、Checkpoint、五分钟指标、
  事件与 Publication 已有可核对身份；
- 现有 RouteEvent 保存前缀、peer IP、peer ASN、origin ASN、AS_PATH 引用和质量信息，
  但正式路由事件层没有把 BGP4MP STATE_CHANGE 保存为可消费的会话事实；
- 现有五分钟指标以 RouteState key 数量为主，不能直接回答唯一前缀、独立 peer ASN
  方向、事件前 cohort、IP 地址量和路径关联下游；
- 当前国家中断页和 AS 特征页可作为现状基线，但不代表新版最终效果已经实现；
- 最终验收文档 GFA-01 至 GFA-16 是本计划唯一效果准绳。

## 二、总出口

- 224-310 范围内全部合法国家中断事件使用同一新版详情体验；
- 事件窗口、固定 cohort、独立观察方向、前缀中断、AS 中断、IP 资源、AS 属性和
  路径关联下游均符合最终验收文档；
- 页面、接口、Publication 和派生制品使用同一冻结身份，缺失或冲突失败关闭；
- 伊朗与至少一个非伊朗事件完成五类核心用户任务；
- GFA-01 至 GFA-16 全部具有同一候选版本的可复核证据；
- 候选、合并、构建、部署和生产验证身份分别闭合，不因阶段 Hook 通过而越级。

## 三、全局边界

- 从始至终只使用 RRC25，不增加 collector 或跨 collector 结论；
- 不修改国家中断检测算法、阈值、事件身份和事件合并规则；
- RouteState 仍是唯一状态事实，任何前缀、AS、IP 和路径结果都只能是确定性派生；
- peer session down 不得伪造成 WITHDRAW；会话事实与路由事实必须保持可区分；
- 第一版不使用 customer cone、AS relationship、外部拓扑或在线查询推断下游；
- 不认定全国断网、用户影响、原因、攻击、政策、责任、客户依赖或窗口外恢复；
- 不扩大 224-310 数据范围，不让新前缀抵消固定 cohort 中断；
- 未达到当前阶段出口时不得进入下一阶段；
- 每个阶段结束必须调用通用观测页最终验收防偏离 Hook；
- Hook 结构检查通过不等于数据、算法、制品、API、页面、浏览器或生产效果通过；
- 后续阶段不得通过删除、降低或改写最终验收要求消除前序偏离；
- 任一阶段都不自动授权数据库重建、生产切换、外部网络读取或付费模型调用。

## 四、阶段入口、出口与边界

### S0：最终效果与现状差距冻结

#### 入口

- 最终验收文档已经形成候选版本；
- 当前页面、API、正式 S1-S6 数据身份和已知缺口可以只读核对；
- 尚未把新版设计、候选实现或生产运行时写成已完成效果。

#### 出口

- GFA-01 至 GFA-16 的术语、统计人口、窗口、分类、页面顺序和禁止结论无冲突；
- “已有、部分具备、待建设”和“需要 RouteEvent 重放、需要原始 MRT 定向补提”分别
  冻结；
- 当前线上响应、AS 详情 24 小时限制和会话事实缺口具有可复核现状证据；
- S0 Hook 结论为“一致”或“已修正”。

#### 边界

- 不实现数据、API 或页面能力；
- 不扫描原始 MRT，不执行重放，不改变数据库或生产运行时；
- S0 只证明最终效果和差距被准确冻结，不证明任何 GFA 业务效果已交付。

### S1：观察方向、会话事实与事件前 cohort 出口闭合

#### 入口

- S0 出口全部成立；
- RRC25 Seed、RouteEvent、RouteState、原始记录坐标和事件首次检测时间具有唯一身份；
- peer ASN 去重和“当前没有路由观测即不可见”的最终语义已经冻结。

#### 出口

- 每个事件可得到首次中断前最后完整状态点和固定 cohort；
- 同一 peer ASN 的多会话能够归并为一个独立观察方向；
- 会话可观测、会话不可观测、路由不可见和数据未知保持不同事实；
- peer down 不产生虚假 WITHDRAW，但能按 GFA-04 参与前台不可见判断；
- GFA-02、GFA-03、GFA-04、GFA-14 的 S1 到期效果具有可复核证据；
- S1 Hook 结论为“一致”或“已修正”。

#### 边界

- 不改变国家中断检测结果或事件生命周期；
- 不建立第二套 RouteState，不用会话事实覆盖路由事实；
- 不提前生成前缀、AS、IP、路径、API 或页面最终效果；
- 原始 MRT 只允许用于补齐已冻结窗口内缺失的会话事实，不重新定义既有 RouteEvent。

### S2：前缀、AS 与 IP 事件投影出口闭合

#### 入口

- S1 出口全部成立；
- 事件窗口、固定 cohort、观察方向、路由状态、会话状态、origin ASN 和地址族可共同
  定位到同一五分钟状态点。

#### 出口

- 每槽前缀部分中断、完全中断和观察方向计数人口闭合；
- 每槽受影响 AS 与 AS 路由中断只由固定前缀状态投影产生；
- IPv4 唯一地址量、IPv6 `/48` 等价量和新前缀轨道可重算且互不抵消；
- 缺槽和未知不会被补零或归入正常；
- GFA-05、GFA-06、GFA-07、GFA-08、GFA-09 的到期效果具有可复核证据；
- S2 Hook 结论为“一致”或“已修正”。

#### 边界

- 不复用旧 AS 中断表或 Prefix×VP 行数冒充新版指标；
- 不把新前缀计入固定 cohort 恢复，不生成混合影响分数；
- 不改变 S1 RouteEvent、S2 RouteState 或既有 S3 数据集内容；
- 不提前生成外部 AS 属性、路径关系或前端故事。

### S3：AS 属性与路径关联下游出口闭合

#### 入口

- S2 出口全部成立；
- 受影响 AS、固定前缀、冻结点 AS_PATH 和已冻结 AS 属性快照具有可核对身份；
- AS_PATH 缺失、AS 属性缺失和路由状态未知可以分别表达。

#### 出口

- 受影响 AS 列表拥有稳定分类、排序、规模和 AS 名称/组织/性质；
- 缺少静态属性的 AS 保持未知，不通过在线查询或名称推断补齐；
- 路径关联下游只来自事件前实际 RRC25 AS_PATH；
- 全部路径关联下游与同时发生前缀中断的子集人口闭合，并能回到路径、前缀和地址量；
- GFA-10、GFA-12 的到期效果具有可复核证据；
- S3 Hook 结论为“一致”或“已修正”。

#### 边界

- 不使用 customer cone、AS relationship、商业关系或外部拓扑补写路径关系；
- 不把路径包含关系写成依赖、影响传播或因果；
- 不复制第二套 AS 档案，不改变 AS 特征页已有静态事实；
- 不提前宣告 AS 页面下钻或完整前端体验通过。

### S4：Publication、读模型与 API 出口闭合

#### 入口

- S1 至 S3 出口全部成立；
- 事件概览、三类趋势、AS 列表和路径下游均有冻结、完整、可分页的派生结果；
- 当前 Publication、Revision、事件窗口和数据最终性可只读核对。

#### 出口

- 全部合法事件通过同一用户语义取得概览、趋势、AS 列表和路径下游；
- 同一公开结果只包含一个事件窗口、一个冻结身份和一致最终性；
- 首屏和趋势响应有界，AS 与路径大集合稳定分页或按需读取；
- 旧结果、新候选、缺失结果和冲突结果不会被静默混合；
- GFA-01、GFA-14、GFA-15 的 S4 到期效果具有可复核证据；
- S4 Hook 结论为“一致”或“已修正”。

#### 边界

- 不让浏览器一次下载完整 AS×时间、前缀×方向或 AS_PATH 矩阵；
- 不在正常 API 结果中用空数组或全零冒充尚未产生的能力；
- 不修改检测事实，不静默覆盖旧 Publication 或旧 revision；
- 候选 API 通过不等于前端、部署或生产效果通过。

### S5：页面阅读与 AS 同窗下钻出口闭合

#### 入口

- S4 出口全部成立；
- 同一候选接口能提供事件概览、前缀趋势、AS 趋势、IP 趋势、AS 列表和路径下游；
- 已有 AS 特征页能够定位 ASN，但事件窗口继承尚待本阶段闭合。

#### 出口

- 页面按最终验收文档规定顺序完成正常、缺失、错误和最终态阅读；
- 前台不显示 `Prefix×VP`、内部制品 ID、PRODUCT、PUBLICATION、REVISION、DATA THROUGH
  或“同一冻结制品、证据、限制与未知”等系统自证文字，改用前缀、独立方向、AS 和
  地址量的人话；
- 点击受影响 AS 后，AS 特征页继承同一事件开始和结束时间；
- 返回事件页后保留原事件、时间位置和列表条件；
- 伊朗与至少一个非伊朗事件完成五类核心用户任务；
- GFA-11、GFA-13、GFA-15、GFA-16 的 S5 到期效果具有可复核证据；
- S5 Hook 结论为“一致”或“已修正”。

#### 边界

- 不以静态草图、组件测试或 API 200 代替真实浏览器阅读效果；
- 不复制 AS 档案，不为国家或 ASN 增加专用页面分支；
- 不在前端重新计算确定性前缀、AS、IP 或路径指标；
- 不把审计字段改放到折叠区、提示框或页尾来规避普通页面禁令；
- 不展示原因、用户影响、客户依赖、责任或窗口外恢复结论。

### S6：同一候选整体效果与生产身份验收

#### 入口

- S0 至 S5 出口全部成立；
- 同一候选版本的数据、Publication、API、页面、AS 下钻、错误态和性能证据可共同
  复核；
- 候选、Git、构建制品、部署目标和当前运行时身份可以相互核对。

#### 出口

- GFA-01 至 GFA-16 全部通过；
- 伊朗与至少一个非伊朗事件在重复、顺序和并发验证中保持相同数字、排序和路径关系；
- 缺槽、未知、session down、身份冲突、超大集合和不可用属性场景保持失败关闭；
- 五类核心用户任务完成，事实边界和正确弃答保持成立；
- 当前生产运行时使用的不可变制品与最终通过候选身份一致，且具有可执行回滚身份；
- S6 Hook 给出最终“一致”或“已修正”结论。

#### 边界

- 不以 Hook、文档、测试计数、架构图、单个 API 200 或静态截图替代最终效果；
- 不把已实现、已提交、已评审、已合并、已构建、已部署和已验证混写；
- 不授权扩窗、多 collector、数据库重建、外部数据融合、付费模型调用或 Network RCA；
- S6 以前任何阶段都不得宣告生产最终效果通过。

## 五、阶段封口

- Hook 必须同时完整回读最终验收文档和本计划；
- Hook 必须核对当前阶段入口、出口、边界、到期 GFA 和未到期 GFA 的可达性；
- 回检结论只允许为“一致”“已修正”“无影响”或“存在待处理偏离”；
- “存在待处理偏离”必须列出 GFA 编号、偏离位置、实际证据和原因；
- Hook 通过只代表合同结构和当前任务路径没有机检偏离，不代表阶段业务效果通过；
- 每个阶段必须使用当前阶段自己的实际证据，不能继承上一阶段的“通过”字样；
- S6 只有在 GFA-01 至 GFA-16 全部具有同一候选版本证据时才能宣告最终完成。

阶段结束调用：

```bash
python3 .codex/hooks/country_outage_generalization_review.py --stage S0
```

后续阶段将 `S0` 替换为对应阶段编号。作为 Codex Stop Hook 自动调用时，设置环境变量：

```bash
export DOMEYE_COUNTRY_OUTAGE_STAGE=S0
```
