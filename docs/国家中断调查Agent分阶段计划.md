# 国家中断调查 Agent 分阶段计划

版本：1.0  
约束：只定义阶段入口、前端效果、后端效果、阶段出口与边界  
最终效果基准：[国家中断调查 Agent 最终验收文档](./国家中断调查Agent最终验收文档.md)

## 一、总入口

- 现有国家中断观测页、趋势制品、报告与追问能力具有可引用的只读合同；
- 当前产品事实范围固定为已有 `country_outage` 事件和唯一 RRC25；
- 最终验收文档已经明确调查助手与通用聊天、外部搜索、真实全国断网证明和 Network
  RCA Agent 的边界；
- 本计划不把既有代码、历史模型认证、页面截图或生产状态写成新调查 Agent 已经完成。

## 二、总出口

- 用户能够在明确事件和快照上下文中完成提问、澄清、组合调查、证据下钻、有限假设、
  多轮追问、事件切换和失败恢复；
- 前端达到 IFE-01 至 IFE-10，后端达到 IBE-01 至 IBE-13，联合旅程达到 ISE-01 至
  ISE-12；
- 全部关键数字、结论、证据、限制、未知和假设状态绑定同一合法 RRC25 publication；
- 最终候选通过量化门槛、同候选浏览器旅程和最终防偏离回检；
- 最终出口不自动等于已合并、已构建、已部署或生产已验证。

## 三、全局边界

- 从始至终只使用 RRC25，不增加 collector，不把外部资料混入核心事实；
- 不修改或降低最终验收文档来迁就中间实现；
- 未达到当前阶段出口时不得进入下一阶段，不以“后续补齐”掩盖已经到期的偏离；
- 每个阶段只验收到期的前端效果、后端效果和联合旅程，未到期能力必须保持未完成；
- 每个阶段结束必须调用国家中断调查 Agent 最终验收防偏离 Hook；
- Hook 结构检查通过不等于前端、后端、数据、模型、浏览器、用户价值、部署或生产效果
  通过；
- Hook 发现偏离时必须在当前阶段修正，或明确记录“存在待处理偏离”并停止晋级；
- 任何阶段都不授权公共互联网读取、付费模型调用、数据库写入、生产操作、发布或部署。

## 四、阶段入口、前端效果、后端效果、出口与边界

### I0：最终效果、问题范围和阶段映射冻结

#### 入口

- 最终验收文档已经形成候选版本；
- 现有国家中断页面、报告、追问、趋势和 API 合同可作为现状基线读取；
- 公开问题语料只作为需求与评测假设，不作为事件事实来源。

#### 前端效果

- IFE-01 至 IFE-10 的最终阅读和交互效果均有唯一编号、清楚边界和联合场景映射；
- 用户角色、典型问题、组合问题、歧义、证据追踪、有限假设和越界问题均进入冻结问题
  范围；
- 本阶段页面保持现状，不宣称聊天调查工作台已经出现。

#### 后端效果

- IBE-01 至 IBE-13 的最终事实、调查、证据、假设、模型、会话、失败和审计效果均有
  唯一编号；
- ISE-01 至 ISE-12 和量化门槛完整映射到前后端效果；
- 可回答、部分回答、证据不足、超出范围和有限假设的含义冻结，不依赖具体模型措辞。

#### 出口

- IFE-01 至 IFE-10、IBE-01 至 IBE-13、ISE-01 至 ISE-12 全部映射到 I1 至 I5；
- 最终验收文档与本计划互相引用，编号连续且没有相互矛盾的能力声明；
- I0 Hook 结论为“一致”或“已修正”。

#### 边界

- I0 只冻结最终效果、阶段头尾和边界，不证明任何新前后端能力已经实现；
- 不固定编程语言、模型、工作流框架、工具数量、存储或部署形态；
- 不把公开问题出现频率解释为真实客户优先级，不收集用户名或个人信息。

### I1：事件绑定的基础聊天与直接事实问答闭合

#### 入口

- I0 出口成立，最终效果和阶段映射没有待处理偏离；
- 合法国家中断事件能够解析到明确的 RRC25 publication；
- 现有页面和只读事实能够提供基础摘要、时间、ASN、指标语义和证据位置。

#### 前端效果

- IFE-01、IFE-02、IFE-04、IFE-05 的基础部分到期：用户从事件页进入后能看到持续可见
  的事件上下文，并在聊天式页面询问直接事实；
- 回答能够区分事实、指标解释、证据边界和证据不足，并可展开基础证据位置；
- IFE-06 的基础状态到期：开始、完成、失败和取消具有清楚状态，不展示内部思考过程。

#### 后端效果

- IBE-01、IBE-04、IBE-08 的单问题部分到期：每个问题固定同一事件快照，只读取最小
  必要的正式只读事实，并先判断可回答性；
- IBE-09 的基础叙述边界到期：语言生成不能修改关键数字、时间、方向和未知；
- IBE-10 的单事件短期会话部分到期，同一问题幂等重试不产生重复答案。

#### 出口

- ISE-01、ISE-04、ISE-06、ISE-07 的基础旅程通过；
- 用户能够完成“发生了什么”“最低点是什么”“指标什么意思”“证据在哪里”和越界问题
  的事件绑定问答；
- I1 Hook 结论为“一致”或“已修正”。

#### 边界

- I1 不承诺自由入口自动找事件、复杂多意图分解、组合调查或有限假设；
- 不因页面外观像聊天就称为 Investigation Agent 已完整实现；
- 不增加现有事实合同之外的数据，不把模型语言当作新的事件证据。

### I2：问题澄清、多目标理解与调查路由闭合

#### 入口

- I1 的事件绑定、基础聊天、直接问答和边界回答已经通过；
- 冻结问题集中具有多目标、歧义、指代、事件不唯一和修正问题；
- 当前 publication 的能力、完整度和缺失状态可以公开判断。

#### 前端效果

- IFE-03 到期：系统能够显示识别出的多个子问题，在关键条件不足时提出最少必要澄清，
  并允许用户修正对象或方向；
- IFE-08 的多轮指代和事件切换基础部分到期，新旧上下文清楚分隔；
- IFE-09 到期：后续问题建议只展示当前能力可支持的调查方向，不诱导越界结论。

#### 后端效果

- IBE-02 到期：问题形成包含请求类型、实体、多个分析目标、可回答程度和澄清状态的
  可校验请求；
- IBE-03 到期：每个分析目标只进入白名单能力允许的调查路径，能力不可用时不会伪装；
- IBE-10 的多轮结构化状态部分到期，自然语言和未确认假设不会污染事实。

#### 出口

- ISE-02 的问题分解部分、ISE-05 和 ISE-09 的上下文部分通过；
- 请求类型与分析目标 Macro-F1、关键实体准确率和关键歧义正确澄清率达到最终文档到期
  门槛；
- I2 Hook 结论为“一致”或“已修正”。

#### 边界

- I2 只证明问题理解和调查路由效果，不证明组合计算、Evidence Graph 或假设检验完成；
- 低置信度不得通过降低阈值、隐藏澄清或默认选择事件来提高表面完成率；
- 用户要求忽略规则、访问外部 URL 或执行操作时仍然保持核心边界。

### I3：组合分析、证据图和同事实回答闭合

#### 入口

- I2 已能稳定形成合法多目标调查请求；
- 时间线、ASN、地址族、Update 活动、资源和路径相关的已发布能力状态清楚；
- 组合问题的确定性事实、缺失语义和证据引用可以在同一 publication 内核对。

#### 前端效果

- IFE-02、IFE-04、IFE-05 的完整组合效果到期：多个子问题分别展示结论、关键事实、
  证据、限制、未知和完成状态；
- ASN、地址族、时间点、排名和代表性路径能够下钻到同快照证据，并公开分页、样本和
  观测方向；
- 局部证据不足不会掩盖其他已通过校验的子答案。

#### 后端效果

- IBE-05、IBE-06 到期：关键结果由可重复计算产生，Evidence Graph 同时绑定 Fact、
  DerivedFact、Claim、Limitation、Unknown 和尚未检验的 Hypothesis；
- IBE-08 的组合可回答性到期，每个子问题独立判定并保持缺失证据；
- IBE-12 的事实复现部分和 IBE-13 到期：页面、趋势、报告和调查回答共享同一事实语义，
  审计可以重建关键数字、证据关系和结论等级。

#### 出口

- ISE-02、ISE-03、ISE-06 和 ISE-10 的组合事实部分通过；
- 关键数字、方向、排序、结论等级与事实一致率为 100%，Claim 的有效 Evidence 引用
  覆盖率为 100%，快照混用为 0；
- I3 Hook 结论为“一致”或“已修正”。

#### 边界

- I3 的 Evidence Graph 是确定性调查制品，不因存在图结构就称为完整 Agent 或 RCA；
- 路径样本不冒充完整路径集合、真实流量、业务依赖或因果传播；
- 组合分析只使用同一事件和同一 publication，不在本阶段扩展跨事件或跨 collector 比较。

### I4：有限观察假设与人工确认闭合

#### 入口

- I3 的组合分析和 Evidence Graph 已通过；
- 允许的有限观察命题、禁止的因果命题和假设状态已经冻结；
- 每个允许命题都有可核对的支持、反对和缺失证据定义。

#### 前端效果

- IFE-07 到期：系统只建议与当前问题直接相关的有限观察假设，用户确认后才检验；
- 假设结果同时展示支持、反对、缺失证据和状态，不以颜色作为唯一语义；
- IFE-04 的假设分区到期，假设不与事实、限制和未知混排。

#### 后端效果

- IBE-07 到期：假设建议、人工确认、白名单检验、状态变化和禁止命题边界全部成立；
- IBE-06 的 Hypothesis 关系和 IBE-09 的模型限制到期，模型不能改变假设状态或使用
  因果措辞升级结论；
- IBE-08 的原因、责任、用户影响和全国断网策略拒绝保持 100% 正确弃答。

#### 出口

- ISE-08 完整通过，ISE-07 在反复追问和提示词注入下仍保持边界；
- 用户能够完成建议、确认、检验、阅读双向证据和撤销未完成检验的完整旅程；
- I4 Hook 结论为“一致”或“已修正”。

#### 边界

- “支持”只表示固定 RRC25 事实支持观察命题，不表示原因或责任得到确认；
- 不把政府行为、攻击、配置错误、设施故障、全国断网或用户影响纳入允许假设；
- 不自动串行扩展假设，不建设自主长期调查或多 Agent 协作。

### I5：前后端联合旅程、可信度和最终效果验收

#### 入口

- I0 至 I4 均达到出口，所有已发现偏离已经修正，没有通过修改最终合同消除偏离；
- 同一候选具有合法事件、冻结问题集、失败场景、桌面与窄屏环境和可复核审计身份；
- 未到期的模型、浏览器、权限、容量或环境条件已明确列出。

#### 前端效果

- IFE-01 至 IFE-10 在同一候选完整通过；
- IFE-06、IFE-08、IFE-10 的最终效果到期：进度、取消、重连、会话到期、新 revision、
  事件切换、桌面、窄屏、键盘和减少动态效果完成同一调查旅程；
- 所有失败、部分回答、证据不足和未知均以用户可理解且不泄露内部信息的方式呈现。

#### 后端效果

- IBE-01 至 IBE-13 在同一候选完整通过；
- IBE-11 和 IBE-12 的完整运行效果到期：快照冲突、能力不可用、工具、模型、校验、
  超时、取消、幂等和会话失败均确定性关闭并可审计；
- 未授权数据访问、外部网络读取、生产写操作、快照混用、越界断言和跨用户泄漏均为 0。

#### 出口

- ISE-01 至 ISE-12 和最终验收文档全部量化门槛在同一候选通过；
- 最终回检列出前端、后端、联合旅程、模型、浏览器、容量、权限、环境和审计证据身份；
- I5 Hook 给出最终“一致”或“已修正”结论，任何有条件项仍清楚标为未到期；
- 产品可以称为“RRC25 国家中断调查助手”，但不得称为 Network RCA Agent。

#### 边界

- 不以 Hook、测试数量、静态截图、一次模型调用、单个 API 200 或候选页面代替最终旅程；
- I5 通过不授权合并、构建、发布、部署、生产切换或外部能力启用；
- 后续若增加 collector、外部证据、跨事件比较、因果模型或生产操作，必须重新形成独立
  最终效果合同和分阶段计划。

## 五、阶段封口

Hook 必须同时回读最终验收文档和本计划，核对当前阶段的入口、前端效果、后端效果、
出口、边界和到期 IFE、IBE、ISE。阶段结束调用：

```bash
python3 .codex/hooks/country_outage_investigation_agent_review.py --stage I0
```

后续阶段将 `I0` 替换为对应阶段编号。作为条件化 Stop Hook 运行时，显式声明：

```bash
export DOMEYE_COUNTRY_OUTAGE_INVESTIGATION_STAGE=I0
```

回检结论只允许为“一致”“已修正”“无影响”或“存在待处理偏离”。“存在待处理偏离”
必须列出 IFE、IBE、ISE 或边界编号、偏离位置和原因，并停止进入下一阶段。Hook 通过只
证明合同结构、阶段映射、当前任务路径和冻结核心没有发现机检偏离，不代表本阶段前端、
后端、数据、模型、浏览器、用户价值、部署或生产效果已经通过。
