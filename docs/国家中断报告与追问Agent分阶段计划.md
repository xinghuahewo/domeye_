# 国家中断报告与追问 Agent 分阶段计划

版本：2.1  
约束：只定义阶段入口、阶段出口和实施边界  
最终效果基准：[国家中断报告与追问 Agent 最终验收文档](./国家中断报告与追问Agent最终验收文档.md)

## 一、总入口

- Domeye 已有合法 `country_outage` 事件、RRC25 页面和可授权读取的只读数据能力；
- 已有一份人工认可阅读风格的国家中断观测报告；
- 目标只包含前端最终效果和报告生成逻辑；
- Codex 对话、项目记忆和现成报告正文不构成 Pi Agent 的正式输入；
- 最终验收文档 2.1 是唯一最终效果基准。

## 二、总出口

- FE-01 至 FE-09、RG-01 至 RG-13 和 SCE-01 至 SCE-10 全部通过；
- 前端形成可完成生成、阅读、追问、外部证据和下载的技术报告研读工作台；
- 报告生成逻辑在固定 RRC25 快照上生成数字可信、边界正确、可复现的中文报告；
- 两条主线完成集成验收，不存在“界面通过但报告不可信”或相反情况；
- 每个阶段均留下防偏离 Hook 结论和可复核证据。

## 三、全局边界

- 不修改 `backend/core/` 业务逻辑，不改写国家中断历史数据；
- 只处理已有合法 `country_outage` 事件，从始至终只使用 RRC25；
- 不支持任意国家、任意时间、collector 选择、多 collector 或自动定时报告；
- 不扩大到其他事件、通用 RCA、归因、责任判断、处置或生产写入；
- 不暴露 Shell、文件编辑、任意路径、SQL、数据库凭据或任意会话切换；
- 不把 Codex 记忆、模型训练记忆、未授权互联网资料和报告示例数字当作事实；
- 外部搜索只在用户显式授权后读取受控公开网络，不读取内网、登录页面、浏览器
  会话或用户上传文件；
- 外部证据只作独立补充，不修改 Domeye 报告，也不补足最低数据门槛；
- 报告和问答只在短期会话内使用，不建设永久会话历史；
- 不以文档、结构检查、单元测试、一次模型调用或候选环境替代阶段出口；
- 未达到本阶段出口时不得进入下一阶段，后续阶段不得降低最终验收合同；
- 每个阶段结束必须调用国家中断报告与追问 Agent 最终验收防偏离 Hook。

## 四、阶段入口、出口与边界

### A0：两条验收主线和量化基线冻结

#### 入口

- 当前国家中断页面、只读数据和人工认可报告能够复核；
- 最终验收文档 2.1 已确认；
- 尚未用正式 Agent 证明前端和报告生成逻辑。

#### 出口

- FE-01 至 FE-09 与 RG-01 至 RG-13 的范围、关系和优先级没有冲突；
- SCE-01 至 SCE-10 的输入、预期结果和证据形式已经冻结；
- RRC25、已有事件、用户触发、最低门槛、显式外部搜索、短期会话和下载边界
  已形成基线；
- 会话、响应、容量、下载、视口、浏览器、隔离、清理、日志、权限和频率限制
  已形成版本化验收配置；
- 当前能力、目标效果和未实现项没有混写；
- A0 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不实现前端或报告生成逻辑；
- 不把 Codex 当前效果写成 Pi Agent 已具备能力；
- 不提前宣告任何 FE、RG 或 SCE 已通过。

### A1：报告输入、快照和事实闭合

#### 入口

- A0 出口全部成立；
- 代表性合法事件和量化验收配置已经冻结。

#### 出口

- RG-01 至 RG-04 通过；
- 合法事件、唯一 RRC25、固定快照、最低数据门槛、能力状态、事实标识和派生公式
  可以重复核对；
- 多接口身份冲突时整批重读，持续冲突时失败关闭；
- 前端能够获得显示事件身份、数据门槛和能力状态所需的确定结果；
- SCE-02 和 SCE-03 的数据侧结果通过；
- A1 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不要求正式中文报告、问答界面和下载已经完成；
- 不通过第二 collector、数据库直读或扩大权限解决事实缺失；
- 不使用 Codex 记忆、外部资料和示例数字补充事件事实。

### A2：基础报告生成逻辑闭合

#### 入口

- A1 出口全部成立；
- 固定快照能够提供经过核对的事实集合和明确能力状态。

#### 出口

- RG-05、RG-06、RG-08、RG-12 和 RG-13 的基础报告部分通过；
- 代表性事件能够生成达到人工认可风格的中文报告；
- 报告具有稳定结构、确定数字、控制面边界和清楚未知项；
- 发布前完成事实、公式、来源、能力和语义校验，失败时不发布草稿；
- PDF 与 Markdown 使用同一通过校验的报告制品；
- 无 Codex 记忆、无现成正文和无默认互联网的基础报告重放通过；
- SCE-01、SCE-02、SCE-03 和 SCE-09 的生成侧结果通过；
- A2 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不要求完整问答、外部证据和全部模型组合已经完成；
- 不为改善文风降低数字追溯、失败关闭或控制面边界；
- 不把一次成功生成等同于稳定通过。

### A3：前端和 Domeye-only 追问闭合

#### 入口

- A2 出口全部成立；
- 已存在可读取、可追溯、可定位段落和事实的正式报告。

#### 出口

- FE-01 至 FE-06、FE-08、FE-09 和 RG-07 通过；
- 用户在“数据观测”和“报告与追问”之间完成生成、阅读、就此追问和下载；
- 桌面、平板、手机、键盘、读屏、滚动、焦点和减少动态效果均可完成关键旅程；
- 问答以研读记录呈现，事实可展开并返回数据观测位置；
- 默认模式始终为“仅使用 Domeye 数据”，连续追问不离开原快照；
- 取消、重复请求、短期重连、到期和新 revision 的前端结果稳定；
- SCE-04、SCE-08、SCE-09 和 SCE-10 的前端与问答部分通过；
- A3 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不提前开放外部搜索；
- 不把追问扩展为跨事件通用 RCA 或永久聊天历史；
- 不允许通用聊天外观、草稿流、强制滚动或并发答案互相覆盖。

### A4：外部证据、模型、安全和运行闭合

#### 入口

- A3 出口全部成立；
- 基础报告和 Domeye-only 追问已经能够端到端复核。

#### 出口

- FE-07 和 RG-09 至 RG-11 通过，RG-13 的完整干净重放通过；
- 用户显式开启的外部证据独立分区、逐项引用、来源分级且不自行认定因果；
- 未授权原因问题、恶意 URL、登录页面、文件上传和提示注入不能扩大能力；
- 至少一个正式模型组合通过；备用模型只在已认证时完整重生成；
- 标准基础报告可以短期复用，用户问答、检索词、来源和临时状态保持隔离；
- 事件权限贯穿生成、追问、外部搜索和下载，跨用户内容不可见；
- 排队、并发、幂等、容量、超时、重试和频率限制按冻结配置通过；
- SCE-05、SCE-06、SCE-07 和 SCE-10 的安全隔离部分通过；
- A4 阶段结束 Hook 结论为“一致”或“已修正”。

#### 边界

- 不要求支持全部模型供应商和全部外部来源；
- 未认证模型、用户上传文件、内网页面、登录态和浏览器会话不进入正式能力；
- 外部资料不改变 Domeye 报告、不替代最低门槛、不成为 Agent 自主归因依据。

### A5：前端与报告生成逻辑联合验收

#### 入口

- A0 至 A4 出口全部成立；
- 两条主线的合同、场景、量化配置和证据位置均可复核。

#### 出口

- FE-01 至 FE-09 全部通过；
- RG-01 至 RG-13 全部通过；
- SCE-01 至 SCE-10 全部在最终验收环境通过；
- 前端阅读质量和报告事实质量同时达到最终合同；
- 量化门槛、权限隔离、模型组合、干净重放、失败关闭和下载制品均有证据；
- 已确认偏离全部修正，未验证项仍标为未知；
- A5 阶段结束 Hook 给出最终“一致”或“已修正”结论。

#### 边界

- 不以局部测试、候选环境、文档声明或单条主线通过代替联合验收；
- 不授权生产切换、历史数据修改、核心检测改造或其他事件类型扩展；
- 任一到期 FE、RG 或 SCE 缺少证据时不得宣告最终完成。

## 五、阶段封口

Hook 必须同时回读最终验收文档和本计划，核对当前阶段入口、出口、边界以及到期
FE、RG 和 SCE。结构检查通过不等于产品效果通过。

阶段结束调用：

```bash
python3 .codex/hooks/country_outage_agent_review.py --stage A0
```

后续阶段将 `A0` 替换为对应阶段编号。回检结论只允许为“一致”“已修正”“无影响”
或“存在待处理偏离”；最后一种必须列出 FE、RG 或 SCE 编号、位置和原因。
