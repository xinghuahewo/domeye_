# Requirement Traceability Matrix

## Purpose

Track:

```
Outcome
 ↓
Capability
 ↓
Requirement
 ↓
Implementation
 ↓
Test
 ↓
Evidence
```

## Requirement Template

| Field | Description |
|---|---|
| ID | Unique requirement identity |
| Capability | Product capability |
| Source | Origin of requirement |
| Problem | Why this exists |
| Solution | Expected change |
| Dependencies | Blocking requirements |
| Milestone | Target release |
| Acceptance | How completion is verified |
| Evidence | Test/report/PR |
| Status | Current state |

## Status

- Idea
- Analyzed
- Planned
- Implementing
- Integrated
- Verified
- Released
