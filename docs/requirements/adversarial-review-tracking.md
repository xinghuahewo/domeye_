# Adversarial Review Tracking Matrix

## Purpose

Track architecture review findings as managed requirements.

A finding is not a task. It must be mapped:

```
Review Finding
 ↓
Epic
 ↓
Capability
 ↓
Requirement
 ↓
Implementation
 ↓
Verification
```

- Implementing
- Verified
- Released
