# 国家中断趋势分析 S3 验收记录

版本：`country-outage-trend-analysis-s3-v1`  
阶段：S3  
范围：地址族对照、ASN 四状态迁移/持续性/规模、活动与状态时间对应  
状态：S3 已封口；不代表 API、页面、报告、生产或最终验收

## 一、阶段结论边界

S3 在同一 RRC25 固定快照、同一时间网格和同一 TrendProfile 分析身份上构造三类
确定性上下文：

1. IPv4 与 IPv6 对照；
2. ASN 状态迁移、持续性与观测规模；
3. UPDATE、ANNOUNCE、WITHDRAW、资源与状态的时间对齐。

本阶段只描述控制面观测比例、数量、状态和时间关系，不生成单一影响分数，不解释
成因、归属或路径传播。它不是 API、页面、报告、生产或最终验收证据。
三类上下文共同使用算法身份 `country_outage_trend_context_s3_v1`；输入或规则变化
会形成新的 `context_id`。

## 二、IPv4 与 IPv6 对照

地址族对照要求两个画像具有相同 incident、publication、revision、
`data_through`、RRC25、窗口、时间网格、指标和单位。允许分母不同，因为这正是
地址族对照必须保留的事实。

每个槽同时显示比率与分母：IPv4 值、IPv4 比率、IPv4 分母，以及 IPv6 值、
IPv6 比率、IPv6 分母。输出还包含：

- 两族各自质量、模式、关键点、阶段和终点残留；
- 每槽 IPv4 减 IPv6 的百分点差；
- 最大分化槽及其双份来源；
- 两族谷值位于同槽、相邻槽或滞后槽；
- 分母比例达到 10 倍时的显式不对称警告。

任一地址族质量不足时仍保留两族质量、分母和独立画像，但比较状态降级为
`insufficient_data`，不跨缺槽生成分化值、最大分化点或谷值对应。

冻结场景中 IPv4 分母为 1,000，IPv6 分母为 100。即使比例变化显眼，
小分母不等于同等绝对规模，不能隐藏两族分母后只比较百分比。

## 三、ASN 四状态人口闭合

ASN 状态固定为：

- `fully_visible`；
- `partially_visible`；
- `fully_invisible`；
- `unknown`。

unknown 独立参与人口闭合。任意 ASN 地址族状态未知时，聚合状态保守保留 unknown，
不并入 fully visible 或 partially visible。每个槽四状态数量之和必须等于固定 ASN
人口；每个 ASN、每个地址族的各状态槽数之和必须等于时间槽总数。

迁移矩阵在窗口起点、阶段终点和窗口终点之间生成完整 4×4 单元格。即使某格为零
也保留，16 格数量之和始终等于 ASN 人口。

## 四、ASN 下钻与优先审查视图

每个 ASN 输出：

- IPv4、IPv6 各自基线 Prefix×VP 观测规模；
- 起点、阶段采样点和终点状态；
- 四状态槽数和每种状态最长持续段；
- 连续处于已观测非全可见状态的最长槽数；
- 终点是否等于起点状态；
- 所有状态转换与来源引用。

优先审查保留两个独立视图：按观测规模排序、按持续性排序。每一行同时展示
观测规模和持续性，不生成单一影响分数，也不把排序解释为实际影响、成因或归属。

冻结样本含 5 个 ASN、968 个基线 Prefix×VP，每槽始终保留 1 个 unknown ASN；
终点状态分布为全可见 2、部分可见 1、全不可见 1、unknown 1。

## 五、活动与状态时间对应

四条轨道保持不同统计人口：

| 轨道 | 统计人口 | 单位 |
|---|---|---|
| UPDATE | update message | count |
| ANNOUNCE | announce message | count |
| WITHDRAW | withdraw message | count |
| 资源 | resource record | count |

每个五分钟槽把活动值与同槽的原子状态、阶段 ID 对齐。每条轨道的最早最大值与
谷值、最大单槽下降、最大单槽回升只建立同槽、相邻槽和滞后槽关系，并明确活动位于
状态点之前还是之后。

这些关系只表示时间关系。不同统计人口不相加、不相减，不生成共同分数；输出中的
`cross_population_arithmetic_performed=false`、`common_impact_score=null` 和
`causal_claim=null` 是机器边界。

## 六、失败关闭

S3 冻结八类失败关闭场景：

- 地址族 revision 不同；
- 地址族统计人口错误；
- 重复 ASN+地址族；
- ASN 槽数不完整；
- 非法 ASN 状态；
- 重复活动轨道；
- 活动统计人口不在白名单；
- 非观测活动槽携带数值。

失败时不拼接快照、不补槽、不吞掉 unknown，也不退回为无身份 JSON。
