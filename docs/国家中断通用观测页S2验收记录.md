## 一、本阶段结论

S2 只把 S1 已冻结的 81 个事件 cohort 投影为事件窗口内的五分钟前缀、AS 和 IP
状态。共有 13,488 个事件状态点、112,584 个事件前固定前缀和 4,518,501 个
预期独立观察方向关系。

RouteState 仍是唯一状态事实。S2 不保存另一套 Prefix×VP 状态，不使用旧 AS 中断表，
也不把会话掉线伪写成 WITHDRAW。物理输出是每事件的完整五分钟 series，以及前缀、
AS 和新前缀的基线与变更点；后续可重建任一状态点，但不需默认下发巨大全矩阵。

## 三、前缀与观察方向规则

对每个固定前缀：

- 一个独立观察方向仍是一个 RRC25 peer ASN；同 ASN 的多个 BGP 会话只算一个方向；
- 同一方向内任一 RouteState key 当前可见，该方向就可见，不要求当前 origin 必须与
  冻结点 origin 相同；
- 预期方向中至少一个不可见且至少一个可见，就是部分中断；
- 全部预期方向不可见，就是完全中断；
- 部分中断和完全中断的唯一前缀合计为“前缀路由中断”，完全中断的子集为
  “完全中断前缀”；
- 任一缺槽或无法确定的方向保持未知，缺槽和未知不补零、不连线、不写成恢复。

会话 `STATE_CHANGE` 保留为独立点观测事实。它可说明某时会话发生转移，但不会被当成
连续的第二状态机覆盖 RouteState；前台的“中断”仍只表示当前路由未被观测到。

## 四、AS 分类规则

固定前缀在 S1 冻结的目标国家 origin ASN 集决定归属，多 origin 保留多个真实归属，
不把不同 AS 的前缀人口混成影响分数：

- 某 AS 至少一个固定前缀部分或完全中断，且没有未知前缀，则为“受影响 AS”；
- 某 AS 的全部固定前缀都完全中断，且没有未知前缀，则为“AS 路由中断”；
- 只要存在未知前缀，该 AS 保持未知，不静默并入正常、受影响或 AS 路由中断。

因此前缀趋势和 AS 趋势有独立整数人口，不使用双轴、百分比或混合影响分数伪造可比性。

## 五、IP 资源与新前缀轨道

IP 趋势只从唯一前缀集投影：

- IPv4 使用规范化、去重并合重叠前缀后的 **IPv4 唯一地址并集**；
- IPv6 投影为规范化、去重并合后的 **IPv6 `/48` 等价并集**，不写成 IPv6 实际地址总数；
- 观察方向数、BGP 会话数、AS_PATH 数和重叠前缀都不会重复扩大资源量；
- 事件 cohort 冻结后首次观测到的目标国家前缀进入 **新前缀独立轨道**；
- 新前缀同时保留“当前可见”和“累计出现”两条趋势，不加入固定 cohort 分母，不抵消
  前缀路由中断，也不把 AS 提前写成恢复。

- 没有重新解析原始 MRT 生成 RouteEvent，只消费已冻结 RouteEvent 一次；
- 没有建立第二套 RouteState，没有改动 S1 cohort 和会话事实；
- 没有生成 S3 的 AS 外部属性或路径关联下游，没有使用 relationship 或 customer cone；
- 没有实施 Publication、API、前端、数据库或生产切换；
- 所有趋势仍只是 RRC25 路由控制面观测，不代表全国断网、用户影响、原因、责任或客户依赖。

地址并集与 IPv6 `/48` 等价并集；81 个事件、13,488 个状态点的人口、身份、语义和边界
均已闭合。新前缀若在首次出现的同一五分钟槽内又撤回，首次观测记录允许槽末状态为
`not_visible`：累计轨道计入该前缀，当前可见轨道不计入，二者不混淆。
