## 五、兼容修正

现有历史国家中断表不一定已经增加 `incident_id_v2`、`peak_snapshot_id` 和
`legacy_semantics`。详情查询已改为从整行 JSON 安全读取这些可选字段，因此旧表
无需迁移即可继续返回基础事实；存在新字段时仍能读取结构化事件身份。
